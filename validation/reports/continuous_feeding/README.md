## 事前方案、场景和控制边界

[实验前计划](../../../docs/连续主动送链实验计划.md)在本轮动力学前保存；[唯一修复计划](repair_plan.md)在复跑前保存。主例顺序是小幅−64.5mm、头向−258mm，头向失败后先修复复现，再执行尾向+258mm。每例同一起态，目标后2s观察，返回后原定2s；失败例没有到达返回后观察段，不假写成已完成。

实际模型：113mm水平直管，中心线x=−1.2…1.8m、y=0、z=1.2m、半径.0565m；20关节、21根64.5mm连杆，初始J8–J13、60°、phase0、x=−.5m，建立6s。摩擦[2,.005,.002]、重力[0,0,−9.81]、Kp127、Kd1、限矩2.355Nm、机械被动阻尼1.5、armature .01保持原场景。沿用既有Conda `mujoco`，没有安装依赖。物理1ms、控制20ms、读角200ms。

`ContinuousFeeding`只有全关节角、反馈时刻及控制时刻输入。目标是沿身体接续的弯曲分布，移过一个同轴关节组后自动接续下一组，可在分数位置停止。左右曲率分配由角度几何肩部高度差调整，中部和边界共同变化；命令总角预算始终180°、偶数轴目标0°，不是管径顺应，没有Yamada积分或名义恢复项。

进入关节按当前角预置，离开关节角度≤8°时失能；共有目标按45°/s上限连续变化。实际各例使能数量6→7，未出现数量无界扩大。**≤8°是角度释放代理，不是已测得卸载**，本轮返回失败证明它不足以保证真实承托交接。

长度观察以全身角度重建、合格悬垂端提供条件性上下方向，在局部弧边界共同高度切取两侧材料长度，反馈`(头−尾)/2`。共同高度不是测得的管轴中心或接触脱离点。通过两侧差抵消部分共同截面高度误差，而不是把使能关节数当长度。速度滤波.4s，误差≤8mm且变化速度≤4mm/s持续.4s新反馈后进入2s观察，观察期间仍闭环。

世界骨架、真实管径、真实重力、接触力、力矩和根部姿态仅用于评价；没有外拉、根部约束、运行中位置重置或读取世界位置来控制。窗口外主动力矩为0，但保留机械阻尼，不能称已等效真实舵机断电动力学。

## 修复效果与原因判断

**已确认的实现错误及修复：** 头向主例37.42s起观察失效。新进入J13按约−39°预置，观察失效分支把目标冻结在预置角，导致无法完成展直。修复后只冻结送链位置/偏置，继续完成当前规划的形状；37.42–37.80s观察失效后确实短暂恢复，并进一步返回。39.02s再失效、42.04s终止，避免原来的91.4s无效等待。它修复了目标冻结，**没有修复实际大幅返回能力**。

**高置信事实：** 旧边界释放角度虽≤8°，失能后可重新弯折；真实承托区域与使能区域错位。头向修复末态J5已失能却弯约35°，支撑集中在第7连杆；尾向返回旧边界的弯折和新使能区合在一起形成大角度包绕。实际角度/掩码/支撑分布和分镜一致。近零角度并不能证明释放后无需承托，也不能保证旧段持续竖直。

**中等置信解释：** 直接按规划材料位置切换控制区域，在重力、接触摩擦及两侧重量不对称时，新承托形状未建立就释放旧边界，使实际上弧滞留。局部截面随后不再代表真实上弧，悬垂方向资格失效，长度闭环无法继续。没有外加拉力，不把失效归因于人为拉动；没有逐项消融，不能声称已经证明唯一物理原因。

**尚未证明有效的中部协调项：** 偏置在小幅/头向/修复/尾向分别14.22/111.42/24.64/26.44s达到±.18范围；小幅支撑点横摆比上一轮主例26.26mm更大。控制目标对称不代表承托位置稳定。本轮不宣称这个协调项改善了原地性，后续需重新审查其作用。

长度估计在旧两条记录的变化量RMSE为4.29/2.20mm、最大10.12/7.55mm；新运动中按反馈时刻对齐真值的RMSE为7.12/11.79/13.55/17.99mm，最大17.35/28.31/41.27/64.50mm。原记录的低误差没有迁移到大幅返回，这是明确的适用范围限制。新反馈与时序同时变化，不把本轮数字解释为单个控制项的因果收益。

## 下一项最小改进与交接

下一步应优先修复**释放和真实承托弧接续**，暂不继续扩大目标：

1. 从完整角度骨架定位真实上部弯曲区域，长悬垂端提供条件性方向；避免“先用当前使能窗口定义开口，再据此判断是否能看到真实上弧”的循环依赖。不能把几何定位当作接触传感。
2. 保留旧边界一小段交接缓冲，直到角度重建显示它已离开上部承托弧并保持展直，再失能。允许必要的短时局部重叠，不无限扩大使能范围；不能只凭一帧≤8°就释放。
3. 新使能区域尚未与实际弧对齐时减缓或暂停送链，协调已有承托区；完整角度骨架的开口/转角必须包括重新弯折的旧边界，防止局部命令180°而整体包绕。

如果继续验证，先只复现尾向+258mm返回这个最严重病例；修复后再做相反方向回归。不以放宽观察资格、延长失效等待、增加包紧角度或加大阻尼换通过。本轮按3+1预算终止，尚未验证其他管径、弯管、更多次数、长期稳定或实机，不能称任意两侧长度已可达。
