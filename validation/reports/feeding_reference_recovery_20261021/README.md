# 模式4→3重选与送链参考连续交接

2026-10-21。本轮仅使用已有实测角记录、软件时钟和内存串口，没有连接真实机器人，没有新增闭环动力学。实机单文件与默认角度反馈的MuJoCo调试入口已同步；只做本地提交。

## 范围、假设和验收

已知问题分为两组：模式4→3继承展直缓冲窗口；送链方向/长度观察在候选交接、真实串口采样间隔下掉线，接管阶段笼统显示“未稳定”。固定既有步态公式、顺应方法、机械尺寸、直线度0.98、3次/0.4 s方向稳定门槛、5°跟踪门槛、3°角度波动和2 mm长度波动门槛。只改变状态切换、采样缓存、参考坐标交接和诊断。

软件验收要求：4→3真正重新选窗并写入扭矩掩码，新控制器持续收角并可提出/完成自动位置交接；失败保留原支撑掩码并保持，不伪称模式3；重复时间戳不得伪造采样，已使能区段不得用作被动参考；短暂缺样可恢复，失去参考连续性时不能把坐标跳变计入送链；真实跟踪误差仍应阻塞并给出具体数值。

## 已确认问题与修改

1. 原实机`select_gait`从主动送链退出时只清掉送链对象，保留`first/last/enabled`。仿真入口还先切一次基础模式，提前清掉来源标志。两者均不能满足4→3重测窗口。现在保留来源信息，先暂停送链、读取全身实际角并选出开放圆弧，再以实测角预置和写入新掩码；不先全失能，也不重新生成名义圆弧。重新创建选窗/数量观察器和时间状态，沿用Ctrl+U配置不变。
2. 选窗时只把当前实际失能两端作为条件性方向依据，不能将模式4仍在使能的直线缓冲段当作自然悬垂。重选失败仍是模式4保持，不退回“继承窗口”的静默路径。
3. 原方向历史按0.4 s裁剪后可能只剩2个样本，而判据又要求3个；真实约0.21 s读角间隔下出现无意义的`collecting_stability`。改为同时保留最低样本数和时间跨度，没有降低稳定时间、直线度或波动门槛。
4. 所有被动候选继续并行积累历史。新旧参考仍合格、仍失能且方向相容时，在同一帧完整骨架上重建两个长度坐标，显式扣除仅由换参考造成的坐标差。不能直接冻结头坐标系中的旧向下向量。若旧参考已经使能、形状不可靠、没有共同参考或有效观测缺失过久，提升基准序号，不能假装连续。
5. 接管采样按连续的坐标基准判定，不再只因候选编号或融合来源改变就清空。短暂合格采样不足保留已有历史；真实不可靠形状、跟踪不合格和不连续基准仍重新采样。送链中失去连续参考时保持材料参数，重新取得稳定数据后保留此前已观测进度，未知间隔内运动不计入完成量。速度估计重新初始化，避免假速度尖峰。原恢复时间上限保留，观察失效时也不能仅因复核计时到期便完成/自动返回。
6. `acquisition_reason`区分采样、跟踪、角度波动和长度波动。显示最大误差关节、目标角、实测角、误差，以及波动最大的关节。旧代码在非新反馈帧又将原因覆盖成“等待稳定”，容易掩盖持续跟踪误差；现在保留真实原因。

## 后续实测：失能状态Ctrl+3被拒绝

14:36启动的`rolling_arc_20261021_143621_821744.jsonl`全部561条保存态都是`released/basic_arc`，20关节均失能，保存角度只有1组不同值。本次不是模式4窗口继承，不能拿前述4→3检查解释它。`initial_selection_followup.json`保留代表原始行、记录统计与修复后的选择结果。

已确认的程序问题：初始选择要求候选绝对弯曲量至少占全身绝对关节角之和65%。这把失能末端的局部折弯也计入分母，错误排除了主圆弧。本次全身绝对角之和290.479°，J10–J15占58.73%；但该区重建转角169.81°、圆覆盖205.12°、开口比例0.542、圆拟合RMS12.42 mm，且尾侧参考合格。原来统一报“没有开放圆弧和下垂参考”不能说明真实拒绝原因。

修复改为局部弯曲至少90°，并要求候选跨过由合格失能参考确定的重建顶部，继续检查已有开放/平面/圆拟合条件；不再用全身绝对角比例排除主圆弧。此样本顶部材料坐标13，选择J10–J15（6关节）。方向仍是条件性角度估计，不宣称实测世界Z或识别真实支撑。失败时记录`initial_window_selection.accepted=false`、实际全角、候选拒绝统计与数值，并区分失能初始化和模式4保持原掩码。

此续修只增加2项针对性检查，并复核7项相关已有检查，共9项通过：实测失败姿态接管、失败诊断保存、模式4→3实机/仿真一致性、自动交接、扭矩掩码、原偏置初始化、直线拒绝和仿真入口。使用既有`mujoco`环境，没有新实机或动力学实验。命令：`python -m unittest validation.test_feeding_reference_recovery.ModeSwitchTests validation.test_feeding_boundary.BoundaryTests.test_ctrl3_arms_measured_offset_arc_and_ctrl_u_keeps_configured_seed validation.test_feeding_boundary.BoundaryTests.test_ctrl3_rejects_unobservable_straight_pose_without_enabling validation.test_feeding_boundary.BoundaryTests.test_debug_ctrl3_uses_same_selector_and_configured_reset -v`。
