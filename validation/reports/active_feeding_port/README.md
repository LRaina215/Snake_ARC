## 发现的问题与处理

- 直接沿用绝对时钟会把暂停计入形成/等待期限，单帧可能吃进暂停dt。恢复时剔除暂停间隔、重置目标更新时间；实际反馈时间仍保持真实采样时钟。暂停10 s及单帧检查通过。
- 实机可能从任意现姿接入，若形成前固化虚拟切片，会得到错误起态。形成期间不固定切片，完成后重新建立长度基线并清空旧速度；重启保留当前目标和旧承托掩码，按限速接入。
- 送链中修改基础幅值会触发旧形成标志，阻碍下一任务。基础参数与送链任务分开管理，回归核对通过。
- 故障重试曾先重置再叠加暂停时长，使阶段期限偏到未来。现在先消除暂停，再从当前时刻重设重试期限，保留原故障事件。
- 一项旧回归默认要求拒绝高角频率，与用户已授权的DIY行为冲突。测试改为分别核对DIY接受和研究模式原子拒绝，未恢复参数拦截。

上述为软件可复现问题及修复，置信度高。硬件通信延迟、跟踪误差、扭矩和真实形态仍无法通过内存总线验证。原研究中正向大幅目标裕度有限、几何长度代理偏差和横摆仍存在，没有因同步而宣称解决。
