## 已确认的原因

原软件仍使用历史20路校准的前18项；在用户确认的直线姿态中，J7报−86.2°、J10报−89.8°、J14报−90.3°，J1也报−21.9°。因此旧零位不再对应当前装配的直线基准，重建会把直线误画成弯曲。这个问题不能靠旋转预览画面或统一缩放连杆长度修复。

取 `rolling_arc_20261107_155147_986557.jsonl` 中t=32.531 s、全失能的一帧完整精度角度；18个角度舍入后均与用户发回的数据一致。使用已知旧零位和角度换算反算编码器整数位置，作为新软件零位。未连接设备、未向舵机写入内部偏移或目标。

新校准保存在 `configs/hardware_18j_reference.json`，并显式复制到单文件实机入口：

```python
ZERO_RAW = [1778, 2078, 2055, 2024, 2032, 2018, 1041, 2054, 2050,
            3049, 2033, 2047, 2047, 3058, 2063, 2045, 2063, 2022]
```

旧20路档案保留供历史实验追溯，不再作为当前18关节装配的校准。ID顺序和方向符号未改变。
