# 恢复局部实测截面顺应与修复滑窗时钟

2026-10-13。用户授权直接同步实机，由用户开展实际测试。本轮只有离线目标生成与协议检查；没有新动力学、没有连接串口或操作机器人。

## 改动及验收口径

假设：移除名义恢复后，同一实测截面、相位和增益产生的候选目标不再受初始圆弧幅值影响；重复控制时间戳不应触发永久停控。固定机械长度、奇偶轴、使能掩码、滤波和目标限速，只改顺应目标来源和计时处理。验收包括参考函数数值对照、半径增大的输入响应、重复时刻幂等、两端适配一致、扭矩关闭及发送ID检查。

参考依据是相邻仓库 `Snake_Robot_Gait/snake_control/pole_compliance.py` 的当前实际实现：从实测线/圆弧出发，管外局部半径按 `scale/(1+K_i)` 变换，转角乘 `1+K_i`，保持弧长，归一化模块长度后积分生成关节角。未以该仓库早期文档中相反的半径公式替代当前代码。

- 固定窗口及自动窗口内核现在直接使用实测截面转换角，删除 `q_nominal + yielding*(F_actual-F_nominal)`。
- 删除目标不满足开放检查时向名义圆弧二分插值的退路。研究检查启用时保持最近目标并标记原因；默认手调DIY仍不以这些形态门槛拦截。
- 保留局部平面重建、零挠率圆弧滚动、全局奇偶轴映射、首尾使能关节半增益；这些是局部适配。没有恢复全身螺旋或驱动窗口外关节。
- 基础模式仍按幅值形成圆弧；滑窗观察器仍可用名义形状比较位置/数量。两者均不进入局部顺应目标的恢复项。
- `yielding` 从手调参数和状态说明中撤下。`SectionOptions.yielding` 仅为读取旧配置保留，不参与计算；输入旧的 `yielding=...` 会明确说明已取消，避免静默误导。
- 曲线末端半连杆原先和最后一个内部关节共用模块编号，已改为独立末端模块，避免归一化漏掉末端物理长度。几何点/投影窗口未改变。
- 实机反馈采样与滑窗控制共同使用 `perf_counter`。重复控制时间戳不消耗时间、相位、单步余量或移窗事务；下一递增时刻继续。真正倒退的时间仍报错。
- 仿真手调默认直接共用实机内核；研究目录下对应截面与时钟实现同步。

## 已验证事实

命令：`conda run --no-capture-output -n mujoco python -X utf8 validation/test_measured_section_restore.py`。

五项测试全部通过：

1. 将同一局部曲线送入参考仓库原始 `build_backbone` / `joint_angles`，在平面退化和轴序换算后，对照两种窗口奇偶、三个相位，目标误差不超过 `2e-14 rad`。更改名义幅值/旧yielding字段、提供不同外部参考，均不改变候选目标。
2. 合成较大实测截面对应更小的目标弯曲量；固定实测输入重复更新，候选不会递归变形上一帧目标。注意：真实机器人跟随目标产生新实测形状时，仍可能在无接触约束下逐渐收紧，此项不证明排除闭环包绕。
3. 相同控制时间戳返回原目标与使能，下一递增时刻恢复，时间倒退仍被识别；研究与实机内核一致。
4. 固定/滑窗模式在实机和仿真手调适配中产生相同目标；同一时刻重复调用不消耗单步余量；仅发送J8–J13目标。
5. 在普通时钟不变的条件下验证高精度采样/控制时钟；内存串口中窗口外扭矩寄存器为0，退出后全部为0。

已保留旧版 `0caf90b` 的失败复现数据，见 [software_checks.json](software_checks.json)：相同时刻第二次调用报 `Control clock must increase`；同实测输入但名义幅值30°/85°时，旧候选最大相差0.3438739016 rad，新候选差为0。当前Conda环境的 `monotonic` 为 `GetTickCount64()`，分辨率0.015625 s；`perf_counter` 为 `QueryPerformanceCounter()`，分辨率1e-7 s。已有实机日志只保留了故障状态，不能从100ms记录单独还原故障瞬间的所有调用；重复时间戳机制已经离线复现。

## 复盘与交接边界

首次数值对照暴露了末端模块编号错误，修复后全部检查通过。旧名义恢复对候选的影响及旧重复时钟异常已确认；这两项是否解释用户实机中的全部现象尚不能确定。

本轮未观测实际运动，因此开放形态、接触支撑、跨管、饱和、漂移及连续移窗效果未验收；历史动力学通过结论不能转移到新控制律。本轮完成代码恢复与两端同步，不能宣称研究运动目标或实机变径已经通过。

下一项最小验证由用户进行：先Ctrl+2在固定窗口比较实测截面被撑开前后的目标，再Ctrl+3确认滑窗不再因时钟报错停控。默认仍由Ctrl+U建形，Ctrl+1/2/3切换，Ctrl+X全部失能。保持/冻结语义不变：暂停相位可以继续顺应，Ctrl+N冻结发送目标。
