## 必要检查

`py -3.12 -X utf8 -m unittest discover -s validation -p "test_*.py" -v`：13 项通过，其中新实机检查 8 项，原 Step1 检查 5 项。

| 新检查 | 结果及含义 |
| --- | --- |
| 校准/公式一致性 | 单文件 ID、零位、方向与档案一致，圆弧角与既有仿真公式一致 |
| 预置与失能 | 在所有舵机原先使能的内存场景中，先预置实测位置，再更新使能；目标包仅包含 J8–J13，释放后全零 |
| 平滑/单步/暂停/反向 | 正反单步准确停在累计目标相位，反向操作不翻转当前姿态，暂停保留已发目标，长循环延迟不追赶大跳变 |
| 参数与窗口 | 非法整行修改被整体拒绝；接管时不能更改窗口，释放后可以 |
| 使能失败 | 忽略使能写入的串口会被读回比较发现 |
| 协议故障 | 回显/噪声正常过滤，错误位、协议校验错误及超时被拒绝 |
| Ctrl 输入 | Ctrl+U/J/H 和 Ctrl+空格映射有效，普通字母/空格和 F 键不绑定；按住重复被过滤 |
| 控制中断与清理 | 在主动反馈阶段注入串口故障，主循环终止，退出全失能并关闭端口；不继续生成动作 |

## 离线完整流程

```powershell
py -3.12 -X utf8 codes/Rolling_Arc_Real.py --dry-run --no-hotkeys --no-console --auto --fast --duration 12 --log validation/results/real_controller/dry_run.jsonl
```
