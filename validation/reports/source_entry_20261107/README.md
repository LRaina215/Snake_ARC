# ARC调长后复用原重力矩回卷（2026-11-07晚间）

本轮完成：在旧18关节模型中，从三种两侧长度起态自动准备前部螺旋，再直接接入原重力矩回卷，实际形成统一Helix；通过部分已同步单文件实机与手调共用控制器。Ctrl+U增加两端短时归零后失能。没有连接实机。新连接件、完整T管回归和跨管径最优半径未验收。

## 五项问题的结论

| 问题 | 已验证事实 | 结论边界 |
| --- | --- | --- |
| 1. ARC半径兼顾稳定和速度 | 110 mm管道、同一送链任务下比较50/60/70°、双方向共6次；60°送链误差较小，70°自碰撞，50°反向过量 | 60°是本次较均衡候选；不能证明存在唯一或通用最优半径，也没有据此发布自动半径优化器 |
| 2. 自动调长到只有前部搭管 | 近等长、头短、尾短均自动准备前部，尾部接入晚于前部实际支撑确认 | 材料分配与曲线准备自动；真实支撑仍由操作者L确认，不能仅凭电机角证明接触 |
| 3. Ctrl+U两端归零再释放 | 悬垂和触地两种初态，有／无归零共4次有效对照；两种归零均约1 s达到零位后失能 | 展直不等于竖直；触地端不能直接作为重力参考。此动作会短时使能非承载端 |
| 4. 前部向内、前后不属于同一Helix | 回卷中前部持续推进，结束后统一全身曲线；实际最终约1.978圈，最大离轴半径106.9 mm以内 | 当前三起态仿真有效，不撤销此前真实机器人失败记录 |
| 5. 接原回卷送尾 | 已复用 `return_seat → return_wind → return_finish → recover`；三起态回卷中前部实际向前约182 mm | T管代表例完成接入、到达对准，但本轮未完成完整T管越障 |

## 假设、固定条件和输入

方案见[本轮计划](../../../docs/2026-11-07晚间仿真计划.md)。主假设：前部准备完成后，无需冻结全部前部另写尾部卷曲控制；可以复用原回卷，通过缩短直尾、补偿前部相位，将尾部材料沿同一拼接曲线送入螺旋。

固定18关节、旧等轴距64.5 mm、110 mm主管，T管代表例为向上60 mm支管。实际加载 `Snake_Robot_o18_Tee_straight.xml`／`Snake_Robot_o18_Tee_up60.xml`，不是根据文件名推断尺寸。主管圆柱半径55 mm；额定限矩2.355 N·m、摩擦0.5、被动阻尼1.5，主动PD为127／1。默认Helix中心线半径94 mm，螺距130 mm。控制20 ms、全身读角200 ms、实际状态保存50 ms，物理步长1 ms。

控制输入为全身实测角、已发使能、采样时刻和控制时间。MuJoCo接触、管轴与世界位姿仅用于独立评价，以及实验脚本模拟操作者的L确认；没有将其传入实机控制器。前部确认要求实际绕管至少0.8圈、离轴半径不超过120 mm、至少两段接触持续0.6 s。删除了原“接触索引必须相隔3段”的评价要求：接触刚体数量与曲线形态已分别检查，不把索引跨度当支撑的必要物理条件。

新实物连接件只有外形102 mm、相邻电机78 mm及同轴146 mm等描述，尚不足以确定完整转轴几何；本轮未冒充新机械模型，未用102 mm替换运动轴距。

三条记录检查了完整保存的实际状态，运行时每1 ms检查非相邻刚体接触：

- 调长／纯ARC准备阶段近管骨架极角覆盖最大236.84°，保留开放缺口。它含肩部和近管切线段，不等于圆弧本身的总弯曲角，也不宣称始终精确半圆。
- 实际前部支撑先于尾部接入；`return_wind`中前部持续接触，前部目标变化约1.74 rad，实际头部前进约182 mm。
- 无已记录的非相邻刚体碰撞、无落地；全部失能关节驱动力矩为零。关节实际角不超过74.70°，低于90°限位。
- 三例分别有84／77／85个50 ms保存帧发生至少一关节限矩饱和，不能写成完全无饱和；最大全程跟踪误差分别8.19／8.22／8.23°。
- 最终保持3 s后，另从近等长成功记录的**原qpos/qvel和完成态**续跑10 s：最少1.978圈、最大半径106.78 mm，头部前进42.45 mm，无自碰撞／落地／低于接触记录门槛的保存帧，无限矩饱和，最大跟踪误差0.54°。

最后对已嵌入实机文件的核心重跑近等长，结果与实验核心一致；头短、尾短保留先前等效核心的完整记录。原回卷与改后库实现另做逐控制步对照：保留8或9关节时，目标差为0、使能及阶段一致。8关节用于后续重力释放，9关节用于本次初始前部支撑，不能将初次接入前缀永久覆盖后续T管释放参数。

这里复用的是本仓库此前已移植的实机版2回卷，逐帧对照对象为本轮修改前的`7e3259b`。用户ZIP中的默认螺距为140 mm，本轮沿用本仓库130 mm仿真参数，因此不称为原文件、原参数直接运行。

## 半径对照：保留有限结论

本节明确指**左右调长／主动送链时的ARC半径**，不是ARC Rolling推进时的最佳半径，也不是Helix抱管半径。

同一个60°稳定起态，先用3 s建立50／60／70°，然后执行相同双方向、请求129 mm的送链任务。表中半径为初始关节重建的截面拟合半径，非管道半径；调长沿用已有中间15°幅值补偿，运动中并非恒定半径。

| 幅值 | 初始拟合半径 / mm | 头侧增长：实际量 / mm、时间 / s | 头侧缩短：实际量 / mm、时间 / s | 实际过程 |
| --- | ---: | --- | --- | --- |
| 50° | 149.07 | +118.54，21.2 | −164.79，21.2 | 双向完成，但反向过量35.8 mm |
| 60° | 123.93 | +133.92，21.0 | −133.10，20.8 | 双向误差约4.9／4.1 mm，当前较均衡 |
| 70° | 105.93 | 未完成 | 未完成 | 开始进给后头端与尾侧非相邻刚体接触，立即判失败 |

50／60°实际平均送链速度约5.59–7.77 mm/s；50°缩短方向看似最快，同时明显过量，不能作为速度优势。两者总时间相近还受固定0.1关节/s进给限制，**本轮没有测各半径的最大稳定速度**，因此不足以证明速度最优。

50°缩短方向有最长约0.1 s、60°增长方向有单个约0.05 s保存窗口，接触力低于记录用0.15 N。复核这些保存姿态仍有几何接触（最小接触距离为微小负值），不能称为已离管或掉落；早期进度中“短暂失去接触”的表述在此更正。原始严格`passed`标志保留，不把单帧门槛自动等价为工程失败。两者无非相邻自碰撞，冠部高度变化约17–24 mm。

工程结论：在**当前几何、当前双向送链速度**下，保留60°默认值合理；更贴管并不一定更好。暂时不能从单管径、三幅值推出跨管径通用最优ARC半径，更不能发布“自动选最优半径”功能。离散平面近似可用 `R≈d/(2 sin(α/2))` 理解转角与半径关系，d为同一弯曲平面相邻有效转轴距；它不是考虑接触、重力、摩擦及离散交替轴后的最优公式。

## 两端归零的实测状态对照

两端初始置入25°／−45°弯折，承载ARC固定J8–J13，其他条件不变，分别比较悬垂与真实触地的有／无归零，各5 s。

| 情形 | 未归零：5 s后非承载端最大角 | 归零完成时最大角 | 释放后5 s最大角 | 承载区最大位移 |
| --- | ---: | ---: | ---: | ---: |
| 悬垂 | 26.02° | 0.056° | 5.96° | 20.67 mm |
| 触地 | 26.88° | 0.070° | 3.90° | 13.37 mm |

两种归零均在约1 s完成并恢复两端失能，承载段持续接触，无非相邻碰撞。触地例确有地面力，不能只根据场景标签称为触地。归零过程各有37个20 ms保存帧至少一关节限矩饱和；这项动作有效但不能宣称全程轻载。释放后被动驱动力矩为0。实际重新下垂后可恢复少量弯角，目标不是将两端永久锁成直线。

首次“floor”候选未真正触地，故未作为触地证据；纠正初始地面高度后才采用 `end_reset_round2`。动力学试验中的归零结束判据读角为20 ms，发布控制器全反馈为200 ms；后者已用内存串口验证命令顺序、到位释放、超时释放及人工中断，未因此宣称新的实机动态结果。

## 实现与操作

1. Ctrl+U形成并静置后，两端短时预置实测角→使能→目标归零→失能；承载目标保持。`END_ZERO_ON_U=False`可关闭，空格终止并释放两端，X全部失能。
2. Ctrl+5选择自动ARC→Helix，G连续或J单步。自动调长之后先完成前部螺旋，尾部保持失能。
3. 观察前部搭稳后L确认，再G执行原回卷。若在`front_finish/front_seat`提前L，确认会记住，J/G完成曲线衔接后自动接回卷；不会将尚未统一的前部永久冻结。
4. 回卷顺序为接管切线弧及直尾、缩短直尾并推进前部相位、消去切线弧、恢复半径和统一全身Helix。完成后保持。5不执行T管解旋；6接后续流程。

完整按键和参数见[操作说明](../../../docs/ARC_Helix与重力矩越障操作说明.md)。修改只在本地提交；真实硬件效果交由用户验收。

## 失败复盘与数量

本轮并非只有三条成功记录。共有20次入口运行（其中1次为嵌入核心复验），另1次成功状态续跑、6次半径对照、8次归零候选／对照（4次为有效最终对照）；不把失败或重复候选从测试数量里删掉。

| 记录 | 问题与判断 | 处理 |
| --- | --- | --- |
| round1–2/basic5 | 强行改前部预算／形态后达不到支撑评价 | 未发布 |
| round3/basic5 | 观测窗口7关节与参考6关节反复重规划，350 s仍未完成 | 修正后继续核对，最终放弃这套前部重写 |
| round4/basic5 | 前部实际已绕约一圈，但接触索引跨度门槛阻止确认 | 分开检查形态、接触与持续性，不用索引跨度替代承重 |
| round5/basic5 | 实测残差直接拼入长前部，出现头／中段接触 | 未发布 |
| round6三直管 | 扩展前部预算版本直管成功，但T管头／后段干涉 | 不能以三直管通过发布该版本 |
| round6–12/buffer6 | 加长前部、额外引导弧、归零、相位与螺距修改仍出现头尾干涉 | 保留失败，不采用160 mm螺距等候选 |
| round13/buffer6 | 恢复已有前部准备，仅替换回卷入口后消除已知干涉；卡在后续对准 | 初次回卷有效；完整T管仍未通过 |
| final三直管／embedded/basic5 | 最小改动方案均形成实际全身Helix | 同步发布 |

原因判断：长前部重写扩大了扫掠空间，并重复计算了源回卷已包含的过渡材料，导致与失能尾部干涉；多种相位／螺距候选仍失败，不能把原因单独归给某个相位。最小复用方案消除这些已知失败，支持“前部预算重复及入场改动过大”的判断，置信中等。没有证明其排除了全部可能失败。

本轮前部重写探索超出了最小改动需要，产生较多失败复现。后续不沿失败的扩展预算继续叠补丁。下一项最小验证是用户在新机械实物上检查归零、前部支撑及接原回卷；若继续仿真T管，优先核对本次`align`未确认的具体姿态与操作者判据，而非再次改动已通过的送尾曲线。跨管径最优半径需另行设计受控速度试验，不由本次数据外推。
