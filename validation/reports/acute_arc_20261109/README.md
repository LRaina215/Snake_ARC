# 18 关节竖直转水平急弯对照

**全身使能的 Helix 越过了两种 110 mm 管径的连续 90° 急弯。**原 A 组沿用了局部保留 1.5 圈的退尾逻辑，J16–J18 在跨弯时失能。原记录仅代表局部包绕版本。更正后 A 组 18 个关节持续使能并跟踪整条带螺距曲线，在 105 mm 中心线半径短弯和纯斜接弯上都完整越弯并续行至少 72 mm。B 组仍未完成整圈 ARC 越弯和 72 mm 续行的组合目标。两种场景均不能用于证明切换的必要性。

## 模型和控制输入

- 固定 18 关节，头端、相邻关节和尾端间距为 25、72、91 mm。质量 2.584 kg，管径 110 mm，沿用摩擦系数 0.5、原驱动限位及阻尼。相同场景的 A/B 从同一个保存的 MuJoCo 积分状态分支。分支前共同竖直 Helix 实际上行约 140 mm。
- 纯斜接弯复用仓库两块 90° 斜接网格并等比缩到 110 mm。修正后直管端面与斜接网格边界吻合，入口 `z = 1.727 m`，出口 `x = 0.146 m`。另建半径 105 mm 的短弯，入口 `z = 1.768 m`，出口 `x = 0.105 m`。选取短弯是因为实机参考在播放约 10–13 s 可见一小段转向区，单机位无法反推其半径。该模型是近似场景。
- 控制周期 20 ms，角反馈周期 200 ms。两组都从实测角拟合竖直 Helix，并用公共 `CurveGait` 积分和预置。更正后的 A 组整条参考曲线保持 130 mm 螺距和全身使能，过弯时调整弯轴。B 组以材料弧长拼接包绕、肩部过渡和自由尾段，交接使能并缩小轴向错位。展宽、短头部引导和曲线压缩都在参考曲线上完成。仿真真值只用于评价和模拟操作者发出一次入弯命令，接触力、根位姿及实际位移未参与连续控制。
- 出弯按实际碰撞外壳最末点、实际网格边界和水平管支撑判定。续行固定跟踪出弯时环上的同一组实体连杆。预定整圈判据为包角 325–395°、轴向跨度不超过 100 mm、拟合面 RMS 不超过 27 mm，径向最大值小于 170 mm。弯中用实际包绕段拟合面与实际管道中心线的交点估计绕管角，竖直和水平直段直接用管轴。全程保存状态间隔 50 ms。

## 每轮复盘

| 轮次 | 假设与实际结果 |
| --- | --- |
| 01 | 首次 A/B。1.055 圈、半径 94 mm 的 B 组在竖直段撤去余下支撑时失载。局部 Helix 到弯区停滞。事后发现直管端盖深入斜接网格，本轮只保留弯前失载证据及原始状态。 |
| 02 | 将 B 的保留材料提高到 1.12 圈，参考半径收小 3 mm。弯前承载恢复。弯内出现约 5.7 kN 的接触法向力总和和 125 个自接触帧，且此时模型还有直管与斜接网格重叠。即使全身离开，也排除为跨越证据。 |
| 03 | 恢复斜接原接缝位置后复测。峰值法向力回到约 320 N。B 能在弯前保持近一圈并爬升，进弯后环面多在竖直段的截面方向。局部 Helix 和 B 均卡住。 |
| 04 | B 在斜接处把一圈暂时展宽到椭圆以提供倾转净空。建立水平侧支撑前即失载触地，未越弯。展宽削弱了当时的夹持，这是结合接触时序的判断。 |
| 05 | 改用短半径连续弯。局部 Helix 卡在弯头。B 完整越弯，且出弯后产生了远超 72 mm 的实际平移。弯中构型打开至约 285°、轴向跨度达约 172 mm，续行也有跨度超限。 |
| 06 | 在纯斜接弯尝试把材料边界向尾侧移动，给前部留出 108 mm 的短引导曲线。环仍停在弯头下，出现 25 个自接触帧。单独增加前部引导不能解决此例。 |
| 07 | 短弯入弯时把参考轴向错位由 75 收至 55 mm。97.15 s 完整出弯，弯内最大跨度降至约 146 mm，包角最低仍约 302°，并在水平侧出现首尾邻近段自接触。 |
| 08 | 短弯进一步收至 35 mm，出弯参考回到 63 mm。弯中跨度降至约 133 mm，仍有约 302° 的打开和 6 个自接触帧。99.60 s 首次出弯后，尾端曾摆回出口面上游约 8 mm，首个跨过 72 mm 的原始里程区间跨过了这个失效时段。按重新计程后的独立复核，整圈续行只通过到 46.8 mm。 |
| 09 | 保持 round08 的轴向设置，只在弯区多分配约 57 mm 的包绕材料。出现首尾挤碰和失载，未出弯。此例表明继续增加包绕材料会引入干涉。 |
| 10 | 直接压缩弯区参考曲线沿截面轴向的坐标，再按材料弧长积分。弯中最大跨度减到约 121 mm，仍未达到 100 mm，且记录到 209 个自接触帧。按此控制继续调小轴向错位会受到首尾净空约束。 |
| full_helix_short | 修正短弯基线。沿用同一模型、起态、滚动速度和参考螺距，只取消局部化与退尾。全部 3822 个保存帧均为 18 个关节使能。62.25–68.20 s 出现 39 个自接触帧，完整出弯和首个 72 mm 续行均发生在其后。约 191 s 越过水平直管远端并触地。 |
| full_helix_miter | 同一修正应用于纯斜接弯。全部 3968 个保存帧均为 18 个关节使能。60.05–74.85 s 出现 194 个自接触帧，表明过弯虽可完成，弯内干涉明显。约 198 s 越过水平直管远端并触地。 |

本轮复核了出弯门槛、实际包角、轴向跨度、接触、失能和饱和，并检查主要运行的完整回放。两组在弯头和首个 72 mm 续行范围均没有地面支撑，B 组窗口外驱动力矩为零。round08 最大实测关节角约 87.7°，最大跟踪误差 25.9°，2720 个保存样本中有 2719 个至少一关节力矩饱和。模型在给定负载下的力矩余量不足。当前结果不足以外推其他起始相位、其他 Helix 方法、实机或自动归中。

若要验证步态切换的必要性，下一项最小验证是先核对实物弯件几何，并用全身 Helix 确认该几何是否构成可复现的障碍。整圈参考仍需把弯区包绕段与两端过渡段一起设计，先逐相位核对实体净空和可达曲率，再验证承载交接。

## 复现

在仓库根目录使用既有 `mujoco` Conda 环境。每次运行给一个新输出目录。

```powershell
conda activate mujoco
python validation/acute_arc_experiment.py --output artifacts/my_short_pair --scene short --reference-radius .13 --ring-turns 1.12 --ring-radius-delta -0.003 --duration 215
python validation/acute_arc_experiment.py --output artifacts/my_full_helix_short --scene short --modes helix --reference-radius .13 --duration 215
python validation/acute_arc_experiment.py --output artifacts/my_full_helix_miter --scene acute --modes helix --reference-radius .155 --duration 205
python validation/acute_arc_experiment.py --output artifacts/my_short_arc --scene short --modes arc --reference-radius .13 --ring-turns 1.12 --ring-radius-delta -0.003 --corner-pitch .035 --exit-pitch .063 --duration 136
python validation/acute_arc_experiment.py --review artifacts/my_short_arc/arc
python validation/render_vertical_arc.py artifacts/my_short_arc/arc --speed 4
```

原始模型、参数、实测状态、目标、角反馈、使能掩码、力矩和事件保存在本机 `artifacts/acute_arc_20261109/`。`run.json` 为运行时记录，`review.json` 用同一版判据离线复核。结论以复核结果为准。实机和现有热键入口未修改。
