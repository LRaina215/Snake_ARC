# ARC、主动调长与 T 管模式切换验证

本轮假设是模式4的缓冲使能不能代表承载 ARC，切换时应从最新全身角度重新识别圆弧。Ctrl+5 与 Ctrl+6 共用前卷和卷尾过程，前部成形后等待操作者确认实际搭稳，再开始尾段使能与 Shift Rolling。

固定 18 关节、64.5 mm 间距、主管直径 110 mm、T 支管直径 60 mm、摩擦 0.5、限矩 2.355 N·m。控制周期 20 ms、全身读角周期 200 ms，使用实机入口和二值使能。仿真接触、位置只在试验脚本中充当操作者确认与评价真值。实机接触和支管方位仍由现场确认。

第一轮六例，覆盖基础 ARC→5、模式4正向调长→5、反向调长→5、带缓冲 ARC→6、5 完成后→6，以及改变初始相位的→6。每例保存完整实际状态、目标、使能、力矩、热键指令和阶段确认。失败后按原因修复，再重跑失败例及相关回归。

验收要求实际前部先形成主管支撑并稳定至少 0.4 s，然后才允许尾侧接入。模式5须形成前后都贴管的完整螺旋并保持 3 s。模式6须保持右 U 的正确搭管方向，尾部失能力矩为零，逐节回卷，整身清障后持续贴管滚动至少 10 s。还检查全过程落地、限位、限矩和移窗交接。自动调长阶段保留开放圆弧。只有真值形态与支撑通过才记为通过，控制器进入完成阶段本身不足以证明通过。

运行示例在项目的 `mujoco` 环境中执行。

```powershell
python .\validation\mode_handoff_experiment.py --case basic5 --output artifacts/mode_handoff/round1/basic5
```

## 修复与复盘

共保留 8 轮、31 次物理运行记录，原始失败同样在 `artifacts/mode_handoff/round*/`。每轮针对已知失败或相关回归，最终版本覆盖下面九种条件。

- 模式4实际使能会包含展直与交接缓冲，已复用全身圆弧特征选择器重新取承载弧。Ctrl+5、Ctrl+6 选择时保持原状态，首次推进时用新读角再次规划。
- 模式4结束后约半圆的转角常分布在七个不均匀关节上。直接按均匀幅值接到螺旋会改变支撑弧半径。现在用实测截面拟合半径和各交替关节族的总弯曲，选择接近该半径的曲线参考，重叠接管、渐变成形后撤掉缓冲。
- 只要求“头比尾短”不足以保证前端能绕管。现在按半圈螺旋弧长计算前端所需材料长度，过短先调长，过长则向适合起卷的长度调整。
- 固定内扣 10 mm 能改善部分短前端，但会改变原 T 管起态。已改为先用原半径前卷。跟踪稳定后暂停观察，按 L 确认搭稳才能送尾。若尚未搭稳，继续 J/G 每次增加 2.5 mm 内扣，最多 10 mm，目标仍沿同一条拼接曲线生成并限速。原型中固定内扣的失败记录保留在 round5。
- Ctrl+5 与 Ctrl+6 共用这一流程。Ctrl+5 在完整 Helix 成形后保持；Ctrl+6 接着对准、解旋、失能和回卷。仿真手调入口也转发同样的 Ctrl 热键。

首轮有一例在对准阶段保持，原因是实验脚本漏发继续滚动命令。另一例最终 Helix 被“前6节必须有接触”的编号判据排除，实际前一圈在 L8 承载，整体两圈均贴管。现按前后螺旋区间与完整包绕形态验收。模式4→6 的接近过程较长，330 s 记录到时尚在对准。延长观察并按实际螺旋方位确认后，完整越障通过。实验脚本对准时的头端角范围从 90–108° 改为 90–130°，右 U 必须实际搭稳、尾部落向轴下和清障后持续滚动的验收保持执行。

最终九例的第一笔卷尾使能均在前部真实支撑持续确认后发出。完整 Helix 按控制时间保持 3 s，T 管组整身清障后连续滚动 10.5 s。最终版本全过程无落地，失能关节执行器力矩为零。模式4 J→5 有两帧（50 ms 采样）主管承载力接近零，相位变化的→6 有一帧，随后恢复，最终保持或持续滚动段均承载。部分关节到约 90.08°，接近模型 ±90° 限位，且仍有较多限矩采样；两侧长度变化较大的切换和回卷速度仍慢。

另用当前默认 20 路配置走通内存串口的完整热键链路。输入 J4–J16 使能、弯曲集中于 J9–J13，选择器取得 J9–J14 的六节承载弧，再按当前形状自动调长。Ctrl+5 完成后 Ctrl+6 可接入；释放报文保留前8路，其余12路关闭扭矩；Ctrl+X 可全部失能。记录在 `artifacts/mode_handoff/protocol_check.json`。该项验证协议和控制状态切换，硬件动力学效果交由用户实测。

这些是使用操作者确认的仿真结果。角度反馈能重建形状、规划移窗和生成曲线，实物支撑由操作者观察后按 Ctrl+L 确认。当前满足所列条件下的阶段切换与先前后尾目标，实机与其他管径、摩擦和任意起态待验收。下一项最小验证是按这套同键位流程在实物上分别检查一次模式4→5和5→6。
