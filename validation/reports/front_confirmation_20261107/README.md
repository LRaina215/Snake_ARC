## 修改

1. `front_finish`、`front_seat`、`front_hold` 接受操作者的实物搭稳确认；自动暂停、锁定当下已发前部目标、进入 `first_shift`，确认本身不新增使能或下发运动。没有用关节跟踪误差证明实物支撑。
2. 已在 `first_shift` 时重复L不重建曲线、不重置位移、不改变任务运行状态。
3. 未确认的 `front_hold` 保持前部，不再因J/G继续旋转；提示明确写出当前阶段和下一步。
4. 送尾仍按实测曲线平移并逐节接管，已确认前部保持原目标，接管完成判断只检查接入尾部，不再要求锁定前部追踪另一条名义曲线。
5. 实机与MuJoCo手调共用上述逻辑。最近16条命令的时间、结果、拒绝原因和前后阶段进入JSONL。
