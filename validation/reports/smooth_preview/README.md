## 发现的问题与解释

控制器的`target_geometry`是开放约束处理后的候选，最终下发还需滤波/限速。因此目标平滑与已发目标折线可能不重合，这属于不同计算阶段；图例明确“滤波前”与“已发”。实测平滑也不是穿过所有关节的样条，而是直线/相切圆弧的连续截面近似，和真实连杆折线有所偏离是该几何方法的结果。以上含义由当前调用链确认，不将差异全部称为跟踪误差。

控制缓存可以晚于显示所用的当前读角/目标更新；显示缓存编号，不重新计算成看似最新的控制输入。两条缓存曲线分别来自控制的截面拟合，先依据各自原点/基底恢复到同一头部坐标，再使用共同显示投影；没有为凑重合另做平移或旋转。Z截面仍隐藏面外偏差，应结合右侧已发目标角差判断。
