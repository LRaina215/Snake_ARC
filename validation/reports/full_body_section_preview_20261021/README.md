# 全身截面与重力定向预览

本轮只修改完整实机入口的只读预览；MuJoCo手动入口共用该预览。不新增动力学实验，不连接硬件，不修改控制目标、使能或模式。精简版入口仍不打开预览。

## 检查计划

假设：原图缺少失能关节源于按窗口裁剪，转动源于拟合基底未定向。固定已有角度、目标、使能及控制截面，只改变显示范围和截面平面内方向。

验收：完整显示J1–J20及两端点，按实际使能掩码着色；目标与实测共用控制截面，平滑曲线原始数据不变；估计重力投影朝下；拟合基底任意转动或翻转不引发画面转动、镜像；重复与陈旧反馈不推进重力估计。方向不可用时明确提示并保留已有方向。

仅回放既有25秒仿真记录及已保存实机角度记录，另作独立显示进程启动检查。回放不等于实机显示已经验收。运动形态、支撑、力矩等不作为本轮显示修改的通过结论。

## 结果与复盘

- 已有25秒仿真记录125个新反馈、实机任务19的188个新反馈全部完成全身坐标与标签检查；均显示20关节及两个端点。实际掩码逐关节着色，无裁剪窗口外的关节。
- 仿真记录122帧使用双侧方向、3帧单侧暂用。该实机任务188帧均只有尾侧观测合格，不能写成实机双侧融合验证通过；界面明确标为单侧暂用。两侧均不能给出有效方向时保留历史方向。
- 重力只决定原控制截面平面内的转角，没有改换截面平面；每帧核对平面投影矩阵、控制实测平滑曲线投影及向下分量。另有3项软件检查，覆盖拟合基底旋转/翻转、重复/陈旧反馈、关节颜色与控制状态隔离。工作树和实际D盘入口的检查均通过。
- 单文件复制到仓库外后，独立进程可启动、绘制、关闭；使用内存串口，硬件连接数和使能写入数均为0。精简版无预览，未修改。

示例：[实机角度重建](real_pose.png)、[仿真8秒](simulation_8.0s.png)、[拉动中11.8秒](simulation_11.8s.png)、[恢复14秒](simulation_14.0s.png)、[末态24.8秒](simulation_24.8s.png)。截图来自原始反馈，不是目标动画。仿真存档没有保存滤波前候选曲线，本次回放没有伪造洋红候选；实时入口仍显示控制器实际提供的实测与候选曲线。逐帧数值见`display_replay.json`。

**发现的问题与证据：**

1. 原实现以`window[0]-1 : window[1]+3`裁剪，直接使用拟合基底，且没有调用已有重力估计器。这能直接解释少关节及无重力定向，原因判断置信度高。
2. “所有关节完全共面”不是编码器记录支持的事实。首个实机示例的最大面外距离约49.6毫米；现在显示完整投影并注明面外距离，没有强行拉直失能段。估计重力也不是IMU实测，无法凭关节角排除两端共同摆动或整身刚体转动。
3. 复用旧控制器重算回放时，2.02秒出现最大目标差0.001048 rad，已保存在`control_recompute_attempt.json`。差异发生在绘图调用之前，不能作为本轮显示失败或改变控制律的依据；具体旧控制版本差异本轮未追查。改为直接读取存档角度和控制截面，在缓存真正更新的时刻恢复原坐标基底，避免把两个不同时刻的角度和截面硬凑在一起。

**验收范围：** 显示范围、颜色、平面内重力定向及状态隔离检查通过；未连接真实舵机，没有新增运动能力或精度结论。下一步仅需用户重启实机入口，观察真实姿态与预览是否一致；若仍不符，用对应原始读角记录定位，不追加无目的实验。
