# 2026-10-21：主动送链失能段自动选择修复

已在研究核心、实机单文件和仿真手调入口同步。控制输入仍只有全关节角、机械尺寸、采样时间和使能范围。此次未连接硬件、没有新增动力学；实测日志是用户已有运行，新的命令只是离线计算。

## 假设、范围与实现

[事前计划](../../../docs/主动送链失能段选择修复计划.md)。旧方法固定取两端最末3连杆，实测初始头/尾直线度0.9771/0.8621均低于0.98，导致准备结束仍无长度基线。新方法保留0.98门槛，搜索当前两侧失能区的连续3～5连杆，要求至少3个新样本、跨越0.4 s、内部关节角最大变化≤3°；端点低于估计顶部至少2.5平均连杆长，所选区段低于估计顶部至少0.5平均连杆长。

选中区段仍符合条件则保留，避免因重叠候选质量轻微变化而反复切换。两侧夹角≤25°时按段数×直线度加权融合；仅一侧可用或两侧冲突时明确标注所用单侧，不悄悄平均冲突方向。启用范围改变后重选，原区段不再参与候选。历史只累计新采样时间，超过0.6 s间隔重新收集。

稳定性是固定材料区段的内部形状稳定，不比较不同时刻头坐标中的方向，避免把头坐标变化误判为方向变化。这仍是假设自由悬垂区段指向下方；不能仅凭几何断定重力、世界姿态、无外物接触或真实卸载。

## 发现的问题与修复

1. 固定末端选择排除了存在可用内侧区段的真实姿态，证据为旧/新同角反馈比较，原因明确。改为搜索和保留可用失能区段。
2. 新稳定观察需要短历史，第6秒恰好不稳定时，旧准备逻辑立即报错。现在在原`maximum_untrusted_s=3 s`预算内等待恢复，默认最晚约第9秒仍无基线才保持；没有无限等待。任务18及合成边界检查覆盖此问题。[初轮回放](round_01_real_replay.json)保留：该初版工具曾在报错后继续计算，故其中后续基线字段不是成功证据，最终工具已在故障处终止，并修正暂停元数据口径。
3. 若只在运动更新时积累稳定历史，用户慢速按Ctrl+L会反复因样本间隔超限而无法推进。暂停/保持期间现在随全角新反馈更新观察器；目标、使能、材料位置与基线保持不变。2.4 s暂停采样及随后单帧检查通过。
4. 新旧控制输出有小幅差异，旧“与存档目标一致”测试不能继续冒充当前物理验收。测试改为明确报告存档差异，只断言当前研究/嵌入一致与协议范围；原始成功数据没有覆盖或改写。
