# 停止滚动、纯平面主动送链：2026-10-14

已验证：不推进滚动相位、也不依赖沿管前进，边界弯曲交接能让一侧实际缩短、另一侧实际增长，然后反向回调。修复例去程头侧−66.50mm、尾侧+75.05mm，身体平均位置沿管最大偏移仅.091mm。

尚未实现：承托区空间位置固定，以及冠部材料位置到达目标后稳定停止。支撑点最大三维偏移仍18.28mm，去程观察3s结束时真实冠部超出目标.478关节。两例均未满足本轮全部验收；不能把 `task_complete` 当作原地控制通过。原地≤5mm是本轮事前提出的目标，不是用户提供的精度要求。

## 方法、条件与输入

事前[主例计划](../../../docs/原地送链实验计划.md)和[唯一修复计划](repair_plan.md)保留。主例1次40.84s，定向修复1次49.64s，结束后只读复盘，没有第三次动力学或实机实验。

控制器固定phase=0。主例的J7–J13局部目标是J7=60u、J9=60、J11=60、J13=60(1−u)，偶数关节保持0°，其余关节主动失能。边界交接使弯曲沿材料移动，u由角度重建的条件性冠部误差驱动，观察阶段也继续调整。初始6关节，送链后保持7关节局部区，允许停在分数进度，没有强制跳到整数窗口。不是自动管径顺应，也没有名义恢复项。

唯一修复把预设总转角180°改200°（各基本弯曲66.667°），u速率上限.12→.06/s、位置增益.3→.15/s。两项一起修改，初始构型也变化，只是功能修复，不能归因于某个参数或宣称同初始状态的效率提升。

实际模型元数据：水平直管中心线x=−1.2…1.8m、y=0、z=1.2m，半径.0565m，即直径113mm；20关节、21根64.5mm连杆，初始沿管x=−.5m。摩擦[2,.005,.002]、重力[0,0,−9.81]，Kp127、Kd1、限矩2.355Nm、被动阻尼1.5、armature .01，均沿用原场景。物理1ms、控制20ms、编码器反馈200ms，使用既有Conda `mujoco` 环境。

控制输入仅全关节角、反馈时刻及控制时刻。接触力、真实管径、世界位置、根部姿态均未传入控制器；没有外加拉力、根部固定、位置重置或修改摩擦。失能区主动执行器矩为0，但模型仍有机械阻尼，尚未标定为真实舵机失能的等效动力学。

这里“头/尾长度”是实际骨架在管轴高度两侧穿越点到端点的材料长度，不是依赖使能边界计数，也不是准确的接触脱离点。两侧变化不严格等量，管轴上方弧长也会改变。修复例净转移70.77mm约1.10根连杆；这支持实际调长效果，但不能替代事前的冠部定位验收。

“支撑点”是实际机器人—管道接触位置的竖直支撑力加权均值。力分配改变也能使它移动，不等于同一个接触点的滑移。最高带和身体平均位置也有横摆，因此空间失稳不能只归结为加权指标抖动。质心表格实际使用骨架点平均位置，并非质量加权质心。

两例观察器始终给出可用判断，但对真实最高带材料位置的RMSE为.215/.162关节，最大误差.563/.367关节。主例14.4s、修复19.2s报去程达标时真实误差分别−.137/−.070关节，之后观察3s仍继续偏移到−.649/−.478。**只看达标瞬间或最后返回残差会漏掉去程过冲。**

所有阶段、全部2042/2482帧实际状态及每1ms限位/失能/饱和/落地统计已检查；查看完整时间曲线、从启动到返回后的全部分镜及最差绕管状态。没有声称逐帧人工观看视频。该场景无障碍、无滚动推进，越障后持续运动不适用；两次都有去程和返回后的3s实际观察，不增加长hold。未做能源评价。

## 形态审查不能混淆的指标

平滑截面转角和开口满足事前150–218°、开口≥.4，整体保持开放，没有形成闭合螺旋；这不等于所有绕管角指标通过。

旧使能端点绕管角最大237.96/250.19°。同时，另一个不依赖使能掩码、按实际相邻转角>5°选弯曲区间的管心极角最大273.34/244.85°，同样超过218°。其最差时刻是7.56/25.24s。[主例最差实际截面](main_20261014_014331/worst_pipe_wrap.png)和[修复最差实际截面](repair_20261014_015043/worst_pipe_wrap.png)显示，低角度的边界及直线段也可能扩展极角区间；不能把所有超限都解释成使能掩码变化。指标定义不同，需要区分真实折弯总角、截面开口和绕管极角。严格“全过程接近贴管半圆”的历史标准仍不能报通过。

## 原因判断与下一项最小改进

较高置信：固定中部关节角只是固定相对形状，没有固定承托弧的空间位置。两侧重量分布和边界形变改变时，承托弧仍会倾摆，记录直接显示这种现象。

中等置信：边界送链较快、角度观察器使用悬垂方向的条件估计及接触重分配共同造成去程迟停和过冲；本轮没有逐项消融。放慢并加承托余量减小了部分摆动，却仍失败，不宜继续单纯放慢。冠部最高带位置本身也随形状变化，不应直接等同于真实送链量。

下一项建议是**几何约束的交替承托送链**，不加入管径顺应：允许中部弯曲一起协调，先由一侧局部承托保持开放弧，另一侧边界收放；新承托形状接近目标后交换角色。以角度重建的两侧材料长度差及其变化率作为停止判据，冠部只作辅助，避免移动到目标就立刻报完成。每步限制实际开放弧形状，不能通过继续包紧来换固定支撑。初始目标几何可由实测截面建立，但接触“不滑动”只能是规划假设，不能写成已观测卸载/锚定。

仅编码器及条件性重力方向不能直接观测刚体平移：整体平移而关节角不变会给出相同反馈。因此可以尝试用几何/接触动作减少位置漂移，不能宣称已实现世界坐标位置闭环。如果继续，只安排一个同管径、同起态的往返病例，优先复现去程过冲和横摆；本轮到此停止，不扩大管径、急弯或长时间测试。

尚未验证不同管径/摩擦/弯管、从初始构型先向尾侧送链、连续多次调长、结束后的长期稳定及实机效果。代码中的正方向只做了软件动作检查，不作为尾侧起始动力学通过。
