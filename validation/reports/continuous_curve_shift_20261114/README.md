# 连续曲线移位调长

首轮假设：在固定弯曲形状下，仅移动直线和承载弧的分界也能靠角反馈完成双向调长。沿用18关节、110 mm水平直管、原舵机约束和被动阻尼，使用同一初态。改变目标生成方式，控制器只读角度与时间，世界骨架和接触用于评估。先做Ctrl+4约一个轴距的去回，再做确实进入自动预调长的Ctrl+5，并复核Ctrl+7能否归中并交回基础ARC。按各实验已有判据检查开口、实际长度变化、支撑、碰撞、限位、失能力矩、交接与出口状态。原始仿真保存在本机 `artifacts/continuous_curve_shift_20261114/`。

## 源码审阅

附件 `水平管滚动步态切换.py` 用 `s_h` 平移关节积分区间，用 `Helix_Length` 改变中间螺旋段长度。它的串口和热键代码用于该文件自己的实机入口。本次复用几何关系。

11月8日的 Ctrl+4/5/6 从两个离散窗口构造曲率分布后插值，Ctrl+7 才通过改两条直线长度移动整个半圆。现有三条路径共用 `FeedingCurveBuilder.plan`。参考曲线在任务开始生成，位移为 `d` 时头侧直线长加 `d`、尾侧减 `d`，各中间曲线段的长度、曲率、扭率及任务相位固定。拼接边界随位移连续经过两相邻连杆的积分区间。程序不再从相邻关节窗拼出过渡曲率。

Ctrl+4 用角反馈的悬垂长度估计决定移位量。试过将一次请求直接换成同等曲线位移，真实悬垂变化反而偏小（72 mm 的反向任务仅变化46.2 mm），因此恢复长度闭环。Ctrl+5/6 预调到材料坐标指定的位置，Ctrl+7 根据两侧估计长度差归中，三者走同一个连续曲线生成器。

## 仿真结果

实际场景主管外径110 mm，沿水平轴，18关节模型的各段为64.5 mm。Ctrl+4 试验按模型几何设定最后一轮任务量64.5 mm，反馈周期0.2 s、目标周期0.02 s、物理步长0.001 s。接触、世界骨架及外力只用于评价。Ctrl+5 和 Ctrl+7 分别从ARC与Helix起态运行，各以1倍切换速度验证。

| 病例 | 实际结果 | 验收 |
| --- | --- | --- |
| `manual_checked` 中间往返 | 两次目标±64.5 mm，实际+70.06 / −54.11 mm。上弧转角175.47–180.69°，最小开口比0.586，轴向漂移0.087 mm | 通过既有各项判据 |
| `boundary_checked` 短端边界反向 | 保持开放并反向，上弧179.27–197.16°，最小开口比0.416。实际77.74 mm，误差+13.24 mm | 反向和形态通过。±12 mm精度未通过 |
| `full_stroke_06` 两端及回中 | 同一次物理过程到达两侧曲线位置边界并返回初始曲线坐标，282.12 s。最小开口比0.413，上弧173.38–216.12°，轴漂移0.310 mm。最终实际两侧长度差48.80 mm | 行程和开放形态通过。最大单段误差27.07 mm，4个采样承托力低于0.1 N，精度和连续承托未通过 |
| `five_01` 自动预调后成Helix | 进入公共调长并实际经过预调，前部搭管后送尾。末段至少1.978圈，送尾期间前端实际前进182.12 mm | 通过该代表场景的成形验收 |
| `seven_01` 解缠、归中及续行 | 回到基础ARC，出口包绕176.92–181.78°、截面平面RMS最大11.71 mm，续滚6 s推进123.48 mm | 开放、归中及续行通过。全记录有1个近零承托采样、36个饱和采样 |

终版 Ctrl+4 三例均无触地、自碰撞、限位超出或失能执行器输出。全行程的最大跟踪误差1.56°，限幅力矩占所有关节物理步0.0104%。全行程末尾3 s内实际半长度差仍变化约6.75 mm。Ctrl+5 的84个采样存在力矩饱和，保存帧无自碰撞或触地。中间往返的最大骨架折线曲率16.39 m⁻¹，短端16.28 m⁻¹，全行程16.38 m⁻¹。查阅了全时段数值及斜视、端视序列。

## 问题与复盘

- 单用材料移位无法消除滑移和余段摆动造成的长度偏差。末轮全行程最差的任务中，角反馈认为变化64.03 mm，世界骨架切片测得91.57 mm。误差主要出在用下垂段估计方向和截面切片来代理实际悬垂长度，尚未分离各自贡献。
- 全行程前三次在可用悬垂参考丢失时停住。日志显示，失能端点弯折曾让旧掩码把中间已展直的关节一起维持使能。修订了退出及折弯接管，保留两侧可用的失能参考。第5次走完整段，但预留参考时曾排除仍在重建上弧里的关节，最小开口比0.350。终版优先保留曲线覆盖和实测上弧，开放形态重新通过。
- 末轮偶发承托采样为零，未观察到持续下滑或落地。现有数据不足以确认每次零承托的持续时间和成因。下一项最小验证是在短端交接和中间反向处，核对角度方向估计误差与力矩、支撑变化是否同一时刻发生。
- 本次验证覆盖水平直管、当前18关节模型和上述入口，实机与Ctrl+6完整越障仍待验证。保留全部尝试，包括未通过的精度、观察器和形态运行。37项针对软件检查通过。
