## 场景、输入与证据

新记录`physics/display_pull_20261013_165050_222158/`保存原始状态、qpos/qvel、目标、掩码、实测反馈、外力、事件和参数。核对模型数值：直管中心线沿X，高1.2 m，半径0.0565 m，即直径113 mm；非变径或弯管。本轮控制保持v3，初始J8–J13，物理1 ms、控制20 ms、实际读角200 ms。

10–12 s对头端施加总量4 N、向外/向下的力，随后持续运行13 s。该外力是本轮专门加入的仿真扰动，不是失能关节正常重力的替代描述。失能意味着主动驱动力矩为零，模型仍有重力和机械阻尼；阻尼未做实机标定。

估计器只接收实测全角、窗口、采样时间及尺寸。保存的根四元数转换出的真实向下仅用于评价。全部125个新反馈与既有640个反馈参与复盘；完整物理轨迹1251态，并保存25000个物理步的汇总检查。完整视频位于本机`validation/results/physics/display_pull_20261013_165050_222158.mp4`与`validation/results/gravity_preview/gravity_aligned_preview.mp4`，可由渲染脚本从存档重建，不另跑动力学。

**若把12°要求扩展到包含外力的整个新例，则不通过：** 全程双侧合格区95分位12.35°，保留在JSON的`full_run_dual_p95_under_12=false`。本轮`passed`只指计划中的正常精度、无翻转和恢复范围；没有改变算法或放宽12°阈值。冲突提示是几何一致性告警，并不覆盖所有不准确时刻。

### 主动发现的问题与原因

1. 11.2 s两侧各自对真实向下误差约27.44°和4.91°，融合仍显示双侧合格且偏差15.26°；11.6 s后才触发冲突。原因判断可信度高：被拉的一侧仍较直，方向差尚未超过25°，仅形状无法判断哪侧是真重力。不能把“双侧融合”解释为精度保证。
2. 历史滤波没有表现出统一的消抖优势。新例相邻世界方向变化95分位为2.68°，瞬时融合为2.24°；既有记录分别2.80°/2.46°。新例双侧误差95分位为12.35°，瞬时融合11.96°。合理解释为滤波滞后和端部坐标条件性传递的误差；本轮不进一步调参，也不宣称滤波全面更好。
3. 两侧同时摆动、短端均不可用、整身刚体转动不能凭关节角保证重力准确。这里是可观测性边界，不是本轮已经验证通过的场景。
