假设：自动滑窗的开口方向门槛形成旧窗口依赖；主动送链的弯折邻域以不断扩大的实际圆弧/掩码为中心，逐轮接管远端，耗尽失能参考。

固定条件：使用 2026-10-21 14:46:23 实测记录，全关节角、掩码、时间和已发目标；不读取接触力或世界姿态，不连接实机。保持 K=.02 的实测截面控制，不增加名义恢复项。

变量：运行中方向参考/失配重新定位及交接；送链必需掩码与多余缓冲释放。

验收：先复现两处阻塞；实测输入重放能输出有证据的重定位并完成受速率限制的交接；主动送链释放无弯曲任务的远端缓冲，不把使能直段当重力证据，恢复有效观测与相对任务；双向请求、失能掩码和目标连续性回归。仅有限软件/重放检查，不把固定记录、理想跟踪或内存串口认作实机闭环、支撑或开放形态通过。恢复过程中实际形态/承重由后续实机验收。

## 最终实现与原因复盘

用户进一步要求统一特征识别，以及模式4不得重建当前半径。最终由 `snake_control/feature_arc.py` 统一提取全身实测圆弧，供初始选窗、4→3、运行中定位和送链使用。依据为重建曲线的开放转角、覆盖和拟合；两侧方向、已知送链弯曲分布和历史位置用于区分候选，不是发现圆弧的前置条件。不输入接触力、真实管径或世界姿态。

确认并修复的原因：

- 截图对应的J2–J6开口反向，旧方向门槛否决尾侧，局部观察又没有搜索远处圆弧。独立失能段方向与共同特征识别现在将该姿态定位至J8–J12。不带方向时旧主动圆弧仍是候选，因此不能把“有圆弧”当成测到了管道接触。
- 最新送链卡在位置1.01595关节、J4–J19使能，尚未到[-4,6]边界。头侧仅3段且直线度约.907，尾侧仅1段。长度切片、扩大的捕获邻域与保留端折弯共同扩大缓冲，耗尽参考。现在长度切片不再兼任使能范围；采用统一识别出的弯曲段，捕获邻域不递归扩大，保留端/端点不参与捕获。无弯曲任务的外侧直段在目标与实测稳定后释放，参考丢失时也能恢复。未放宽.98直线度和5°跟踪要求。
- 模式1/3进入模式4后的首次任务，旧代码会重建60°/相位0模板。现在捕获实测特征段作为送链起态，沿材料坐标平移这个弯曲分布，保留两个轴族的角度分配总量，不重新规定半径。日志新增 `seed_source / measured_seed_deg / seed_turn_deg`。无seed构造仍供历史研究复现，日常入口不使用模板形成过程。双轴电机角绝对值之和也不再冒充实测种子的平面总转角。

4→3按实测圆弧接管、释放缓冲后再估计两侧方向，无需切换前存在合格失能参考。正常邻接移窗继续滚动。人工大幅挪偏后的远距离重定位暂时固定相位：新特征段以实测角接入，多余旧弯曲段限速展直并确认后释放。旧关节不跟随时不虚报完成。
