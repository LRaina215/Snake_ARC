# 三条完整热键路线演示（2026-11-08）

本轮按用户要求重新运行当前控制器，录制Ctrl+4→Ctrl+5、Ctrl+4→Ctrl+5→Ctrl+6，以及从ARC直接Ctrl+6的实际运动和完整按键记录。不是将旧成功录像换标题，也不将仿真阶段名当作实际形态通过。

## 开始前的安排

假设：当前共用实机控制器可通过相同Ctrl操作完成三条路线；需要分别核对模式4调长到模式5的交接、完整Helix接6，以及ARC直接接6。

固定18关节、64.5 mm旧轴距、110 mm主管／60 mm向上支管、原摩擦与限矩；20 ms控制、200 ms全身读角、50 ms实际状态保存。4→5使用直管；两条含6路线使用相同已有T管ARC初态，模式4演示用H调短头侧一次。世界坐标和接触仅作评价／模拟操作者L确认，不给控制器。

第一轮各跑1次。已知旧自动操作者还要求固定绝对电机相位，该校准依赖此前入场轨迹；本次保留真实构型／接触确认，移除绝对相位门槛。若运动失败，保留全过程，先分析具体失败再决定必要修复，不盲目增加重复。

验收检查开放ARC、前部搭稳后接尾、实际统一Helix、右U真实搭管、失能下落至轴下、回卷及整身清障后继续运动。每步检查非相邻碰撞，保存全部状态、目标、掩码、力矩、反馈和按键。视频显示当前阶段、按键时间与历史、使能、目标和实测角。失败路线明确标注，不剪掉失败拼接成功片段。

## 完整过程复盘

4→5：无非相邻碰撞／落地，失能驱动力矩为0，实际角不超过74.70°；纯送链和圆弧准备阶段近管覆盖最大235.88°，保持开放。覆盖角含近管肩部／切线，不当作精确半圆总弯角。最大跟踪误差8.18°，85个50 ms保存帧有至少一关节限矩饱和，不能称为全程无饱和。

直接6：检查了4941个实际保存状态；无运行时1 ms非相邻碰撞事件、无落地，失能驱动力矩为0。最终滚动实际最少1.975圈、最大离轴半径107.26 mm；清障后的210帧全部有主管／尾部接触，尾端继续前进215.4 mm，结束全身最小x=762.5 mm，高于409 mm清障线。实际角最大79.54°；613帧至少一关节限矩饱和，全程最大跟踪误差43.53°，所以通过单例越障不代表所有阶段轻载或无较大偏差。

直接6的右U在仿真t=152.24 s确认，额外保存的精确实际状态满足原释放形态：尾部质心y=−46.45 mm、尾端y=−245.52 mm、z=1187.07 mm，前部及U后段均与主管接触。释放开始时尾部绕管轴的重力矩约+0.648 N·m；失能尾段随后到轴线下方，尾段质心y≈14.45 mm、z≈874.23 mm，前部旋转约42.99°、头部前进约16.71 mm。后续再接原回卷完成清障。这里是重力矩，由模型质量和实际位置计算，不能解释成电机电能。

确认姿态持续时间可能短于50 ms普通保存间隔，单看相邻截图可能漏掉；本轮专门补存了按L前的实际状态。脚本每20 ms模拟操作者确认，结果依赖该确认时机，不能据此保证人工实机按键同样宽裕。没有把接触或世界位姿接入控制算法。

4→5→6失败：先完成了实际统一Helix，近管覆盖、前部后部交接、无碰撞及失能检查没有发现形态假通过；失败发生在后续U形成。无收紧时最终停在右U等待，600 s总时限内没有确认；收紧1 mm仍未形成合格右U，按实验等待上限停止。更严格头部方位对准未能找到可确认姿态，换成模式4的J方向也未解决。

因此原因不能简单归为“只要抱紧即可”。调长改变了接6的实际入场姿态；当前头部方位／接触的对准条件不足以保证后续U可释放，且U过程有较大角偏差和饱和。入场姿态、曲线平面与受载变形的具体贡献尚未分离，不能把其中任一项断言为唯一原因。

## 数量与保留的失败

共7次完整路线尝试：首轮三条各1次；直接6为补存精确确认状态再跑1次；失败的4(H)→5→6收紧1 mm重跑1次；收紧后改变对准条件及改用J方向各1次。见下表，不以最终只展示3段删去失败次数。另有2次从失败保存状态恢复的12.2 s局部收紧检查。

| 记录 | 改变项 | 结论 |
| --- | --- | --- |
| round1/ctrl4_ctrl5 | 基础4(H)→5 | 通过 |
| round1/ctrl6 | 直接6，去掉旧绝对相位门槛 | 完整通过；普通50 ms记录不足以逐帧展示临界释放状态 |
| round1/ctrl4_ctrl5_ctrl6 | 4(H)→5→6 | 右U未形成，失败；600 s等待已完整保留，后续改成有界等待 |
| round2/ctrl6 | 同路线补存精确L状态 | 完整通过，作为展示版本 |
| round2/ctrl4_ctrl5_ctrl6 | 初始用O收紧1 mm | 右U未形成，失败；作为展示的失败版本 |
| round3/ctrl4_ctrl5_ctrl6_H | 保留收紧，改用120–135°对准范围 | 实际头部只在约82–100°，60 s内没有可确认姿态，失败 |
| round3/ctrl4_ctrl5_ctrl6_J | 换为J调长方向 | Helix形成后仍未形成可释放右U，失败 |

局部收紧检查仅从失败状态恢复，不拼进主录像：4次O请求到90 mm，或6次O但提前L采用已执行到的88.4 mm，均未在保存状态中形成合格U；最大角跟踪误差约77.7°／75.5°，各219/245帧饱和。继续收紧没有解决问题，故停止扩大半径扫描。6次O例未到请求88 mm是提前L按设计取消剩余调节，不是偷偷恢复半径。

本轮已完成三条实际操作路线的录像和复盘，但**未实现4→5→6成功全过程**。下一项最小工作应从该失败状态核对U曲线相对主管的实际方向、承担载荷的关节及饱和，而不是再放宽释放形态判据或拼接成功视频。尚未验证新连接件实机、其他管径或任意两侧长度。
