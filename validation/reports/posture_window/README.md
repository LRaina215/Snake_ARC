## 新行为与局限

- 七关节作为稳定状态持续11.16s，而非6→8必须经过的交易；没有要求大管后回到六关节。已有6/8校准仅作为相位数据，新宽度几何残差迁移已在该七关节病例核对：55新角覆盖24相位格，位置误差≤.221关节。
- 直管19次无可信端的观测仍存在，策略此时保持窗口；不称所有短端全相位可定位。至少一个可信悬垂参考仍是假设，关节角不包含整体绝对朝向。
- 七关节数量代理6.68–7.91，末段仍建议扩大但未满足1s持续、没有创建交易。形态/支撑合格只说明本次选择可用，不能证明数量最优或长期收敛。
- 新策略没有实际缩小、回退、9以上支撑、双向返回或真实设备验证。7/9名义形态和机械软件检查不能替代那些动力学。
- 急弯764态单管轴不可测（508接触轴冲突），有效区无包绕违规；身体开放通过不代表严格整段管轴验收通过。

当前符合本轮两主例的目标；下一最小改进先对保存的七关节反馈审查数量代理的相位依赖，再决定跨相位形状余量是否必要。不为了展示更多数量增加仿真，也不根据基线已通过的场景宣称通过率或能效优势。本轮未测机械功/电能，不作效率结论。
