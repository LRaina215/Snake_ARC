# DIY调参接入修复

用户实测报告：70°固定顺应被名义开放约束阻挡，滑窗被60°/0.6冻结标定阻挡，更换初始关节数量后启动被归一化峰值速度检查阻挡。本轮只修复调参和模式接入，不开展新的动力学或硬件实验。

默认开启DIY_PARAMETERS。绕过幅值×频率/归一化峰值预检、档案±90°限制、实际/目标开放形态拒绝以及固定60°/0.6接入限制。顺应目标不再按原±90°和开口门槛截断。基本有限值、单圈编码范围、控制时钟与有效反馈、显式使能协议仍需成立；单圈范围是报文表示条件，不把越界取模成其他角度。

形成速度、静置、正常目标限速、顺应滤波仍可在顶部调节。本轮没有自动归零或改动这些参数。窗口外继续失能。顺应数学结构仍需J2..J19内至少3个连续关节及边界连杆；基础窗口可用J1..J20。不是任意无效几何都能计算顺应。

手调滑窗的ManualArcReference调用当前joint_angles_deg，按实际幅值/频率/窗口建立名义几何参考，数量比较也使用同一名义目标；不退回60°。GeneralPhaseReference在DIY路径不加旧标定残差，并在metadata标记未标定。自动交接仍由形状观测和相邻连续交接条件决定，未强制任意移窗。关闭DIY恢复原严格路径。
