## 修改和操作

1. 可达位置同时考虑完整弯曲分布与保留失能参考。默认J8–J13种子、尾参考可达位置区间为[-6,4]，头参考为[-4,6]；是内部材料参数，不是毫米或世界位置。偏置种子优先选择能保留全部初始弯曲关节的参考侧。任何请求需要在保留端弯曲时都不能静默删掉目标。
2. 到边界显示`boundary`并保持，同向再次按键不推进，反向可重新开始。没有把边界截停写成毫米任务成功。
3. 旧非法区或反向时旧跟踪误差超限，使用`reverse_recover`。从实测角到向内可执行姿态做限速过渡，按每一步已发目标检查5°误差，既不继续强迫旧终点，也不放宽门槛。恢复结束`recovered`保持，不计为64.5 mm到位；后续J/H继续长度任务。若新中间目标也无法跟上，仍有等待上限与保持原因。
4. 配置窗口独立保存在`configured_window`。自动移窗/扩缩只改运行窗口；X→U恢复顶部配置或用户明确设置的`window=a:b`。实机和MuJoCo各自使用原初始配置，不硬编码6关节。
5. 失能时Ctrl+3读取全身角，搜索任意机械可行宽度的连续弯曲段，比较开放形态、半圆覆盖和条件性下垂参考；已有使能时Ctrl+3仍切换自动滑窗顺应。选窗成功按实际角预置接管、平滑形成，再进入滑窗；直线或无法判定时保持失能，明确提示，不默认回到中间。自动选窗不会覆盖Ctrl+U配置。条件性下垂不是世界重力或支撑真值。
6. 同宽度移窗不再依赖圆拟合误差；仍检查截面几何、位置依据、退出角、目标连续性等。扩缩数量仍要求圆覆盖估计及多相位依据，本轮未移除这些条件，也未改成每按一次前进/后退就必定移窗。
