# 实际截面顺应与滑动窗口：本轮冻结计划

用户授权：先实现固定6关节窗口的选取、相邻迁移和交接；只有证据表明固定宽度不能兼顾承重与开放形态，才自行开发扩缩。仅仿真与本地commit，实机文件不修改。此前遗留修改不纳入本轮。

## 控制与评价边界

- 截面顺应复用Python实际关节角→正运动学→局部平面→连续线圆弧→Yamada积分。截面模块不读取管道半径、中心线或接触。
- 窗口定位先使用MuJoCo接触的向上承重分量。这是仿真中的理想观测原型，不声称实机失能关节能够取得同等反馈。
- 全局奇偶关节相位保持一致。平滑交接期间共用一个名义180°弧度预算，按使能权重和奇偶分配曲率；窗口外驱动力矩严格为零，机械阻尼仍为1.5。
- 候选须覆盖承重区域且实际形状可用；窗口保持优先，边界载荷持续偏移才迁移。交接要检查新窗口覆盖、跟踪误差和承重，不以计时到点单独判定成功。失败保留记录并退回。
- 保留前轮冻结的实际管轴包绕150–218°、目标截面转角≤190°、端距/主动骨架长度≥0.4、限矩2.355 N·m、无地面支撑、连续失去支撑<0.5 s。
- 急弯横跨两段轴时，单截面管轴包绕不可观测，仍记录为不可观测。新增独立身体开放形态评价：实际角重建截面总转角150–218°、端距比≥0.4、平面拟合RMS≤15 mm；这些条件不能替代“管轴包绕已确认”，分别报告两个结论。窗口交接取整个使能并集，不能只审查重叠区。
- 进度用全身固定骨架点的平均位置评价，窗口移动不会改变评价点集合。全身离开障碍后继续3个滚动周期。
- 不追加反馈延迟、低阻尼、随机扰动或无目的统计重复。每轮先审查全部保存时间点、最差状态及完整侧/端视视频，再决定下一轮。

## 有条件扩缩与修复

先判断失效原因是交接错误、实际窗口位置错误，还是固定弧长不足。只有实际轨迹显示固定宽度的承重与开放条件无法共同满足，才启用长度变化。增加关节时重新分配一个半圆的总曲率，而非保持原60°幅值。形状与承重决定候选长度，管径真值只参与评价。扩缩版本增加1次已知失败场景修复和1次必要回归；其他代码问题也只补最小失败复现与相关回归，并在运行前更新本文件说明理由/预计次数。

每轮报告：已验证事实、失败证据、原因与置信程度、未覆盖范围、下一项最小验证和是否达到该轮目标。保留全部成功/失败的actual qpos/qvel、发送目标、权重/掩码、支撑反馈、选择原因和交接事件。机械正功不称为电能；不能以运动通过替代开放形态验收。

## S1首例后的明确修复（增加1次）

`s1_head`实际完成两次迁移且无失去支撑；但返回交接时发送目标峰值196.56°，并集的管轴包绕最高242.10°，原冻结门槛判失败。完整图中保持开放，没有出口累计收紧；仍保留失败，不能将视觉开放直接改判通过。并集包含进入端的直连杆，指标会在切换统计范围时跳变，这同时提示需要在使能进入端前主动增加开口余量。

修复加入旧窗口内的准备阶段：2 s平滑将名义曲率预算从180°降至150°；只有拟加入的整个并集的实际/发送截面转角均≤165°且开口≥0.4才开始使能交接。交接完成后2 s恢复180°。这保持相同滚动公式和原验收门槛；准备超时保留拒绝事件，不偷偷扩窗。首例修复`s1_head_repair`增加1次，反方向`s1_tail`仍是原计划的第2次且承担必要回归。迁移等待状态可能延长，最长改为80 s，最后交接完成后3周期即停；返回申请为max(24 s,首次完成+6 s)，不向尚未完成的交接重叠发请求。初始11次+该1次修复=12次当前预算。

## S1第二次复盘：按授权启用短暂扩缩（再增加1次）

`s1_head_repair`发送目标最大187.49°，实际身体截面153.15–190.20°，开口≥0.549且全程承重；但7关节并集管轴包绕仍达227.14°，原冻结上限仍判失败，未改判通过。这里存在指标范围变化，但同时启用7关节确实不满足原有完整验收。

设计`6→5→6`交接：准备后先在旧6关节内部把曲率分配给新旧重叠的5关节，退出关节逐步卸载；跟踪和支撑覆盖合格才失能退出关节。稳定5关节段保持150°名义预算，再准备并接入新关节，最终6关节段恢复180°。任一时刻使能并集最多6关节，5关节段每个奇偶族独立分配总曲率，150°预算避免两个同类关节各需90°。这不是按管径增加关节，而是已知交接失败触发的临时收缩/恢复。若支撑不足或目标/实际并集无法打开则拒绝或回退。

新增`s1_head_contract`1次已知失败修复；原定`s1_tail`承担反方向必要回归，总预算暂为13次。两次旧失败仍存档并渲染全程。大管径场景若另有明确弧长不足，再根据该病例证据安排最小扩窗修复和回归。

## S1第三次复盘：5关节覆盖不足，采用卸载相位交接（再增加1次）

`s1_head_contract`没有失去支撑、目标≤190°，但实际截面最低142.90°、恢复6关节时管轴包绕227.01°，仍失败。5关节下两个同类关节需75°幅值，0.6 rad/s滚动时峰值速度45°/s已经占满原45°/s命令速率，幅值变化/反馈没有跟踪余量；这是动力学与离散构形的可能原因，不把它写成已证实唯一原因。

更直接的几何事实：相邻移动1关节时，退出和进入关节属于同一全局奇偶族。在该族sin/cos接近零的相位，旧/新6关节名义目标接近一致。新版等待该相位（族因子≤0.015），短暂停相位，但物理与顺应继续；实测进入/退出角≤4°、速度≤8°/s、退出主动关节力矩≤0.2 N·m、新窗口承重覆盖≥80%、实际与发送形态合格才将退出关节失能、进入关节预置实测角后使能。其他5个重叠目标保持连续，随后恢复相位。任一时刻使能6关节，不产生7关节并集，也不经历5关节覆盖不足。

新增`s1_head_phase`1次修复，`s1_tail`仍承担原计划反向回归；当前预算14次。主动退出力矩是新增的MuJoCo观测，用于交接卸载，不进入截面几何反馈；实机力矩可观测性仍待后续移植确认。前3次失败代码和证据已本地提交739e9f3，当前源保留可选历史策略以供追溯，不继续试调其阈值。

## S3出口观察计时修复（增加1次）

3个应用原运行均完成全身出口与身体开放；急弯106个采样的单管轴包绕仍不可观测。实际相位审核发现`s3_taper90`出口后31.5 s含3.416 s交接停相位，仅2.746个实际周期，旧程序以墙上仿真时间除周期误判3周期。修改停止/验收为出口后累计滚动相位≥6π，原记录保留并标记观察不足。只新增`s3_taper90_cycles`1次相同控制/场景的计时修复验证，其他两病例已用实际相位确认3.008周期，不重复。固定初始11+交接修复3+计时修复1=15次当前预算，S4三对照仍在原11次内。

## S4复盘：周期性承重点误判为迁移（增加2次）

110→210 mm急弯三组均完成全身出口及3个实际滚动周期，固定6关节同时维持承重和身体开放，不触发永久扩窗。三组在拐角均存在管轴包绕<150°或轴不可观测的采样，仍按原门槛保留完整验收不通过；这些是覆盖/评价边界问题，不能写成螺旋收紧或无条件通过。基础步态也通过运动和身体形态，尚无通过率优势证据。

`s4_sliding`完成4次自动交接，但出口后3次往返，停相位累计约19.77 s。以一个实际周期积分原始向上承重发现，第一次向头移窗后平均承重中心接近J9.1–9.3、位于J7–12中点9.5附近，短时滤波却继续触发迁移。周期内接触摆动是主要疑因；窗口重塑也会改变承重分布，不能断言唯一原因。

修复只将自动定位的承重中心改为最近2π实际滚动相位积分的分布（F·dφ），保留1.25关节死区、1.2 s持续、5 s冷却和全部交接/形态门槛。停相位不累加；完成交接清除旧分布，取得新窗口的完整周期后再选择。初始实际形态/承重选窗及手工请求不等待完整周期。代价是自动定位约一个周期的观察时延。

运行前声明2次：`s4_sliding_cyclemean`同一110→210 mm急弯修复（最长150 s、出口后3实际周期），`s2_middle_cyclemean`同一4 N载荷回归（最长90 s，为完整周期观察与卸载交接保留时间）。后者仍要求至少1次真实自动迁移；若没有则记录该项未覆盖，不改验收掩盖结果，也不把保持承重写成迁移成功。新总数17次；不重复其余病例，不调整物理/形态门槛。

## 本轮结束时的事实与边界

声明的17次均执行并保留。最终急弯24.370 s完成唯一自动J8–13→J7–12交接，38.0 s全身出口、69.5 s完成3.008实际周期，无出口往返；身体160.93–186.97°、开口≥0.554、失能主动矩0。固定6关节能维持承重与身体开放，不触发永久扩窗。严格管轴指标仍最低142.84°、18越界/47不可观测采样，完整验收未通过。

最终4 N回归90 s保持身体/管轴开放与承重，但没有自动迁移；平均承重中心未跨1.25关节门槛，迁移测试项保留false。没有为了该结果再降低门槛或追加无目的运行。最终定位器仅新跑修复和载荷回归2例，不能将早期短时定位器的S2/S3记录写成最终定位器全矩阵验收。完整复盘、原始证据和后续最小问题见`validation/reports/sliding_section/README.md`。
