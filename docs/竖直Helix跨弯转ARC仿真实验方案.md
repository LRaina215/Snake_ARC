# 竖直Helix经90°弯管转水平ARC：仿真研究方案

> **后续实施结果：**18关节、110 mm裸管/300 mm柔弯的代表例已完成全流程仿真，201.95 s后形成开放半圆、归中并续行124.38 mm；采用1.5圈竖直承载/跨弯，水平侧再退到约一圈后成半圆。完整视频、全部失败及适用范围见[实施与复盘报告](../validation/reports/vertical_arc_20261108/README.md)。以下保留执行前方案，实机和现有热键未同步。

2026-11-08。目标是先在MuJoCo实现完整物理运动流程；当前阶段不更新实机代码或现有Ctrl+4/5/6/7热键入口。研究沿用现有18关节机器人、曲线段拼接、积分映射及逐段使能/失能方法。

## 1．本轮要回答的问题

**能否把约一圈局部承载包绕沿连续弯头迁移到水平管，并在那里打开为半圆ARC、自动归中和继续运动？**

流程为：竖直Helix向上接近 → 逆向送出余尾，保留局部包绕 → Shift Control推动承载包绕迁移过弯 → 水平侧建立承托，逐步退出竖直侧包绕 → 水平开放半圆 → 端部归零/失能、自动归中、基础ARC续行。

“约一圈”是待验证的首选承载预算，可以根据失败原因调整。竖直段先保留非零螺距，水平支撑建立后再打开半圆。**承载包绕要随曲线进给迁移，不能把竖直一整圈固定不动，再要求头端另外形成一套完整水平半圆。**退出的尾段失能，但它的重量仍由承载段承担。

本轮不研究自动发现未知弯头、自动估管径抱紧、T分支、变径、40关节或重力矩小U替代路线。需要的接近触发、弯向及支撑确认使用明确记录的操作者输入；这属于首版流程条件。

## 2．固定场景和真实尺寸

| 项目 | 首轮设置与核对要求 |
| --- | --- |
| 机器人 | 18关节，头端25 mm、17段轴距72 mm、尾端91 mm，总骨架长约1.340 m |
| 尺寸落实 | 新MuJoCo模型的转轴/端点位置与控制器长度数组同时更新；不能只改控制器中的LINK_LENGTHS_M。连接件增重尚无准确实测，质量/惯量的来源和近似需记录 |
| 管道 | 竖直向上→连续90°柔弯→水平，同径110 mm；首选中心线弯曲半径300 mm |
| 几何复用 | 复用本仓库reference/Snake_Robot_o20_Pipe_bend90.xml的90°中心线路径与参考仓库的建模方法，重新生成18关节、裸管110 mm场景 |
| 摩擦 | 首轮管外滑动摩擦系数沿当前裸直管0.5；参考弯管的2.0及橡胶层不直接继承。机器人接触参数和模型被动阻尼如有差异需明示 |
| 驱动 | 先沿用当前基线kp=127、kd=1、力矩上限2.355 Nm；首轮动作倍率1，不使用用户实机文件中的4倍调参覆盖 |
| 初始状态 | 一次性初始化可稳定搭管的竖直Helix，关节总数/相位/绕向和初态存档。运动期间不修改自由根位置/姿态，不加外力托举 |
| 空间净空 | 竖直长度和离地高度足以容纳释放后的失能尾段，避免尾部落地帮忙承载；水平出口足以观察续行 |

本轮只读元数据已核对：参考bend90场景管径113 mm、中心线总转角90°、名义弯曲半径300 mm、管道摩擦2.0；参考u_vertical实际上是180°回弯，不能按文件名当成90°场景。加载新场景后仍应核对实际碰撞几何、关节中心距及元数据一致性。

长度安排须先做粗算：按当前中心线螺旋半径94 mm、螺距130 mm，一圈螺旋长约605 mm；300 mm半径的90°管轴弧长约471 mm；半圆约295 mm。把三段都当成互不重叠且同时完整存在，约需1.371 m，已超过1.340 m总长。这只是规划预算，不是严格不可达证明；它说明应让局部包绕整体迁移并逐步交接，最终按机器人实际曲线弧长核算，不能堆叠三套完整构型。

## 3．曲线控制实现

所有目标保持如下路径：**分段曲线参数 → 曲率/扭率及材料参考方向 → 关节相邻区间积分 → 目标角及使能交接**。

1. **接管当前Helix。**使用全身角度与机械尺寸拟合当前半径、螺距和相位，预置当前目标后接管，不重新把整身拉回默认Helix。先核对相位方向对应实际向上运动。
2. **逆向退尾、局部化承载。**复用已有逆向送链和相位耦合，逐步增长退出直线段、缩短包绕的材料区间；仍在包绕上的关节继续工作，退出段依次失能。先尝试约一圈，期间保留推进能力。
3. **构造随弯轴变化的局部包绕。**以名义“直线—90°圆弧—直线”管轴构造连续参考方向，在管轴周围建立局部螺旋/包绕曲线。用Shift Control推进该包绕的轴向位置和材料区间，竖直侧逐渐退出、水平侧逐渐接入；不单独指定整段头尾的世界目标位置。
4. **真实弧长与积分。**弯轴上的曲线先按蛇身真实弧长重新参数化，再分段得到弯曲方向、曲率和扭率，送入现有积分映射。管轴进给距离、蛇身材料长度和关节间距是不同的量，不能直接互换。拼接处要保持位置及切线连续，参数变化要连续，接入时保留当前已发相位。
5. **水平侧打开半圆。**水平侧实际承托建立后，再退出余下竖直包绕，逐步消除局部螺距并留下上侧开放半圆。复用现有水平Helix→ARC的成弧、端部处理和基础接管能力，不重新执行一遍完整逆向解缠。
6. **归中。**将当前连续半圆作为seed_curve交给公共create_feeding_controller，使用request_center；归中后按最终承载范围再归零、失能两端并交回基础ARC。

控制层复用snake_control/curve_gait.py及公共调长/交接接口；在公共曲线层扩展弯轴参考和参考方向传递。新增竖直跨弯状态编排可以放在snake_control/vertical_arc_transition.py，但不能复制一套Ctrl+4调长算法。仿真实验通过独立validation入口调用库核心，开发期间不重新生成实机内嵌核心。

当前公共调长的“左右悬垂长度”观察器用于最后的水平归中。竖直/跨弯阶段需要匹配当前曲线的观测与退出策略，通过公共接口扩展；不能把水平等长判据硬套到竖直尾段，也不能将使能等同于已测承重。

## 4．解决截面方向退化和输入边界

现有水平Ctrl+7用 up=-down+axis*(down@axis) 选截面上方。竖直轴与重力平行时该投影趋零，顶部角位置不唯一，不能继续归一化后当作可靠方向。

拟用当前曲线的材料方向和相位初始化，沿名义弯轴连续传递截面参考方向；避免参考方向在接近竖直或曲率很小时突然翻转。只有重力投影充分时才用其校正上侧。竖直轴对称起态下，外部弯头的朝向不能仅凭关节角唯一判断，所以首版由操作者选择弯向并触发接近/支撑交接。

| 输入 | 控制用途 |
| --- | --- |
| 实测关节角、采样时刻、已发目标/相位及使能 | 当前形状拟合、目标连续、曲线接管与更新 |
| 已知机器人机械尺寸 | 重建材料坐标与积分 |
| 明确配置的名义管径/弯曲半径及操作者弯向、触发、支撑确认 | 首版曲线规划与阶段交接；这些是先验/人工输入，不冒称未知环境自主识别 |
| MuJoCo接触力、真实管轴、根位姿、精确障碍距离 | 仅初态布置、独立评价和模拟明确的操作者事件，不反馈给运动控制器 |

若实验脚本读取场景真值来模拟“操作者确认已到弯头/已搭稳”，须记录事件来源，不能包装成控制器自己识别成功。不使用真实坐标误差闭环把蛇拖到目标路线。

## 5．开发顺序与首轮测试数量

先做一次离线曲线/模型一致性检查：尺寸、总长、积分限位、拼接切线和参考方向连续性、目标与使能长度匹配。这不是新增动力学实验，不展开无目的参数扫描。

| 动力学轮次 | 假设与改变的变量 | 验收与复盘重点 |
| --- | --- | --- |
| 第1轮：竖直局部承载先导，1次 | 从完整Helix上行开始，逐段退尾至约一圈，其余条件固定；检验局部化后是否还能承载并推进 | 局部化后实际净上移一个轴距约72 mm，退出段主动驱动力矩为0、无地面支撑；核查下滑、构型塌陷、相位方向、实际接触、限位与饱和。不做长hold |
| 第2轮：完整90°跨弯，1次 | 使用先导可行的承载预算，加入弯轴曲线迁移和支撑交接 | 局部包绕实际迁移过弯，竖直段不再提供包绕承载，水平开放半圆形成且归中；随后沿水平管继续实际前进至少一个轴距，检查是否重新缠回螺旋、尾部挂弯或移窗错位 |

第1轮开始的完整Helix短程推进用于确认初始攀爬可用，不能把它与后半段不同状态当成同初态的性能对照。局部化如果失败，先区分“完整Helix本来就不爬”“一圈承载不足”“退尾造成滑落”“曲线/使能交接错误”，再修改一项最相关的因素并复跑该例；不在未解决承载时硬跑跨弯。

首轮共2个动力学主例。失败后每轮只安排1–2次有明确理由的修复复跑，通过后最多补一项与改动直接相关的回归。主例数量少不妨碍记录可行性；也不能凭一次失败否定方向或凭一次成功宣称任意条件稳定。若确实受到18关节长度/力矩的限制，报告对应证据和限制条件。

本轮不增加反馈延迟、低阻尼或摩擦扫描；不通过改变场景摩擦、力矩上限或锁定根部来掩盖控制问题。需要修改物理假设时另存配置并说明，不沿用原条件的通过结论。

## 6．通过条件与交付

竖直承载段允许暂时保留约一圈螺旋；开放半圆的形态验收针对进入水平管之后，不把竖直阶段的完整承载包绕误报为最终ARC。

- 检查完整实际运动：初始上行、退尾、最差交接、过弯、成弧、归中与水平续行；目标曲线或头端先过弯不算完整通过。
- 水平阶段实际包绕/开口、截面平面性和曲率要符合开放半圆；可沿用现有150–220°范围作为首轮检查口径，并报告开口/平面误差。失能尾段可以自然悬垂到弯头下方，但不能仍缠在竖直管上帮助承载或挂住弯头阻止续行。
- 实际姿态持续下滑、掉管、触地支撑、自碰撞、限位、使能反复切换和持续饱和均要记录并分析；瞬时摆动不机械地等同于失败，短暂饱和也不隐去。
- 归中以实际两侧材料长度评价，控制器代理值单独保存；默认目标为相差不超过一个当前轴距约72 mm。两端归零只记录释放前读角，不能保证失能后永远0°。
- 每轮保留假设、参数、曲线、目标、使能、角反馈、实际qpos/qvel、驱动力矩、接触评价和操作者事件；失败运行与成功运行均保留。
- 录制整个流程的斜视与端视视频，叠加阶段、操作者命令、曲线进给、相位、使能/目标/实测角及支撑评价；真值评价与实机可读信息明确区分。
- 交付研究代码、可复现场景/运行记录、完整视频、逐轮问题与原因复盘、最终可行范围；只做本地commit。仿真通过后再讨论实机/热键同步。

以上为执行前冻结方案；后续已完成当前代表场景实现及实际保存态验收。首选一圈的失败、1.5圈可行配置、水平交接自接触修复和最终续行均见[本轮报告](../validation/reports/vertical_arc_20261108/README.md)，不能据此扩大到任意弯头或实机。今日原实机结论见[实机往返总结](2026-11-08实机往返总结与竖直跨弯方案.md)。
