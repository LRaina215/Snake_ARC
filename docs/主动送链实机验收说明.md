1. 按Ctrl+U形成圆弧，等待形成与静置完成。
   若机器人已经搭在管上且圆弧偏离配置位置，可在失能时按Ctrl+3自动定位初始窗口，形成后进入顺应。Ctrl+U保留配置的初始窗口；Ctrl+X再Ctrl+U也会恢复该配置，运行中的移窗不会改写它。
2. 按Ctrl+4选择主动送链。选择模式本身保持当前目标，不立刻送链。
3. 默认请求净材料转移64.5 mm。Ctrl+=加倍、Ctrl+-减半；两次Ctrl+=将64.5改为258 mm。
4. Ctrl+J启动**头侧增长、尾侧缩短**；Ctrl+H启动**头侧缩短、尾侧增长**。方向按J1为头侧定义，与画面左右无关。
5. 首次用6 s接入起态，然后进入`acquire`接管附近关节并展直；此时弯曲分布位置不推进、尚不计算送链进度。新反馈稳定至少0.6 s后建立本步基线，开始一段调整，到位直接保持。没有自动反向。再按J/H从当前弯曲位置接着调整，不恢复初始圆弧；换向也先等待接管稳定。普通滚动相位仍为0。

状态打印和预览显示当前阶段、请求量、长度代理、使能区与暂停/故障原因。使能区会包含展直与交接缓冲，数量可能超过弯曲半圆所需的6关节。返回后不立即撤去所有缓冲，保留当前承托状态。

## 热键和控制台

| 操作 | Ctrl+4模式中的含义 |
| --- | --- |
| Ctrl+J / H | 每按一次执行一段增长/缩短，到位保持；连续按可从当前姿态继续 |
| Ctrl+- / = | 下一项任务材料量减半/加倍；不改变进行中的目标 |
| Ctrl+T | 反转下一项任务方向 |
| Ctrl+G | 暂停/继续；已完成时保持，下一段由J/H明确启动 |
| Ctrl+空格 / N | 保持当前目标，暂停算法更新 |
| Ctrl+L | 推进一次20 ms目标更新后暂停；首次按下建立任务 |
| Ctrl+Y | 在已取得起态基线后提前返回；形成期间尚无基线时提示原因 |
| Ctrl+K | 显示当前状态 |
| Ctrl+X / Q | 全部失能 / 退出并清理 |
| Ctrl+1 / 2 | 切回基础 / 固定顺应，沿用当前窗口接入 |
| Ctrl+3 | 从模式4按全身实测角重新选窗，撤去窗口外的送链缓冲使能，再接入自动滑窗 |

Ctrl+L只推进一个目标更新，真实机构仍会运动到目标，不是物理时间暂停。Ctrl+G恢复不把暂停时长折算成一次大跳步，也不将暂停计入算法等待期限。若已因观测或跟踪问题保持，Ctrl+G显式重试，并在日志中保留原故障；J/H则建立新的任务。J/H保留当前弯曲分布、目标和使能，重新等待接管稳定并建立本段基线；不会先回到种子圆弧。运行中按J/H会替换尚未完成的目标，不排队；建议先等本步完成再按下一次。这里的“单步”是一段默认64.5 mm的闭环任务，不是L的一个20 ms控制更新。

控制台支持`gait_feeding / step / back / run / pause / feed_tick / feed_return`。输入`feed_mm=258`设置下一任务量及正方向，`feed_mm=-258`设置同量负方向，输入本身不执行运动。也可直接改文件顶部参数。全局Ctrl热键同时发送给正在运行的入口，操作时只运行实机或仿真其中一个。

## 现场调参位置

| 位置 | 内容 |
| --- | --- |
| `FEED_DISTANCE_M` | 初始任务材料量，默认`.0645` m，四连杆量改为`.258` |
| `FEED_AMPLITUDE_DEG` | 独立送链形态幅值，默认60°；不随基础模式`amplitude`变化 |
| `FEED_PREPARATION_S` | 首次形成时间，默认6 s；后续J/H不重复形成 |
| `FEED_AUTOMATIC_RETURN` | 默认`False`，到位保持；Ctrl+Y可手动返回本步基线。保留`True`供研究往返使用 |
| `FEED_OPTIONS_OVERRIDE` | 覆盖第3C段`ContinuousFeedingOptions`字段，例如速度与到位阈值 |
| `FEED_DIRECTION_OVERRIDE` | 覆盖第3C段`ManualFeedingDirectionOptions`：搜索段数、直线度、稳定时间等 |
| `FEED_DIAGNOSTIC_PERIOD_S` | 运行中自动输出选段诊断的间隔，默认2 s；Ctrl+K随时查看 |
| 第3C段 `ContinuousFeeding` | 连续弯曲分布、交接、目标滤波和任务阶段 |
| 第3C段 `ManualFeedingObserver` | 模式4旧版全角重建、双侧方向、虚拟切片与长度代理 |
| `RollingArcController.*feeding*` | 读角/时间、热键与飞特扭矩接管 |
| `FIRST_JOINT / LAST_JOINT` | 实机配置的种子窗口；失能后`window=8:13`也可修改 |

仿真种子窗口由其顶部`SIM_FIRST_JOINT / SIM_LAST_JOINT`设置，其他送链参数读取实机文件的`FEED_*`。默认几何是20关节、21段64.5 mm；实际尺寸与零位仍在实机顶部校准。基础参数与送链参数分开，Ctrl+上/下、左/右修改基础幅值/频率不会改变正在进行的送链任务。

`tools/build_real_feeding_core.py`仅是开发同步工具，按标记区嵌入研究数学核心。运行实机不需要它，也不导入仓库模块；现场手改第3C段后不要用生成器覆盖自己的修改。

## 输入、显示与验收边界

控制只使用全关节实测角、机械尺寸和采样/控制时间，不读取管径、接触力、管轴或世界坐标。反馈包含失能关节，关闭预览仍按200 ms读取；失能是飞特0x28扭矩寄存器写0，不向该关节发送零角目标。新进入关节先预置实测角再使能。软件掩码表示已发送并核对的使能命令，不等于测量到了真实支撑力。

2026-10-21观察器改为在两侧失能区内搜索连续3～5段连杆，保留直线度≥0.98，要求至少3个新反馈跨越0.4 s、区段内部角度最大变化≤3°。还检查端点与区段低于估计顶部的距离。可用区段继续沿用，失效才重选；两侧方向相差≤25°时按段数与直线度融合，不一致时明确显示单侧来源。重复时间戳不累计稳定样本，超过0.6 s未收到新的观察样本时重新收集。

稳定性指固定材料区段的内部角度变化，不是世界方向静止；只用关节角无法证明世界重力或真实承重。观察器仍用启动时确定的虚拟切片估计两侧长度变化，实测应对照两侧实际材料变化。准备6 s末若尚在收集稳定样本，使用已有`maximum_untrusted_s`默认3 s等待预算，之后仍无基线才保持。暂停/单帧模式持续读角并更新观察历史，不推进目标、交接或起态基线；因此慢速按Ctrl+L也能收集稳定样本。

控制台每2 s及Ctrl+K显示：头/尾选中或候选的L连杆范围、内部J关节范围、直线度及门槛、观察时间/样本数、局部角变化、下垂几何距离、合格区段数和具体拒绝原因，以及两侧夹角和融合/单侧来源。L1～L21是从头向尾的连杆编号，J1～J20是关节编号。MuJoCo窗口也显示选段和直线度，完整数值与实机一样在控制台和日志中。关闭并重新运行Python后才会载入这次更新。

预览显示实测/已发目标折线及同法重建平滑截面。在主动送链模式，平滑曲线只作显示，长度控制使用连杆几何；其他顺应模式仍显示其实际控制曲线。预览的平面内坐标不是世界XY或管轴坐标。

日志自动保存到`codes/logs/`。送链模式每个控制循环保存一条，包含`feeding_action_id / feeding / feeding_motor_input`、目标、使能、全角反馈及任务阶段/时钟；慢串口时真实间隔可能大于20 ms。暂停时也保留状态。若提供实测日志和完整视频，可核对目标与实际角是否一致、材料变化方向、交接、开放弧以及停止后的漂移。

研究仅在113 mm水平直管验证了±258 mm往返与−64.5 mm小幅。最多16关节使能，长度代理最大偏差20.82 mm，正向大幅去程误差接近验收阈值，仍有厘米级横摆；尚未验证其他管径或任意长度比例。本次接管基线修复仅完成日志片段回放、内存串口与交互检查，**未连接真实机器人，没有实机通过结论**。[研究原始记录](../validation/reports/active_feeding_continuation/README.md)和[同步检查](../validation/reports/active_feeding_port/README.md)保留具体范围。

## 接管计量修复的边界

`acquisition_stability_s=.6`、`acquisition_angle_span_deg=3`、`acquisition_length_span_m=.002`控制基线采样；默认至少3个新反馈，需满足跟踪误差≤5°、稳定窗口全关节角波动≤3°和长度代理波动≤2 mm。上限等待沿用`maximum_tracking_wait_s=10`秒，未稳定则保持并打印原因，不使用运动中的数值强行标零。这些参数可在`FEED_OPTIONS_OVERRIDE`调整。

修复针对“基线建立后才接管展直”的已知启动偏差，不是精确接触长度传感器。后续运动使用原虚拟切片；正常运动不重新标零，参考失去连续性时的显式重标定及计量限制见下节。请对照管旁材料标记验收去程实际变化；旧仿真视频不代表本次修改已通过新动力学或实机验收。

## 历史：可达边界与反向恢复（模式4部分已撤回）

可达范围由当前种子圆弧和失能参考侧共同决定，不能把所需弯曲关节排除在使能范围之外。到边界后显示`boundary`并保持，不称为已完成毫米目标；再按同向键也不向外挤。按反向键可继续相对调长。

如果在反向时仍有超过5°的旧目标跟踪误差，或旧版本已经进入不可执行区，进入`reverse_recover`：从实测角分小步过渡到向内的可执行姿态，仍按5°检查每一步已发目标，角速度限幅也不变。恢复完成显示`recovered`并保持；这一段不按64.5 mm到位计量，下一次J/H再开始长度任务。机械上无法跟上中间目标时仍会保持并报告，软件恢复不等于实机一定能克服卡滞。

Ctrl+U使用顶部`FIRST_JOINT/LAST_JOINT`或失能后明确设置的`window=a:b`；仿真使用`SIM_FIRST_JOINT/SIM_LAST_JOINT`。Ctrl+3的自动初始窗口只属于本次接管，不覆盖该配置。姿态选择只使用全关节角和连杆尺寸，比较开放形态、圆弧覆盖和两侧参考；不能从直线姿态推断管道位置。

顺应性位置移动现在不再受圆拟合误差单独阻塞；长度扩缩仍需要可靠覆盖角与多相位样本，位置移动仍需要可信位置证据、退出角和交接条件。两者不要混同成“所有建议必须立即执行”。本轮原始失败证据、检查和未验证范围见[修复记录](../validation/reports/feeding_boundary_20261021/README.md)。
