# 主动送链：实机与仿真手调

2026-10-14已将最终主动送链方法同步到`codes/Rolling_Arc_Real.py`，仿真手调`codes/Rolling_Arc_Debug_Mujoco.py`调用同一个控制器。实机仍只运行这一份Python文件，使用已有`mujoco`环境，无需启动参数或可视化程序。这里介绍新增Ctrl+4模式；基础圆弧、固定顺应与自动滑窗顺应仍由Ctrl+1/2/3选择。

## 启动与一次往返

```powershell
conda activate mujoco
cd "D:\Desktop\SNAKE\Paper Code\Mujoco\Snake_ARC"
python .\codes\Rolling_Arc_Real.py
# 仿真手调则运行：python .\codes\Rolling_Arc_Debug_Mujoco.py
```

1. 按Ctrl+U形成圆弧，等待形成与静置完成。
2. 按Ctrl+4选择主动送链。选择模式本身保持当前目标，不立刻送链。
3. 默认请求净材料转移64.5 mm。Ctrl+=加倍、Ctrl+-减半；两次Ctrl+=将64.5改为258 mm。
4. Ctrl+J启动**头侧增长、尾侧缩短**；Ctrl+H启动**头侧缩短、尾侧增长**。方向按J1为头侧定义，与画面左右无关。
5. 默认先用6 s平滑接入起态并标定，再主动送链；去程到位观察2 s后自动返回起态，返回观察2 s后保持。普通滚动相位固定为0，材料弯曲分布持续沿身体移动。

状态打印和预览显示当前阶段、请求量、长度代理、使能区与暂停/故障原因。使能区会包含展直与交接缓冲，数量可能超过弯曲半圆所需的6关节。返回后不立即撤去所有缓冲，保留当前承托状态。

## 热键和控制台

| 操作 | Ctrl+4模式中的含义 |
| --- | --- |
| Ctrl+J / H | 从当前目标接入，开始一项新的增长/缩短往返 |
| Ctrl+- / = | 下一项任务材料量减半/加倍；不改变进行中的目标 |
| Ctrl+T | 反转下一项任务方向 |
| Ctrl+G | 暂停/继续；尚无任务或上一任务结束时启动下一项 |
| Ctrl+空格 / N | 保持当前目标，暂停算法更新 |
| Ctrl+L | 推进一次20 ms目标更新后暂停；首次按下建立任务 |
| Ctrl+Y | 在已取得起态基线后提前返回；形成期间尚无基线时提示原因 |
| Ctrl+K | 显示当前状态 |
| Ctrl+X / Q | 全部失能 / 退出并清理 |
| Ctrl+1 / 2 / 3 | 切回原模式；保持当前目标接入 |

Ctrl+L只推进一个目标更新，真实机构仍会运动到目标，不是物理时间暂停。Ctrl+G恢复不把暂停时长折算成一次大跳步，也不将暂停计入算法等待期限。若已因观测或跟踪问题保持，Ctrl+G显式重试，并在日志中保留原故障；J/H则建立新的任务。任务重启先按限速恢复配置的种子圆弧，保留旧支撑，不瞬时重置使能。

控制台支持`gait_feeding / step / back / run / pause / feed_tick / feed_return`。输入`feed_mm=258`设置下一任务量及正方向，`feed_mm=-258`设置同量负方向，输入本身不执行运动。也可直接改文件顶部参数。全局Ctrl热键同时发送给正在运行的入口，操作时只运行实机或仿真其中一个。

## 现场调参位置

| 位置 | 内容 |
| --- | --- |
| `FEED_DISTANCE_M` | 初始任务材料量，默认`.0645` m，四连杆量改为`.258` |
| `FEED_AMPLITUDE_DEG` | 独立送链形态幅值，默认60°；不随基础模式`amplitude`变化 |
| `FEED_PREPARATION_S` | 每项任务形成与起态标定时间，默认6 s |
| `FEED_AUTOMATIC_RETURN` | 默认`True`；改为`False`则去程观察后暂停，Ctrl+Y返回 |
| `FEED_OPTIONS_OVERRIDE` | 覆盖第3C段`ContinuousFeedingOptions`字段，例如速度与到位阈值 |
| 第3C段 `ContinuousFeeding` | 连续弯曲分布、交接、目标滤波和任务阶段 |
| 第3C段 `WholeFeedingObserver` | 全角重建、双侧方向、虚拟切片与长度代理 |
| `RollingArcController.*feeding*` | 读角/时间、热键与飞特扭矩接管 |
| `FIRST_JOINT / LAST_JOINT` | 实机配置的种子窗口；失能后`window=8:13`也可修改 |

仿真种子窗口由其顶部`SIM_FIRST_JOINT / SIM_LAST_JOINT`设置，其他送链参数读取实机文件的`FEED_*`。默认几何是20关节、21段64.5 mm；实际尺寸与零位仍在实机顶部校准。基础参数与送链参数分开，Ctrl+上/下、左/右修改基础幅值/频率不会改变正在进行的送链任务。

`tools/build_real_feeding_core.py`仅是开发同步工具，按标记区嵌入研究数学核心。运行实机不需要它，也不导入仓库模块；现场手改第3C段后不要用生成器覆盖自己的修改。

## 输入、显示与验收边界

控制只使用全关节实测角、机械尺寸和采样/控制时间，不读取管径、接触力、管轴或世界坐标。反馈包含失能关节，关闭预览仍按200 ms读取；失能是飞特0x28扭矩寄存器写0，不向该关节发送零角目标。新进入关节先预置实测角再使能。软件掩码表示已发送并核对的使能命令，不等于测量到了真实支撑力。

观察器用满足直线度与悬垂条件的两端方向估计上下，以启动时确定的虚拟切片估计两侧长度变化。两端共同估计有几何条件，不是IMU或精确管轴长度测量；实测应对照两侧实际材料变化。暂停或保持时真实机构仍受重力作用。当前参数保留观察失效及目标跟踪等待后的保持，参数均在第3C段可读可改。

预览显示实测/已发目标折线及同法重建平滑截面。在主动送链模式，平滑曲线只作显示，长度控制使用连杆几何；其他顺应模式仍显示其实际控制曲线。预览的平面内坐标不是世界XY或管轴坐标。

日志自动保存到`codes/logs/`。送链模式每个控制循环保存一条，包含`feeding_action_id / feeding / feeding_motor_input`、目标、使能、全角反馈及任务阶段/时钟；慢串口时真实间隔可能大于20 ms。暂停时也保留状态。若提供实测日志和完整视频，可核对目标与实际角是否一致、材料变化方向、交接、开放弧以及停止后的漂移。

研究仅在113 mm水平直管验证了±258 mm往返与−64.5 mm小幅。最多16关节使能，长度代理最大偏差20.82 mm，正向大幅去程误差接近验收阈值，仍有厘米级横摆；尚未验证其他管径或任意长度比例。此次同步仅完成离线回放、内存串口与交互检查，**未连接真实机器人，没有实机通过结论**。[研究原始记录](../validation/reports/active_feeding_continuation/README.md)和[同步检查](../validation/reports/active_feeding_port/README.md)保留具体范围。
