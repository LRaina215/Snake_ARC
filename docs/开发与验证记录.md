## 实现与当前边界

供人工操作的MuJoCo入口为`codes/Rolling_Arc_Debug_Mujoco.py`，直接运行，共用实机基础/固定控制与Ctrl操作，额外支持三模式及左右端点拉动。滑动模式调用既有仿真核心，以实际本体位移和自动移窗测试响应；原自动研究入口继续保留。场景在仿真入口顶部改，基础/固定顺应参数在实机入口顶部改；操作差异见[统一调试说明](仿真实机统一调试说明.md)。

实机入口现沿用CaseA的直接运行方式，`python codes/Rolling_Arc_Real.py`即可；串口默认自动查找CH340，手动选择、内存演练及日志开关均在文件顶部修改。每次日志自动保存在文件旁的`logs/`，现有README和实机操作说明不再要求`--port`或`--log`。本页前述CLI及环境检查描述的是当时版本，历史报告保留原接口和实际记录。

- 基础圆弧：20关节，默认固定使能J8–J13；窗口外主动驱动力矩为零，保留模型中的机械阻尼。零目标角不代表失能。弯管使用同一滚动公式。
- 固定截面顺应：由实测关节角和连杆尺寸重建局部半圆，执行截面投影、连续线圆弧与Yamada积分，并用参考校准、总转角和开口约束抑制累计收紧。仿真与实机数学核心对应，实机单文件无需外部可视化程序。
- 滑动窗口：当前只用于仿真。由MuJoCo向上接触力的整指令相位周期分布定位窗口，在合适相位、实际角速与力矩卸载条件满足后相邻交接。当前固定宽度6关节，不读取管径或管轴真值作为控制输入。
- 实机：默认基础圆弧，Ctrl+E切换固定截面顺应；原始负载和电流只记录，没有移植自动选窗。真实通信、失能关节编码器反馈、机械尺寸及运动效果尚待实机验证。

“整周期”指滚动指令相位推进2π，不是实测机器人绕管道转过一整圈。截面拟合也不等于控制半圆平面始终垂直地面。仿真接触反馈尚不能直接替换为未标定的电机负载或电流。

## 按需复现

以下命令在已激活`mujoco`的仓库根目录执行；每条只运行一个病例，另存目录，避免覆盖归档：

```powershell
python -X utf8 validation/fixed_section_experiment.py --scene taper_true90 --label my_taper90 --start -0.35 --duration 120 --exit-cycles 3 --output validation/results/my_section
python -X utf8 validation/sliding_section_experiment.py --scene elbow90_taper110_210 --label my_sliding --start -0.25 --duration 150 --exit-cycles 3 --output validation/results/my_sliding
```

实机软件离线检查：

```powershell
python -X utf8 -m unittest validation.test_real_controller validation.test_real_step2 -v
```

方法、完整判据和每轮复盘在上面的设计与实验记录中，不自动展开历史实验矩阵。
