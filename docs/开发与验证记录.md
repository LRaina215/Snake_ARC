- 基础圆弧：20关节，默认固定使能J8–J13；窗口外主动驱动力矩为零，保留模型中的机械阻尼。零目标角不代表失能。弯管使用同一滚动公式。

- 滑动窗口：两种版本均固定6关节。原接触版仅用于仿真，由整指令周期承重定位/力矩交接；新角度版只用实测角、采样时刻和已知相位，冻结正常相位基准并用同旋向弯曲确认迁移、几何条件相邻交接。200ms新反馈/20ms目标控制通过同一段自然例连续J6–J11→J5–J10→J4–J9，随后2周期开放和支撑通过；已同步现有仿真手调与实机单文件。未观测真实卸载，也未实现持续全相位定位。
- 实机：默认基础圆弧，Ctrl+1/2/3三模式、Ctrl+W自动选窗、Ctrl+E顺应开关；原始负载和电流只记录。角度滑窗已做全记录软件一致性和内存串口检查，真实通信、失能关节编码器反馈、机械尺寸及运动效果待用户验证。
- 角度观察器：首版持续端点拉动有效判断仅2.14%；新版加入冻结相位参考和同旋向弯曲证据。此前偏置例49.77%可用，新连续例73.69%，后段头侧失能端方向失真而拒绝观察；J4–J9继续头向受最短端限制。两次额外返回激励未制造共同证实的尾向迁移，返回未覆盖。

“整周期”指滚动指令相位推进2π，不是实测机器人绕管道转过一整圈。截面拟合也不等于控制半圆平面始终垂直地面。仿真接触反馈尚不能直接替换为未标定的电机负载或电流。

## 按需复现

以下命令在已激活`mujoco`的仓库根目录执行；每条只运行一个病例，另存目录，避免覆盖归档：

```powershell
python -X utf8 validation/fixed_section_experiment.py --scene taper_true90 --label my_taper90 --start -0.35 --duration 120 --exit-cycles 3 --output validation/results/my_section
python -X utf8 validation/sliding_section_experiment.py --scene elbow90_taper110_210 --label my_sliding --start -0.25 --duration 150 --exit-cycles 3 --output validation/results/my_sliding
```

实机软件离线检查：

```powershell
python -X utf8 -m unittest validation.test_real_controller validation.test_real_step2 -v
```

方法、完整判据和每轮复盘在上面的设计与实验记录中，不自动展开历史实验矩阵。
