# 单文件实机调试

从上电开始连续执行Ctrl+U建弧、Ctrl+5切Helix、Ctrl+7切回ARC，以及每阶段如何调速，请看[往返切换操作说明](上电到ARC_Helix往返切换操作说明.md)。

直接在已有 `mujoco` Conda环境或使用该解释器的IDE中运行：

```powershell
python codes/Rolling_Arc_Real.py
```

无需命令行参数、EXE或外部可视化程序；复制这一份Python文件也能运行。默认自动查找CH340，启动等待Ctrl热键，附带实测全身构型预览。相位均衡的自动位置/数量选择已同步，实机效果待用户验证。

**Ctrl+4主动送链已按用户要求恢复到84b28cb版本**：Ctrl+J/H各启动一次相对调长任务，默认64.5 mm，到位保持、无自动返回；首次按键按`FEED_AMPLITUDE_DEG / FEED_PREPARATION_S`执行旧版建形，后续任务沿用已有弯曲分布。撤回后来加入的模式4实测起态平移、缓冲回收及反向恢复逻辑。模式1～3与当前预览保留。现场调参、热键和限制见[实机验收说明](主动送链实机验收说明.md)，检查范围见[回退记录](../validation/reports/mode4_rollback_20261021/README.md)。

## 首次操作

1. 当前实机18关节，顶部默认 `NUM_JOINTS=18`、ID为1–18、波特率115200。零位采用2026-11-07用户确认直线姿态的新校准，见 `configs/hardware_18j_reference.json` 与[零位核对记录](../validation/reports/hardware18_zero_20261107/README.md)。ID和校准表按数量取值；非连续硬件ID仍按实际修改对应关系，新增关节须补真实零位。
2. 运行后观察预览中的J1–J18实际角。尚未接管时显示“使能状态未知”，读角不改变扭矩。
3. Ctrl+U从实测角预置，局部使能并缓慢形成圆弧；等待形成和静置完成。
4. Ctrl+1基础圆弧，Ctrl+2固定当前窗口顺应，Ctrl+3自动移窗与数量自适应；Ctrl+G连续，Ctrl+J单步。
5. Ctrl+N冻结目标，Ctrl+空格只暂停相位而继续顺应。Ctrl+X全部失能；Ctrl+Q退出并清理。

Ctrl+W同时开关自动位置/数量选择，关闭后继续当前窗口局部顺应。Ctrl+E切基础/固定顺应，自动模式中返回基础。扩缩后切模式保持窗口和目标连续性；只有基础模式使用当前数量的名义圆弧，固定/滑窗顺应直接由实测截面生成目标，不拉回名义圆弧。

2026-10-13已恢复参考仓库的实测截面控制规律，并修复滑窗重复时间戳停控。手调顺应使用 `gain / filter`，原 `yielding` 恢复权重已取消。验证与待实测范围见[本轮记录](../validation/reports/measured_section_restore/README.md)。

实机和仿真的键位、三模式、左右扰动测试与场景设置见[统一调试说明](仿真实机统一调试说明.md)。仅使用Ctrl组合，不使用F键；两个入口不应同时运行，否则全局热键都会响应。

## ARC→Helix与重力矩避障

在稳定搭管ARC上直接按Ctrl+5，或先Ctrl+4用J/H调长、停稳后按5。接入时重新读取全身角度，取实际承载弧，按当前形状判断是否进一步自动调长；不把模式4的缓冲使能当成固定起卷窗口。Ctrl+J/G先形成前部螺旋，前部成形／就位时实物已搭稳，可直接Ctrl+L确认；程序保持当前前部目标并进入 `first_shift`，再J/G逐节送尾，重复L不重置进度。5到 `complete` 后保持完整Helix。

Ctrl+6从ARC先完成相同的Helix切换，从5完成态则直接进入 `align`。对准支管后暂停、Ctrl+L确认，再Ctrl+J开始单步解旋；右U搭稳与尾部自然下垂分别确认后继续推进。5/6的J每次默认最多推进1 s控制动作后保持，L只确认阶段；这与模式4的J/H整段调长、L强制推进不同。

全身已使能时Ctrl+5可选择 `helix_normalize`，再J/G逐渐恢复为统一Helix；该操作不启动T管动作。首次送尾结束也自动经过此阶段。重启后已有全身螺旋时可5按实测角预置接管。目标一致性已验证，实际贴管仍待验收，详见[归形修复记录](../validation/reports/helix_normalization_20261107/README.md)。

当前支持从已验证范围内的不同两侧长度ARC自主准备，尚未证明任意散乱姿态均可成功或能求得全局最佳位置。仿真脚本的自动对准判据不进入实机，现场由用户L确认，录像时长不是固定等待门槛。[完整操作、录像含义与参数](ARC_Helix与重力矩越障操作说明.md)；[18关节10类仿真复盘](../validation/reports/sequential_handoff/README.md)。实机效果等待用户验收。

## 可读的调参位置

| 位置 | 内容 |
| --- | --- |
| 顶部基本参数 | 串口、日志、初始窗口、幅值、频率、单步和形成速度 |
| `HELIX_* / GRAVITY_*` | 切换的半径／螺距、前部预算、J单步时间、解旋／释放和回卷参数 |
| `SHOW_PREVIEW / PREVIEW_PERIOD_S` | 全身预览开关、目标刷新间隔 |
| `COMPLIANCE_* / SECTION_*` | 局部截面曲率反馈、滤波、目标与实际形态约束 |
| `MOTOR_SLIDING_* / POSTURE_*` | 自动开关、冷却、相位均衡数量滞回、持续时间、交接角度 |
| `LINK_LENGTHS_M` | NUM_JOINTS+1段；18关节对应19段铰链中心/端点距离，不是外壳尺寸 |
| `joint_angles_deg / SectionReference` | 基础模式初始圆弧；不作为顺应目标的恢复项 |
| 第3B段 `FixedSectionCompliance.update` | 实际角→截面重建→连续曲线→局部曲率→目标角 |
| `PhaseBalancedCount / PostureWindow._select` | 同相位数量判断及相邻窗口选择 |
| `PostureWindow._handover` | 运动中交接、候选形状与目标连续性检查 |
| `RollingArcController.select_gait / tick_motor_sliding` | 热键接管、读角时钟、目标和使能写入 |
| `select_helix / select_gravity / command_helix / GravityCrossing` | 当前形状重新规划、5/6热键、阶段确认与拼接曲线接管 |
| `JointPreviewFigure / preview_payload` | 只读构型绘图与候选方向显示 |
| `FeetechBus` | 飞特报文、校准、进入ID预置和0x28扭矩使能 |

默认`DIY_PARAMETERS=True`：三模式均可输入 `amplitude=70 omega=0.8 delta=0.05`、`gain=0.02 yielding=0.7 filter=0.15`，允许反向单步。取消建形前完整周期峰值/角速度拦截、±90°软件档案限位、固定顺应的开放形态接入/目标拒绝和滑窗60°/0.6硬限制；不会悄悄改回60°。手动改 `window=8:13` 仍在失能后执行。顺应截面数学结构需在J2..J(NUM_JOINTS−1)内连续至少3关节，当前18关节为J2..J17；基础模式可用J1..J18。详细范围与检查见[DIY调参记录](../validation/reports/manual_diy/README.md)。

新连接件的精确转轴／端点尺寸仍待核对，目前 `LINK_LENGTHS_M`保留旧仿真64.5 mm。外形102 mm、相邻电机中心78 mm或同类电机中心146 mm不能直接混作同一种长度。新零位解决角度基准问题，不代表新几何与完整运动已验收。

形成斜率`FORM_RATE_DEG_S`、运行目标限速`MAX_TARGET_RATE_DEG_S`、静置`SETTLE_S`以及顺应滤波仍按顶部设置执行；取消的是据此拒绝启动/接入的拦截，未将形成过程改成瞬时跳角。原始舵机速度寄存器也保留可编辑。协议可编码的0..4095位置范围、有限值、通信/反馈失败处理和Ctrl+X失能保留。

DIY滑窗按当前幅值、窗口与尺寸生成名义几何参考，不直接把原60°标定残差套到新参数上。参数改变后清空旧交接候选并重建观察器；允许进入自动模式不等于必然移窗，仍依据可用形状观测、相邻交接和目标连续性决定动作。DIY的新参数和几何参考尚未完成运动验证，交由用户实测。`DIY_PARAMETERS=False`恢复原研究参数/形态限制。

`amplitude=60`在归一化参考中是半圆缩放基准，七关节时不会让每个关节都达到60°。失能是向0x28写0，不发送零角位置目标。扩窗只对新进入ID预置实测角与配置；缩窗关闭退出ID，公共关节保留目标。原始负载/电流只记录，不参与顺应、支撑判断或移窗。

## 预览与反馈

预览保留连杆折线，并叠加控制内部的平滑截面：青绿色为实测控制输入，洋红色为滤波前顺应候选；橙色折线表示已下发目标。两种“目标”可能因滤波/限速而有差别，图例分别注明。曲线来自当前控制缓存，不新增控制计算；未开启顺应时的曲线明确标注为同法重建。

预览直接正视控制器由实测关节拟合的截面平面，按当前关节数量显示J1–J18全部关节，并在平面内按估计重力朝下定向（2026-10-21起，[原20关节检查记录](../validation/reports/full_body_section_preview_20261021/README.md)）；右侧保留全身角度对照、使能颜色、候选方向与数量估计。u/v坐标来自实际截面原点及基底，没有重力视图切换按钮。目标和实测统一使用实测截面坐标，面外偏差不显示，应同时参考角度差。陈旧反馈明确提示。[方法与验证边界](关节重建截面预览说明.md)。

预览在独立进程中绘图；主控制只发送显示快照，不等待绘制。开启后即使未接管或已失能，也会只读全部18个角度；不自动形成圆弧、不修改扭矩。关闭预览不停止控制。软件显示的使能是已写入并核对的控制掩码，不能测得实际输出力矩。

全关节反馈目标间隔200 ms，控制20 ms；包含失能舵机的有效编码器读数。反馈超0.8 s或串口故障时退出并尝试失能；断连时软件不能保证失能已执行。原始速度/加速度/力矩限制沿用协议值，`TORQUE_LIMIT_RAW=300`不是300 N·m。当前参考表来自仿真角记录，可在之后按真实读角重新标定。

## 同步与验证

开发工具 `tools/build_real_motor_core.py` 将已批准研究核心及6/8参考表显式复制进标记区，`tools/build_real_section_core.py`复制固定截面数学区。日常运行完全不需要生成器；现场手改数学区后不要运行生成器覆盖自己的修改。其余数量的相位参考是几何迁移假设，未声称任意数量都验证过。
