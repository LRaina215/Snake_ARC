# 单文件实机调试

直接在已有 `mujoco` Conda环境或使用该解释器的IDE中运行：

```powershell
python codes/Rolling_Arc_Real.py
```

无需命令行参数、EXE或外部可视化程序；复制这一份Python文件也能运行。默认自动查找CH340，启动等待Ctrl热键，附带实测全身构型预览。相位均衡的自动位置/数量选择已同步，实机效果待用户验证。

## 首次操作

1. 在顶部核对 `PORT / SERVO_IDS / ZERO_RAW / SERVO_DIRECTION / MODEL_TO_SERVO_SIGN / LINK_LENGTHS_M`。默认沿用参考项目20舵机校准、115200波特率。
2. 运行后观察预览中的J1–J20实际角。尚未接管时显示“使能状态未知”，读角不改变扭矩。
3. Ctrl+U从实测角预置，局部使能并缓慢形成圆弧；等待形成和静置完成。
4. Ctrl+1基础圆弧，Ctrl+2固定当前窗口顺应，Ctrl+3自动移窗与数量自适应；Ctrl+G连续，Ctrl+J单步。
5. Ctrl+N冻结目标，Ctrl+空格只暂停相位而继续顺应。Ctrl+X全部失能；Ctrl+Q退出并清理。

Ctrl+W同时开关自动位置/数量选择，关闭后继续当前窗口局部顺应。Ctrl+E切基础/固定顺应，自动模式中返回基础。扩缩后切模式保持窗口和目标连续性；只有基础模式使用当前数量的名义圆弧，固定/滑窗顺应直接由实测截面生成目标，不拉回名义圆弧。

2026-10-13已恢复参考仓库的实测截面控制规律，并修复滑窗重复时间戳停控。手调顺应使用 `gain / filter`，原 `yielding` 恢复权重已取消。验证与待实测范围见[本轮记录](../validation/reports/measured_section_restore/README.md)。

实机和仿真的键位、三模式、左右扰动测试与场景设置见[统一调试说明](仿真实机统一调试说明.md)。仅使用Ctrl组合，不使用F键；两个入口不应同时运行，否则全局热键都会响应。

## 可读的调参位置

| 位置 | 内容 |
| --- | --- |
| 顶部基本参数 | 串口、日志、初始窗口、幅值、频率、单步和形成速度 |
| `SHOW_PREVIEW / PREVIEW_PERIOD_S` | 全身预览开关、目标刷新间隔 |
| `COMPLIANCE_* / SECTION_*` | 局部截面曲率反馈、滤波、目标与实际形态约束 |
| `MOTOR_SLIDING_* / POSTURE_*` | 自动开关、冷却、相位均衡数量滞回、持续时间、交接角度 |
| `LINK_LENGTHS_M` | 21段铰链中心/端点距离，不是外壳尺寸 |
| `joint_angles_deg / SectionReference` | 基础模式初始圆弧；不作为顺应目标的恢复项 |
| 第3B段 `FixedSectionCompliance.update` | 实际角→截面重建→连续曲线→局部曲率→目标角 |
| `PhaseBalancedCount / PostureWindow._select` | 同相位数量判断及相邻窗口选择 |
| `PostureWindow._handover` | 运动中交接、候选形状与目标连续性检查 |
| `RollingArcController.select_gait / tick_motor_sliding` | 热键接管、读角时钟、目标和使能写入 |
| `JointPreviewFigure / preview_payload` | 只读构型绘图与候选方向显示 |
| `FeetechBus` | 飞特报文、校准、进入ID预置和0x28扭矩使能 |

默认`DIY_PARAMETERS=True`：三模式均可输入 `amplitude=70 omega=0.8 delta=0.05`、`gain=0.02 yielding=0.7 filter=0.15`，允许反向单步。取消建形前完整周期峰值/角速度拦截、±90°软件档案限位、固定顺应的开放形态接入/目标拒绝和滑窗60°/0.6硬限制；不会悄悄改回60°。手动改 `window=8:13` 仍在失能后执行。顺应截面数学结构需要J2..J19内连续至少3关节；基础模式可用J1..J20。详细范围与检查见[DIY调参记录](../validation/reports/manual_diy/README.md)。

形成斜率`FORM_RATE_DEG_S`、运行目标限速`MAX_TARGET_RATE_DEG_S`、静置`SETTLE_S`以及顺应滤波仍按顶部设置执行；取消的是据此拒绝启动/接入的拦截，未将形成过程改成瞬时跳角。原始舵机速度寄存器也保留可编辑。协议可编码的0..4095位置范围、有限值、通信/反馈失败处理和Ctrl+X失能保留。

DIY滑窗按当前幅值、窗口与尺寸生成名义几何参考，不直接把原60°标定残差套到新参数上。参数改变后清空旧交接候选并重建观察器；允许进入自动模式不等于必然移窗，仍依据可用形状观测、相邻交接和目标连续性决定动作。DIY的新参数和几何参考尚未完成运动验证，交由用户实测。`DIY_PARAMETERS=False`恢复原研究参数/形态限制。

`amplitude=60`在归一化参考中是半圆缩放基准，七关节时不会让每个关节都达到60°。失能是向0x28写0，不发送零角位置目标。扩窗只对新进入ID预置实测角与配置；缩窗关闭退出ID，公共关节保留目标。原始负载/电流只记录，不参与顺应、支撑判断或移窗。

## 预览与反馈

预览保留连杆折线，并叠加控制内部的平滑截面：青绿色为实测控制输入，洋红色为滤波前顺应候选；橙色折线表示已下发目标。两种“目标”可能因滤波/限速而有差别，图例分别注明。曲线来自当前控制缓存，不新增控制计算；未开启顺应时的曲线明确标注为同法重建。

预览直接正视控制器由实测关节拟合的截面平面，聚焦局部使能段及边界连杆；右侧保留全身角度对照、使能颜色、候选方向与数量估计。u/v坐标来自实际截面原点及基底，已取消重力视图和切换按钮。目标和实测统一使用实测截面坐标，面外偏差不显示，应同时参考角度差。陈旧反馈明确提示。[方法与验证边界](关节重建截面预览说明.md)。

预览在独立进程中绘图；主控制只发送显示快照，不等待绘制。开启后即使未接管或已失能，也会只读全20个角度；不自动形成圆弧、不修改扭矩。关闭预览不停止控制。软件显示的使能是已写入并核对的控制掩码，不能测得实际输出力矩。

全关节反馈目标间隔200 ms，控制20 ms；包含失能舵机的有效编码器读数。反馈超0.8 s或串口故障时退出并尝试失能；断连时软件不能保证失能已执行。原始速度/加速度/力矩限制沿用协议值，`TORQUE_LIMIT_RAW=300`不是300 N·m。当前参考表来自仿真角记录，可在之后按真实读角重新标定。

## 同步与验证

开发工具 `tools/build_real_motor_core.py` 将已批准研究核心及6/8参考表显式复制进标记区，`tools/build_real_section_core.py`复制固定截面数学区。日常运行完全不需要生成器；现场手改数学区后不要运行生成器覆盖自己的修改。其余数量的相位参考是几何迁移假设，未声称任意数量都验证过。

本轮同步没有加入新回正算法，没有真实硬件连接或新动力学实验。已有缩径小幅超限保留为已知限制，用户已要求先开展手动测试。检查及交接状态见[同步记录](自主窗口实机同步说明.md)和[软件验证报告](../validation/reports/posture_port/README.md)。
