# 圆弧滚动实机调试：三模式与6关节自动滑窗

当前入口为`codes/Rolling_Arc_Real.py`，只运行这一份Python文件即可直接通过串口控制真实舵机。默认基础圆弧/J8–J13，Ctrl+1/2/3切基础、固定截面顺应、仅角度反馈自动滑窗；Ctrl+E仍开关顺应。滑窗保持6关节，外侧扭矩关闭，不扩缩数量。本轮同步了仿真连续两次交接通过的方法，未连接真实机器人，实机效果由用户验证。

无需MuJoCo、EXE或本仓库其他Python文件；依赖pyserial、pynput、NumPy。算法和校准数据在单文件内，复制到其他目录也可运行。串口、机械尺寸、公式和顺应参数集中在文件顶部与标明的函数中。

需要相同操作的仿真时，直接运行`codes/Rolling_Arc_Debug_Mujoco.py`。三种仅角度模式共用本实机控制器与Ctrl热键，反馈来自真实模型角，不连接串口；仿真额外支持Ctrl+A/D物理拉动及重新预览。详见[统一调试说明](仿真实机统一调试说明.md)。原自动研究入口保留。

## 启动与最短操作

沿用现有Conda环境`mujoco`，在仓库根目录执行；本机依赖已齐全，无需安装：

```powershell
conda activate mujoco
python codes/Rolling_Arc_Real.py
```

和CaseA参考脚本一样，默认直接查找CH340串口，波特率115200；需要固定端口时在文件顶部将`PORT = None`改成`PORT = 'COM9'`等实际端口。没有找到或找到多个CH340时，会说明原因并退出，多个适配器需在顶部明确选择。脚本独占串口，原EXE等串口程序应关闭。

所有实验配置在文件顶部修改，不再通过命令行配置。也可在选择`mujoco`解释器的IDE中直接运行文件。默认`DRY_RUN = False`控制真实机器人；改为`True`可用内存串口演练同一热键流程。演练结束后改回`False`。

默认`SAVE_LOG = True`，在Python文件旁的`logs/`目录自动生成带时间的新JSONL，不依赖当前工作目录，也不覆盖旧日志；本仓库路径为`codes/logs/`。需关闭记录时改为`SAVE_LOG = False`，修改保存位置用顶部`LOG_DIRECTORY`。

操作顺序：**Ctrl+U形成基础圆弧 → 等待形成与静置结束 → Ctrl+J/H单步或Ctrl+G连续 → Ctrl+E开顺应 → 再按Ctrl+E回基础。**

启动仅打开串口，不自动使能或运动。Ctrl+U读取主动关节实际位置，预置位置目标，再写入固定使能掩码并读回全部20个使能状态。缓慢形成名义圆弧，完成后保持；默认相位0、幅值60°，奇数主动关节60°、偶数0°。从零位形成约4 s命令时间，另静置2 s；这不是实机到位时间测量。重复Ctrl+U不会重新归零。

## 热键与控制台

沿用参考顺应性程序的Ctrl组合键和虚拟键码解析，不使用F5/F6。按住按键不会重复排入单步。热键全局有效，普通字母与普通空格不绑定。

| 热键 | 控制台命令 | 当前行为 |
| --- | --- | --- |
| Ctrl+U | `apply` / `arm` | 读取、预置、使能固定窗口，缓慢形成基础圆弧，完成后保持 |
| **Ctrl+E** | **`compliance`** | **固定截面顺应开/关**；保持窗口和相位，保留连续/暂停/单步状态 |
| Ctrl+1 / 2 / 3 | `gait_basic / gait_fixed / gait_sliding` | 基础 / 固定截面 / 角度反馈自动滑窗；保留当前窗口与相位 |
| Ctrl+W | `window_auto` | 自动请求开/关，关闭时取消尚未完成的角度交接 |
| Ctrl+J / Ctrl+H | `step` / `back` | 正/反单步；形成/静置阶段排队等待，步长默认0.1 rad |
| Ctrl+G | `toggle` | 连续/暂停切换；三种模式都适用 |
| Ctrl+空格 | `pause` | 停止相位；顺应模式继续根据实测形状调整目标 |
| Ctrl+N | `hold` | 冻结并重发最近目标，顺应计算不再改变目标 |
| Ctrl+T | `reverse` | 反转后续相位推进方向，不在操作瞬间翻转姿态 |
| Ctrl+- / Ctrl+= | `delta-` / `delta+` | 单步步长减半/加倍，快捷范围0.01–0.6 rad |
| Ctrl+上 / 下 | `amplitude_up` / `amplitude_down` | 幅值±2°，限速调整 |
| Ctrl+右 / 左 | `omega_up` / `omega_down` | 角频率±0.05 rad/s |
| Ctrl+K | `status` | 读取20关节角及原始负载/电流，显示当前步态与阻塞原因 |
| Ctrl+X | `release` | 全部失能并读回确认；会失去主动支撑，与暂停不同 |
| Ctrl+Q | `quit` / `exit` | 退出；接管后尝试全失能并关闭串口 |

也可在控制台输入对应命令后回车；`run`明确连续，`pause`明确暂停，`help`显示操作说明。

Ctrl+E只在基础圆弧形成、静置完成且实测形态符合开放圆弧条件后允许开启；未接管时按E不会自行使能。开启保留最近目标，通过滤波和限速软接入。关闭保留最近目标和相位，先按形成速度恢复该相位的基础圆弧，不额外静置；随后原连续/单步模式继续，原暂停模式保持。开启/关闭本身不写新的使能掩码。

## 顺应算法与反馈边界

当前移植的是已验证仿真中的固定截面方法：实际角→正运动学→主动半圆平面拟合→连续线圆弧→局部长度归一化→Yamada积分，使用同相位参考校准、K=0.02、yielding=0.7、目标转角≤190°与开口比≥0.4。取消强制内弯D规则，保持零空间扭转参考。它与旧的奇偶角幅值代理/自动窗口方法不同。

固定截面输入仅实测关节角、连杆尺寸、当前掩码及控制相位。**原始负载和电流只记录，不参与支撑判别或顺应目标；不读取管径，也不控制截面平面始终垂直地面。**`gain=0`仍有实际形状反馈，不能替代Ctrl+E关闭顺应。

自动滑窗额外由全20角重建被动端和实际圆弧：两个可靠悬垂端估计向下，冻结正常相位基准剔除正常滚动偏移，用冠部和同旋向弯曲迁移共同确认相邻窗口；再等待零相位、小角、连续新反馈低速、候选开放，进行几何交接。没有角反馈能直接证明支撑或卸载。两端至少3段被动关节，候选范围J4..J17；不满足则拒绝。本轮仅向头侧连续两次通过，尾向/往返未覆盖。

滑窗参考限定60°/.6/正向/21段64.5mm；滑动模式拒绝Ctrl+H/T以及改幅值、频率、window，先切回基础/固定。暂停相位继续顺应，Ctrl+N冻结目标并停止交接，Ctrl+W取消待交接。新实际形态无效保持旧目标/掩码并锁定暂停，需重新选模式；可Ctrl+1回基础。具体范围见[连续移窗复盘](../validation/reports/repeated_motor_sliding/README.md)。

发送控制周期20 ms；几何最短更新间隔50 ms，在20 ms循环中通常量化为60 ms。全20舵机角反馈目标间隔200 ms，顺序扫读；两次采集之间使用最近反馈进行计算，不能把几何计算次数当成新的测量次数。串口读取耗时会降低实际发送/采集频率，程序不追赶阻塞期间漏掉的相位帧。

全20关节（包括失能关节）的编码器应仍有供电并返回有效实际角。反馈按最早样本计龄，超过0.8 s或读失败时终止并尝试失能。实际形态超出150–218°、开口0.4或平面RMS15 mm时暂停相位并保持最近目标；名义参考/过滤后发送目标不满足开放约束时同样保持。新有效角反馈恢复后仍停在保持状态，需用户重新开始滚动。可按E回基础。此形态检查不证明管道承重充分或严格管轴覆盖。

## 调参位置

| 位置 | 通常修改的内容 |
| --- | --- |
| 文件顶部基本参数 | 自动/固定端口、内存演练与日志开关、固定关节范围、幅值、ω、单步步长、形成速度、反馈间隔 |
| 文件顶部固定截面参数 | K、yielding、目标滤波、目标转角/开口、实际形态有效范围 |
| 文件顶部`MOTOR_SLIDING_*` | 自动开关、冷却、小角/速度/连续新反馈交接门槛；改值后需重新验证 |
| `LINK_LENGTHS_M` | 21段铰链中心/端点距离，单位m；当前采用仿真骨架64.5 mm，不是外壳长度 |
| `SERVO_IDS / ZERO_RAW / SERVO_DIRECTION` | 20舵机ID、逐舵机零位和安装方向 |
| `MODEL_TO_SERVO_SIGN` | 控制器角→协议角的坐标转换，当前奇数+、偶数− |
| `joint_angles_deg()` | 基础圆弧公式，同时作为顺应模式名义参考 |
| 第3B段`local_section / yamada_section / FixedSectionCompliance.update` | 截面重建、曲率积分与反馈律；内部单位rad和m |
| `RollingArcController.toggle_compliance / tick_compliance` | 模式开关、固定掩码、反馈有效性和逐帧目标发送 |
| `select_gait / tick_motor_sliding / motor_sample_clock` | 三模式接管、自动移窗目标/掩码更新、新反馈与控制时钟 |
| 第4段`FeetechBus` | 报文和角换算；一般调步态无需修改 |

第3A段保留旧核心，仅供早期仿真历史对照导入，当前实机Ctrl+E不使用它。调实机请修改第3B段和顶部当前参数。若要同步模块化仿真核心，可显式执行`python tools/build_real_section_core.py`；它会覆盖标记的3B数学核心，保留实机协议与调试层，运行实机时不需要此工具。

`BEGIN MOTOR_SLIDING_CORE`区域内是可读的纯角度观察/交接代码及冻结参考；开发时`tools/build_real_motor_core.py`从模块复制该区域，保留顶部参数和串口/操作层，需本轮通过的范围审查。手动修改该区域后不要直接运行生成器覆盖修改；日常实机完全不需要生成器或其他项目文件。

运行时例子：

```text
pause
gain=0.02 yielding=0.7 filter=0.15
amplitude=58 omega=0.5 delta=0.05
step
compliance
run
```

整行参数先验证再提交，无效输入不留下部分修改。固定范围只能释放后手动改为连续6关节；没有在线扩缩。旧`support=...`、`load=...`及`--support`接口已移除。舵机速度、加速度、力矩限制仍为原始协议值，`TORQUE_LIMIT_RAW=300`不是300 N·m，也未在本轮标定成N·m。
