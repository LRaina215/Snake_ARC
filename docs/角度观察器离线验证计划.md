# 角度观察器：仅输出判断的离线验证计划

本轮使用已有两份完整侧拉记录，不运行新的动力学实验、不下发关节目标、不执行移窗、不更新实机。只开发纯关节角观察器与离线评价工具。原自动控制器在端点病例中已经执行过移窗，因此其交接后的数据单独报告，不作为新观察器提前定位成功的证据。

## 冻结条件与假设

- 输入档案：`validation/reports/debug_modes/whole_body_trace.jsonl.gz`及`endpoint_pull_trace.jsonl.gz`，每份1700帧，113 mm直管，20关节；原始文件不修改。
- 观察器输入白名单：20个`measured_controller_deg`实测角、反馈时刻、已知滚动相位、当前实际使能掩码。机械长度21×64.5 mm与名义幅值60°是静态配置，不读取记录中的位置目标。
- 禁止进入观察器的字段：完整自由根部位姿/速度、真实重力方向、接触力、主动关节力矩、管径/管轴、施力时段标签及原选窗事件。它们只能在输出已生成后用于评价。
- 假设H1：两侧失能端在自然悬垂时提供一致的向下方向；若形状或一致性不足，则明确拒绝判断，不能用假重力继续选窗。
- 假设H2：实际顶部圆弧在身体上的位置相对相位参考的偏移，可以反映托管区域迁移；主动控制可能把几何圆弧固定在原窗口，这正是本轮要核对的风险。
- 假设H3：新观察器的圆弧位置/窗口建议与支撑区域相符。原接触定位器的移窗时刻不是新方法必须复现的“标签”。

## 首版规则（运行前冻结）

1. 按已有关节符号约定正运动学，重建全身头部坐标系骨架。
2. 两侧各取远端最多4根失能连杆，至少3根；以从圆弧朝端点的弦方向估计悬垂方向。弦长/路径长均≥0.98、两端方向夹角≤25°才可使用其归一化均值。该方向是有物理假设的估计，不是已知重力。
3. 当前6关节拟合截面平面，检查既有开放条件：转角150–218°、开口≥0.4、平面RMS≤15 mm。扩展观察范围至两侧各2个关节，用同一平面投影并构建连续线圆弧；曲线点仍保留沿身体的连续关节坐标。
4. 用估计向下方向确定高度，在最高处约1/8连杆长度（8.06 mm）的顶部带内做加权中心，得到冠部的连续关节位置。用已知60°基础波、当前窗口与相位生成名义形状，计算同口径的相位参考；不读取目标反馈、不用接触数据拟合参考。
5. 冠部相对名义参考的偏移以0.2 s一阶过滤。越过±0.5关节并持续0.5 s，且对应相邻6关节的实际开放条件也合格，才输出头/尾方向的窗口建议。使能掩码变化时清空确认状态；不将建议当作已执行窗口。
6. 低可信、曲线不可拟合或候选不开放时输出原因。观察器没有执行器接口。

±0.5关节对应相邻窗口的几何分界；其余新阈值是本轮工程门槛，尚未实机标定。不得看完施力结果后搜索参数使它通过。若首版失败，保留失败与原因，是否改进另行依据本轮结论决定。

## 数量、评价及验收

只进行1轮、2份已有记录的完整离线回放，共3400帧；不做低阻尼、延迟或新增场景矩阵。若代码有确定的实现错误，修复后重做同一回放并保留错误说明，不算新增动力学实验。必要的针对性软件检查只覆盖输入边界、状态确认及禁止执行。

- 正常滚动：无窗口建议，且有效判断覆盖至少80%；全拒绝不能算“不误报通过”。名义参考来自公式，未用这两份记录训练。
- 拉动后：分别报告有没有实际几何冠部迁移、有没有支撑分布迁移、观察器是否识别及首次持续建议时刻，不强制将两种迁移等同。端点病例须在原掩码交接前检验；交接后只是被原控制器改变形状的额外审查。
- 支撑相符：按原覆盖口径，检查建议窗口对向上支撑的覆盖是否≥0.8，并与当前/两个邻居逐帧比较。仅“覆盖高”不能证明移窗必要或有收益。
- 定位可信：在有效判断帧，几何冠部位置误差90分位≤0.5关节，估计向下方向相对评价真重力≤15°。同时报告全部误差和最差状态，不只报合格帧。
- 施力有效判断覆盖至少50%；大量拒绝判断意味着当前角度条件不足，不能当作成功。

评价真值使用同一反馈时刻的原实际状态，不能将反馈角与20 ms后的接触混用；第一帧若没有匹配的上一状态则标为评价缺失。另用真实重力方向计算同一几何冠部作原因诊断，明确标为仿真参照、不能算角度观察器。若在真重力下冠部也不随支撑迁移，说明该几何特征不足，增加IMU未必解决。

全程检查原实际开放形态、曲率、支撑、掩码、限位与力矩，并继承原完整审查结论。本轮没有控制或越障，不能报告新步态通过、闭环移窗通过或实机通过。输出逐帧白名单输入、判断、评价、时序图、最差状态与复盘，明确已确认事实、原因判断、未验证范围和下一项最小动作。

## 实现错误修复记录

首轮完整回放后，曲线分段不变性检查确认数值错误：一段64.5 mm直线被分出0.1 mm短段后，同一几何曲线的顶部中心改变0.230关节，原因是每片段同样数量的点没有按弧长加权。保留首轮全部输出和原实现，改为每片段中点采样、以弧长为积分权重，重做同样两份记录。工程阈值没有调整，也没有新增动力学实验。最终结论以数值修复后的结果为准，不能将首轮的具体误差数字混用。针对性软件检查增加1项分段不变性，共3项。
