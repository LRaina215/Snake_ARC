# 仅电机反馈的六关节滑动窗口

## 输入与模块

`motor_shape_observer.py`只接收20个实测关节角、采集时刻、已知指令相位与当前使能掩码，机械长度为21×64.5 mm。它复用头部坐标系正运动学、实际截面投影和连续线圆弧，不访问MuJoCo或执行器。

`motor_feedback_sliding.py`执行同一固定截面顺应核心，并消费观察器建议。角速度由相邻新角反馈差分；输入中没有世界姿态、管道几何、接触力、qvel或N·m力矩。`motor_feedback_simulation.py`在20 ms反馈边界只传角与时刻；每1 ms的内层PD使用模型速度模拟舵机位置环，不把该速度交给外层滑窗。

目前验证的是理想同步角反馈，不是实机串口采集时序。实机代码保持不变，不能把本轮结果写成实机通过。

## 定位：冻结相位参考与弯曲迁移共同判断

1. 由两侧各最多4个、至少3个被动末端连杆估计向下方向。末端弦长/路径长≥0.98，两端方向夹角≤25°；当前实际圆弧转角150–218°、开口≥0.4、平面RMS≤15 mm才具备判断条件。低可信时不建议移窗。
2. 用实测骨架的平滑曲线顶部带计算冠部身体坐标，带宽8.06 mm。参考来自已有正常滚动的第一个完整指令周期，共24格；取每格中位数并做周期插值。它以窗口中点为零，按局部奇偶族换算相位，不在滑动、停相位或移窗后继续学习。
3. 另在实际截面平面上观察窗口两侧各2关节，将**与主圆弧同旋向**的曲率积分作为弯曲质量，求沿身体的中心和两侧被动边界弯曲差。反向折弯单独记录，不能用所有舵机角绝对值冒充上方圆弧。
4. 冠部残差过滤0.2 s，超过±0.5关节，同时同方向弯曲中心残差≥0.2关节或被动边界弯曲差残差≥8°；相邻候选也必须实际开放，并连续成立0.5 s，才输出一步建议。反馈间隔超过0.1 s则清除持续判断，重新建立新反馈连续性。

冻结基准当前只支持60°、omega=0.6、正向；跨窗口的局部相位换算通过几何检查并在本偏置病例使用，但尚未在其他管径/弯管上验证。它是实际滚动参考，不是通用、与速度无关的几何常数。现有两端一致性也不能识别共同偏斜，持续人工侧拉仍有已确认的失效范围。

## 执行：同奇偶轴的相邻交接

从J5–J10到J4–J9，退出J10、进入J4，同为偶数轴。等待sin(phi)接近0（绝对值≤0.015），停止推进相位，但物理和反馈继续运行。进入/退出角≤4°、差分角速≤8°/s、候选实际和预置目标开放；先保持至少0.1 s，再有连续0.06 s的新反馈满足条件，才交换掩码。

新进入关节以当前位置预置，五个重叠关节保留原目标，退出关节立即主动力矩为0。任何时刻都是6个使能，不使用7关节并集。退出关节的接触/卸载并未被控制器观测；这是几何条件下的交接试验，不能称为已确认卸载。20 s未满足条件则拒绝；完成后5 s冷却。真实反馈中断不能计入交接的连续就绪时间，也不补跳盲区相位。

两端各至少3个被动关节使候选窗口当前受限于J4–J17内部；例如J4–J9不能再向头部移动。这是观察器范围限制，不是舵机不能控制J3，也不是窗口扩缩。

## 在现有手调入口验收

仍运行`codes/Rolling_Arc_Debug_Mujoco.py`，默认`SLIDING_FEEDBACK='motor_angles'`，Ctrl+3接入本方法；Ctrl+1/2仍为基础/固定截面。Ctrl+W开关自动请求，已经开始的交接继续受几何门槛约束；Ctrl+N冻结目标，Ctrl+空格暂停相位，Ctrl+X全失能。HUD显示角度观察器状态、偏移和几何交接保持，不把接触承重显示为控制输入。

该文件顶部`SIM_FIRST_JOINT / SIM_LAST_JOINT`可修改初始搭管区域；本轮病例为5/10，默认仍沿用8/13。`SIM_AMPLITUDE_DEG / SIM_OMEGA_RAD_S`默认60/.6，独立于实机文件，避免实机现场调参改变已验证基准。修改的是仿真配置，不必改实机文件。将`SLIDING_FEEDBACK`改为`contact`可保留原接触反馈版本；自动研究旧入口仍使用原接触核心。

角度模式中不接受改变幅值、频率或反向滚动，因为冻结基准未标定这些条件；先切换基础/固定模式再调试。Ctrl+A/D仍是物理端点拉动，但持续拉动不属于本方法已通过范围，不能把没有建议直接解释为没有迁移。

本轮计划与完整结果见`实机反馈固定宽度滑窗实验计划.md`和`validation/reports/motor_feedback_sliding/README.md`。
