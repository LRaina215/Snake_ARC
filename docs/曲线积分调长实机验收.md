# 曲线积分调长：真实机器人试机

当前 `codes/Rolling_Arc_Real.py` 已内嵌仿真验证过的曲线目标生成器，默认 `DRY_RUN=False`，直接通过飞特串口给真实舵机下发指令。只需这一份Python文件，不启动MuJoCo，也不需要实验目录或额外命令行参数。

在原来的Python环境和仓库目录中运行：

```powershell
python .\codes\Rolling_Arc_Real.py
```

仍按顶部 `PORT=None` 自动寻找CH340；需要指定时直接改 `PORT='COM9'`。18关节ID、软件零位、串口波特率和已有调参值保留。尺寸已按2026-11-08用户手量更新为头端25 mm、相邻转轴72 mm、尾端91 mm，属于近似配置，未重新标定硬件零位。

## 操作

1. Ctrl+U形成配置的初始圆弧，等待形成、静置及原两端归零/释放过程结束。
2. Ctrl+4选择主动调长。控制台会显示 `目标生成=连续曲线移位`。
3. Ctrl+J执行一段**头侧增长、尾侧缩短**；Ctrl+H相反。到位保持，再按开始下一段。任务正在运行时连按同向键会继续该段，不再反复清空接管采样或重建长度起点；不会暗中排队多段。反向键仍能切换方向；已暂停时再按J/H仍开始新的相对段。方向按J1为头定义，与搭管后画面左右无关。
4. Ctrl+G暂停/继续当前任务；Ctrl+L沿当前任务方向强制推进一小帧，发完目标后保持。它没有变成另一个自动流程。
5. Ctrl+Y返回**当前这一段任务的起点**，不代表跨过两个端点后自动回到整次测试的中间。Ctrl+X全部失能，Ctrl+Q退出。

`FEED_DISTANCE_M`实机默认每段72 mm；Ctrl+-/=减半/加倍。仿真默认一个模型轴距。调速度仍改 `FEED_RATE_JOINTS_S`，形状幅值仍改 `FEED_AMPLITUDE_DEG`；原 `FEED_OPTIONS_OVERRIDE` 和方向观察器参数入口保留。

建议本次先在中间姿态各做一段J/H，核对方向和实际使能，再逐段向两侧扩大行程并反向返回。观察实际圆弧是否仍开放、长度变化方向是否一致、反向是否接上、旧关节是否退出以及有无反复启停。记录卡住时控制台的阶段和原因即可，不需要另开仿真程序。

## 代码变化与记录

- 调长参考为直线—承载圆弧—直线。头尾直线段长度按同一弧长位移一增一减，承载弧的半径、弧长与相位在送链任务中保持固定。目标角由曲线对各关节相邻连杆区间积分生成。
- Ctrl+4用关节角重建的悬垂长度估计决定曲线移动量。退出关节须已进入直线段、离开缓冲和实测上弧范围，并持续达到近零位，随后关闭扭矩。
- Ctrl+5/6预调使用同一曲线生成器，给定需要移到的材料位置。Ctrl+7归中从已经形成的参考半圆开始，同样通过平移该曲线达到平衡。
- 实机生成器位于文件的 `BEGIN CURVE_FEEDING_CORE` 标记内，日常参数在文件顶部FEED配置区。日志 `feeding.trajectory_backend` 为 `continuous_curve_shift`，`feeding.curve_reference`记录各段起点、长度、曲率和扭率。
