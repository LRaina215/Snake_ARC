# MuJoCo手动调试与实机统一操作

两个入口均直接运行，无需启动参数。在已有`mujoco`环境中选择一个入口：

```powershell
python codes/Rolling_Arc_Debug_Mujoco.py
python codes/Rolling_Arc_Real.py
```

第一条打开MuJoCo手动测试窗口，不打开串口；第二条自动查找CH340控制真实机器人。两端共用基本全局Ctrl热键，仿真有额外扩展键，操作时运行其中一个入口。也可在使用该Conda解释器的IDE中运行文件。

## 实际共用的部分

手调版导入实机控制器、热键监听和命令分派；基础圆弧、限速形成、单步、固定截面顺应、失能及反馈有效性检查共用实现。滑动窗口是仿真控制器的扩展，复用已有`SlidingSectionCompliance`研究核心，尚未移植到实机。

| 操作 | 两端相同的结果 |
| --- | --- |
| Ctrl+U | 读取当前位置、预置目标、固定6关节使能、形成圆弧、静置后保持 |
| Ctrl+J / H | 正/反单步；按住不重复累计 |
| Ctrl+G | 连续/暂停相位 |
| Ctrl+E | 基础与固定截面顺应切换；仿真处于滑动模式时返回基础，保留当前窗口与相位 |
| Ctrl+空格 / N | 暂停相位但继续顺应 / 冻结最近目标 |
| Ctrl+T、Ctrl+方向键、Ctrl+-/= | 反向、调幅值/频率、调单步步长 |
| Ctrl+K / X / Q | 读取反馈 / 全部失能 / 退出清理 |

完整基本键位、参数与状态语义见[实机调试说明](实机调试代码说明.md)。初始窗口为J8–J13，其余关节失能；仿真进入滑动模式后窗口可以自动相邻移动，宽度仍为6。

## 仿真三模式与左右拉动

| 仿真热键 | 控制台命令 | 行为 |
| --- | --- | --- |
| Ctrl+1 | `gait_basic` | 基础圆弧，保留当前窗口与相位，限速恢复基础目标 |
| Ctrl+2 | `gait_fixed` | 当前窗口的实际形状截面顺应，保持窗口固定 |
| Ctrl+3 | `gait_sliding` | 截面顺应加自动选窗和卸载交接 |
| 按住Ctrl+A / D | `push_left` / `push_right` | 拉动世界坐标−Y/+Y侧悬垂端，实际物理运动由MuJoCo计算 |
| 松开A / D或Ctrl | `push_left_stop` / `push_right_stop` / `push_stop` | 停止外力；控制台命令需显式发送停止命令 |
| Ctrl+[ / ] | `push_weaker` / `push_stronger` | 总扰动力减/加2 N，最低0 N |
| Ctrl+W | `window_auto` | 自动选窗开/关；已经开始的交接继续执行 |
| Ctrl+R | `reset_preview` | 保存上一段终态，重建初始预览，日志episode加1 |

默认基础模式。形成之前可先选Ctrl+2或3，形成与静置完成后尝试接入一次；条件不满足会提示原因，需再次按模式键。在线切换保留实际位姿、相位、最近目标与掩码；进入滑动模式先接管当前已使能且承重的窗口，不在切换瞬间跳窗。切回基础或固定模式后仍保留移窗后的关节范围，Ctrl+R才重建顶部参数指定的初始场景、窗口和基础预览，它明确开始新一段实验。

测试顺序：**Ctrl+U → 等待静置 → Ctrl+3 → Ctrl+G → 按住Ctrl+A或D拉动 → 松开停止 → 继续观察承重中心和交接。**默认0.6 rad/s时，一个完整指令相位周期约10.47 s，短暂拉一下不一定触发移窗。自动模式先观察完整周期、确认偏移持续和相邻窗口承重，再等待合适相位及实际卸载。Ctrl+空格停住相位后不会收集新的完整滚动周期，已开始的卸载仍可继续。

左右操作移动的是本体，**不会手动修改窗口、qpos或qvel**。按下时选择当前−Y/+Y侧的头/尾端，在该端施加向外并向下的力；按住期间保持同一施力端。默认总力8 N，Y与向下分量各约5.66 N，可在仿真文件顶部改`PUSH_FORCE_N`、`PUSH_WORLD_DIRECTION`和`PUSH_DOWNWARD_RATIO`。左右同时按住时外力归零，松开其中一个则恢复另一个方向；左/右按世界坐标定义，与相机视角无关。

外力属于人工扰动。本体有位移不意味着一定需要移窗，选窗看整周期关节承重分布，不能用画面左右位置、两侧关节数或截面朝向代替。界面“Outside joints”表示窗口外头/尾关节数，不等于实际接触或悬垂关节数。

滑动模式不允许修改幅值或窗口，沿用已有半圆总曲率预算；需先切回基础模式再调这些参数。相位、频率、K、yielding、滤波仍可调。自动选窗阈值来自`WindowOptions`，本次未修改研究核心或设计扩缩方案。

## 参数与三维窗口

仿真文件顶部修改`SCENE`、`START_X_M`和日志配置。可选直管`straight`、柔弯`bend90`、连续急弯`elbow90`、变径柔弯`taper_true90`以及110→210 mm急弯`elbow90_taper110_210`。柔弯常用起点−0.35 m，急弯常用−0.25 m。

两端共用的幅值、角频率、固定关节、形成速度、K、yielding、滤波和反馈间隔都在`Rolling_Arc_Real.py`顶部修改，仿真不再维护第二套值。模型PD、力矩上限和被动阻尼来自`configs/step1.json`；实机寄存器原始限扭值不是该模型N·m参数。

查看器使用MuJoCo渲染API，不加载原生viewer的键盘菜单；普通字母和普通空格没有步态功能。鼠标左键旋转、右键平移、滚轮缩放，Shift改变旋转/平移方向。窗口显示三模式、主动窗口、窗口外关节数、相位、时间、实际侧移、施力端、周期承重中心和交接状态。蓝色使能，紫色失能。

启动时是静态初始姿态预览，没有推进物理时间或输出支持力。Ctrl+U接管开始动力学，主动按Ctrl+X释放也会结束初始预览；之后暂停相位、冻结目标或失能都不会冻结物理。静态预览不是承重证据，仿真还会默认搭好初始圆弧，真实机器人则读取用户实际搭管的姿态。

仿真关节接口读当前`qpos`，目标不回显成测量；每1 ms物理步按PD和掩码施加主动驱动，窗口外主动力矩为零，保留机械阻尼。基础与固定截面使用实际关节角，固定截面不读取接触或管径；滑动模式另读MuJoCo向上接触力和实际主动关节力矩，它们不能被写成当前实机可读取的信息。模型没有电流、温度和原始负载寄存器，这些字段为`null`。

两端基本控制周期20 ms、基础读角间隔1 s、固定截面全角间隔0.2 s。仿真滑动模式每20 ms刷新实际全角以估计卸载速度，不用保持的旧读数冒充零速度。仿真按仿真时间调度，实机按运行时间调度；仿真角连续且无串口耗时，真实角有量化和总线延迟，共用基本操作不代表物理响应相同。

默认日志在文件旁`logs/`，前缀`mujoco_debug_`/`rolling_arc_`，每次新文件。仿真还保存实际qpos/qvel、目标、掩码、力矩、外力及施力端、实际本体位移、接触承重、周期定位、交接事件和episode。常规手调日志约10 Hz，控制/物理仍为50 Hz/1000 Hz；本轮动力学检查另存全部50 Hz控制采样。关闭窗口或Ctrl+Q执行失能清理。

## 研究实验入口与检查范围

原基础、固定截面、滑动窗口入口及`validation/*_experiment.py`保留作为研究实验工具，不用它们的旧单字母查看器作为统一手调入口。方法实验未被此操作界面修改替代。

此前19项基本操作检查及4.92 s流程保留在[原检查记录](../validation/reports/manual_debug/README.md)。本次复跑这些检查，追加3项三模式/物理扰动/重新预览检查，共22项通过。键位使用虚拟事件调用真实监听回调，没有注入Windows实际按键或连接真实机器人。

动力学尝试共3次：2次完成36.2 s流程，1次因末端body名称错误在施力前中断，错误已修复。均匀整机横向力产生位移却未达到周期承重偏移阈值；改为拉悬垂端后，窗口从J8–J13自动交接到J7–J12，全程6关节使能，保存态开放指标通过。移窗后只观察2.32 s，不能证明长期反复移窗稳定；没有重跑跨管矩阵。完整数据、问题与适用范围见[本轮复盘](../validation/reports/debug_modes/README.md)。
