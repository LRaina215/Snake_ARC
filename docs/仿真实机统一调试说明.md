# MuJoCo手调与实机统一操作

在已有 `mujoco` Conda环境中直接运行，不需要启动参数：

```powershell
conda activate mujoco
python codes/Rolling_Arc_Debug_Mujoco.py
# 或者控制真实机器人：
python codes/Rolling_Arc_Real.py
```

两端使用全局Ctrl热键，操作时只运行一个控制入口。默认基础圆弧、J8–J13，启动等待接管。实机自动查找CH340，端口、零位、速度等在文件顶部调整。

2026-10-14两端新增**Ctrl+4主动送链**，停止普通滚动相位，以材料弯曲分布连续迁移主动调长两侧。Ctrl+J/H在此模式启动一次头侧增长/缩短的自动往返；Ctrl+-/=改下一目标量，Ctrl+G暂停/继续，Ctrl+L单帧，Ctrl+Y提前返回。原1/2/3模式的单步含义保持不变。目标与调参位置见[主动送链验收说明](主动送链实机验收说明.md)。本模式所有控制帧保存，关闭预览仍读取全关节角；仿真外拉在切入时停止，主动送链无需外拉。

## 三模式与热键

| 热键 | 行为 |
| --- | --- |
| Ctrl+U | 从实测角预置、局部使能、缓慢形成圆弧并静置 |
| Ctrl+1 / 2 / 3 | 基础圆弧 / 当前固定窗口顺应 / 自动位置与数量的滑窗顺应 |
| Ctrl+E | 基础与固定顺应切换；滑窗中返回基础 |
| Ctrl+W | 同时开关自动移窗和数量扩缩，关闭时取消待交接的普通请求 |
| Ctrl+G / 空格 | 连续滚动 / 暂停相位；暂停仍做形状顺应 |
| Ctrl+J / H | 正/反单步；自动滑窗模式仅允许正向 |
| Ctrl+N | 冻结已发目标，不执行窗口交接，仍采集角度 |
| Ctrl+T | 反转滚动方向；自动滑窗模式不接受此操作 |
| Ctrl+上/下、左/右 | 基础/固定模式调幅值、频率；自动滑窗保持冻结基准 |
| Ctrl+- / = | 调整单步相位步长 |
| Ctrl+K / X / Q | 显示状态 / 全部失能并确认 / 退出清理 |

也可在控制台输入 `apply / gait_basic / gait_fixed / gait_sliding / window_auto / run / pause / hold / step / back / release / status / quit`。

Ctrl+3现接入 `phase_normalized_count_v3`：从当前窗口接管，运动中根据实测形状选择相邻位置、扩大或缩小一关节，无6/8白名单。自动更新后切回基础或固定模式保留当前窗口，并按轴族分摊半圆预算，避免七关节仍统一使用60°而收紧。`amplitude=60`此时是名义半圆的缩放基准，不是每关节峰值。

形成前可先选Ctrl+2/3，形成与静置完成后尝试接入。手动改 `window=8:13` 仍需先失能。Ctrl+W关闭后保持当前宽度/位置并继续局部顺应；已有交接的形态回退审查仍属于保护逻辑。Ctrl+N禁止实际交接。

## 实机可用输入与范围

在线只用全20关节角、采样时刻、已发相位/使能掩码及机械尺寸。局部顺应、位置观察、相位均衡数量判断在同一实机单文件中；仿真手调默认直接调用它。没有管径、管轴、世界姿态或接触力进入默认控制。

默认DIY_PARAMETERS=True，两端解除建形/接入的速度、幅值、开放形态和60°/0.6硬限制。自动模式使用当前参数的名义几何参考；修改幅值/频率后重建观察器，不复用旧工况标定残差。仍保留形成斜率、滤波、协议编码范围及通信处理。关闭DIY才恢复旧冻结参考和研究门槛。模式接入不保证立刻产生移窗建议，位置观察仍需要足够的形状依据；其向下估计不是IMU或承重测量。[DIY说明及核对](../validation/reports/manual_diy/README.md)。

## 仿真场景与额外热键

顶部 `SCENE / START_X_M / SIM_FIRST_JOINT / SIM_LAST_JOINT` 调初始搭管；`SIM_AMPLITUDE_DEG / SIM_OMEGA_RAD_S` 调基础参数。

| 场景 | 推荐本轮复核初始X |
| --- | --- |
| `straight` 直管 | −0.5 m |
| `length_taper_return` 110→210→110 mm直管 | −0.35 m |
| `elbow90_taper110_210` 110→210 mm连续90°急弯 | −0.25 m |

原 `bend90 / elbow90 / taper_true90` 场景仍保留。变径场景只在初始放置时按管径调整高度，不在运行中修正根位姿。

按住Ctrl+A/D拉动两侧悬垂端，松开停止；Ctrl+[/]调总力，Ctrl+R保存终态并重建初始预览。默认8 N、向外与向下组合，不会直接移窗或改qpos。持续侧拉可能破坏悬垂端方向参考，不能将无建议当作没有滑动。

`SLIDING_FEEDBACK='motor_angles'` 为当前可迁移方法。`'contact'` 仅保留历史固定六关节的MuJoCo接触版本，不是实机方法。

## 显示、时间与日志

两端共用关节重建截面预览：直接正视控制器由实测角拟合的截面平面，保留实测/已发目标折线，叠加青绿色实测平滑与洋红色滤波前顺应候选曲线；全部共用实测截面坐标。控制未启用或缓存未生成时明确标注。[曲线含义与使用](关节重建截面预览说明.md)。

MuJoCo窗口显示蓝色使能/紫色失能、当前数量、数量估计、候选窗口与滚动交接状态。普通字母不会触发步态或MuJoCo原生快捷键；鼠标旋转、平移与缩放。

仿真与实机入口默认自动打开独立预览：左侧显示局部使能段及边界连杆的重建截面，右侧为J1–J20角度对照和使能色条，候选窗口用文字提示。u/v是该平面内坐标，不是世界轴，已取消Gravity / Head按钮。未接管前使能状态显示未知，反馈过期明确提示。关闭预览不停止机器人，Ctrl+X才是失能；实机`SHOW_PREVIEW=False`、仿真`SHOW_SHAPE_PREVIEW=False`可禁用。

显示进程不连接串口、不发电机指令，队列拥堵丢显示帧。预览开启时基础/失能状态也按200 ms目标间隔读取全部角度，不自行使能；预览关闭且不顺应时恢复原基础读角节奏。顺应始终读全20角。

目标控制20 ms、反馈目标间隔200 ms，串口顺序扫读按最早样本计龄，超0.8 s或通信失败时结束并尝试失能。实测形态无效时暂停并保持最近目标/掩码，需重新选模式。全20关节含失能舵机均需有供电、有效读角；串口量化/时延、阻力与模型的差异仍由用户实测。

日志在文件旁 `codes/logs/`，约10 Hz保存实际角、目标、使能、模式、位置/数量判断及事件；仿真另存qpos/qvel、外力与接触评价。暂停/冻结/释放不冻结仿真动力学；启动未接管时才是静态预览。

## 验证边界

本次同步沿用既有三次动力学结果，没有新增仿真或连接设备。110→210→110实际6→7→6及后续移窗已有证据，但保留最大218.67°的小幅超限；急弯部分状态的单管轴评价不可测。没有加入讨论中的额外回正修正。迁移后的软件核对见[同步报告](../validation/reports/posture_port/README.md)，真实效果等待用户测试。
