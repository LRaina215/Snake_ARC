# MuJoCo手动调试与实机统一操作

在已有`mujoco` Conda环境中，直接运行其中一个入口，无需启动参数：

```powershell
python codes/Rolling_Arc_Debug_Mujoco.py
python codes/Rolling_Arc_Real.py
```

第一条打开MuJoCo，不连接设备；第二条自动查找CH340控制真实机器人。两端使用全局Ctrl热键，操作时运行其中一个入口。默认基础圆弧、J8–J13，启动等待用户接管。

## 共用的三模式

基础形成、限速、单步、固定截面顺应、仅角度自动滑窗、反馈检查、目标和使能更新共用实机控制器。自动滑窗固定6关节，仅实际角、采样时间、连杆尺寸、已知指令相位参与判断；接触、世界姿态和实际力矩仅用于仿真评价。

| 两端热键 | 控制台命令 | 行为 |
| --- | --- | --- |
| Ctrl+U | `apply` | 预置实测位置，使能指定局部，缓慢形成基础圆弧并静置 |
| Ctrl+1 / 2 / 3 | `gait_basic / gait_fixed / gait_sliding` | 基础 / 当前窗口截面顺应 / 角度反馈自动滑窗 |
| Ctrl+E | `compliance` | 基础与固定顺应开关；滑动模式中返回基础 |
| Ctrl+W | `window_auto` | 自动选窗开/关；关闭时取消等待中的角度交接 |
| Ctrl+J / H | `step / back` | 正/反单步；滑动模式只允许正向 |
| Ctrl+G / 空格 | `toggle / pause` | 连续/暂停相位；暂停仍有形状反馈 |
| Ctrl+N | `hold` | 冻结目标和移窗，仍采集实际角 |
| Ctrl+T、方向键、-/= | `reverse`等 | 调方向/幅值/频率/步长；角度滑窗不接受反向或偏离冻结基准 |
| Ctrl+K / X / Q | `status / release / quit` | 读反馈 / 全失能并确认 / 退出清理 |

形成前可先选Ctrl+2/3，形成与静置完成后尝试接入。切换保留当前窗口、相位、最近目标和实际位姿；进入滑窗只接管当前6个关节，下一步观察确认后才相邻交接。切回基础/固定保留移窗后的范围。手动改`window`先释放，没有扩缩关节数量。

滑窗参考冻结为60°、0.6 rad/s、正向、21段64.5 mm。可通过顶部`MOTOR_SLIDING_*`调试交接参数，但改变参数后不能沿用本轮通过结论。无效实际形态保持旧目标/掩码并暂停，重新选模式才能恢复；反馈过期或通信失败退出并尝试失能。完整操作见[实机调试说明](实机调试代码说明.md)。

## 仿真额外操作与参数

仿真初始窗口改文件顶部`SIM_FIRST_JOINT / SIM_LAST_JOINT`，幅值/频率改`SIM_AMPLITUDE_DEG / SIM_OMEGA_RAD_S`；这些基本值独立于实机现场调参。默认8/13、60/.6；本轮连续例用6/11、`START_X_M=-.9`。改变搭管配置需检查初始化姿态。

| 仿真热键 | 作用 |
| --- | --- |
| 按住Ctrl+A / D | 在世界−Y/+Y侧头/尾端施加向外/向下物理拉力；松开字母或Ctrl停止 |
| Ctrl+[ / ] | 总扰动力减/加2 N，最低0 |
| Ctrl+R | 保存上一段终态，开始新episode并重建顶部配置的初始预览 |

左右拉动改变本体动力学，**不会直接修改窗口、qpos或qvel**。按下时选定施力端，默认8 N，向外与向下分量各约5.66 N；左右同时按住不施力。持续拉动可能使被动端失去向下参考，不能将无建议解释为没有迁移。窗口外关节数不等于实际悬垂/接触关节数。

场景在顶部`SCENE`选直管`straight`、柔弯`bend90`、连续急弯`elbow90`、变径柔弯`taper_true90`、110→210 mm急弯`elbow90_taper110_210`。新角度版本本轮只验证直管，旧接触版本弯管记录不能直接当作新版本通过。

默认`SLIDING_FEEDBACK='motor_angles'`共用实机方法；`'contact'`保留历史仿真版本，由MuJoCo整周期承重和实际力矩驱动交接，仅该历史版本有接触输入。原自动研究入口及原实验记录保留，不将两个版本混为一套判据。

## 时间、显示与日志

固定顺应/角度滑窗两端目标控制20 ms、全20角新采集200 ms；观察持续时间和差分速度只依据新样本，不把保持读数当作零速证据。仿真用仿真时钟，实机用单调时钟和最早串口样本计龄。串口扫描耗时/量化及失能编码器有效性仍待真实设备验证，不追赶阻塞期间漏发的相位。

仿真接口读实际关节qpos，写目标不会回显成测量；1 ms物理步输出局部PD，失能关节主动矩0，保留机械阻尼。真实0x28写0关闭主动扭矩，未验证其阻力与模型等效。

蓝色使能、紫色失能。查看器不启用MuJoCo原生按键菜单；普通字母/空格不控制，鼠标左键旋转、右键平移、滚轮缩放。HUD显示模式、窗口、角度判断和交接保持；接触支持显示只作评价。

启动为静态搭管预览，Ctrl+U/X接管后物理时间持续推进；暂停、冻结目标或释放都不会冻结动力学。Ctrl+R明确开始新实验，不是连续过程中的姿态修正。

日志默认在文件旁`logs/`，每次新文件。保存实际角、目标、掩码、采集时刻、相位和事件；仿真附存实际qpos/qvel、外力、力矩、接触评价及episode。常规手调约10 Hz日志，控制50 Hz；本轮自动验证保存全部50 Hz状态。关闭窗口或Ctrl+Q清理失能。

## 已验证范围

[连续多次移窗复盘](../validation/reports/repeated_motor_sliding/README.md)记录3次新动力学：同一段50.58 s自然演化在18.0/29.6 s完成6–11→5–10→4–9，随后2个完整指令周期形态与支撑通过。两次额外返回激励未产生符合判据的反向圆弧迁移；返回、短被动端和持续全相位定位没有通过结论。后段观察因头侧被动端方向失真拒绝判断。

三个原始记录共10729帧角输入重放核对实验模块和实机目标/掩码/事件；自然例再核对仿真手调接口，200 ms采样一致。26项相关软件检查通过，没有新动力学或真实设备连接。真实机器人效果由用户实验验证。历史[手调记录](../validation/reports/manual_debug/README.md)和[接触版拉动记录](../validation/reports/debug_modes/README.md)保留其当时实现，不作为新角度方法的覆盖证据。
