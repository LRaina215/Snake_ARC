# 连续主动送链与大幅两侧调长：2026-10-14

用户已认可连续送链、协调中部曲率、以两侧长度变化减速/停止的方案。本轮只开发研究仿真，不改现有实机与Ctrl热键入口，不上传GitHub，只本地commit。

## 假设与实现

1. 把旧的两模板单次交接改为沿全身材料坐标连续平移的局部弯曲分布。每跨过一组同轴关节，接续下一局部交接；目标可为分数连杆长度。新进入关节用实测角预置，离开区展直并按角度条件失能，不把角度条件写成已测得卸载。
2. 仍固定phase=0、预设基本弯曲60°、总转角预算180°。中部与边界一起调整左右曲率分配，尝试减小承托弧倾摆；不按管径顺应，不加名义圆弧恢复项、不增加总角来夹紧。
3. 用全关节角、已知连杆长度和合格悬垂端估计上下方向。通过局部弧边界的共同截面高度估计两侧材料长度，以`(头侧长度−尾侧长度)/2`的变化作为主反馈。共同高度并非真实管轴高度，编码器估计与真实长度分别记录，冠部仅作辅助。先用已有两条记录只读核对这项估计，避免新动力学盲试。
4. 误差大时送链、近目标时结合实测调长速度减速，允许反向纠偏。长度误差≤8mm且变化速度≤4mm/s持续至少.4s新反馈才报告达到目标；结束观察仍维持闭环，不按固定时间强行停窗。

## 固定条件与数量

原113mm水平直管、20关节、21根64.5mm连杆；J8–J13、60°、phase0、x=−.5m，静置6s。摩擦、重力、Kp/Kd、2.355Nm限矩、被动阻尼1.5和armature .01不变；物理1ms、控制20ms、角度反馈200ms。控制器只收角度/时间，世界位置、管径、接触力仅用于评价。无外加拉力、根部固定或运动中位置重置。

三次主例依次进行：头侧目标变化−64.5mm后返回；同起态头侧−258mm后返回；同起态头侧+258mm后返回。目标实际控制为两侧差的一半，弧长变化会使两侧不严格等量。最大1次有预先问题分析的修复，不扫参数。若首例暴露明确实现错误，先修复已知失败再继续两例；达到修复上限后保留失败，不重新建目录绕过预算。

每段最多60s（小幅）或100s（大幅），达标后观察2s再返回，返回后观察2s；不新增长hold、延迟、低阻尼和弯管回归。258mm是挑战目标，不是已经证明的能力。

## 验收与完整复盘

期望两侧真实反向调长、净两侧转移量去程/返回误差≤12mm，目标后2s持续误差仍≤12mm；持续支持、无落地，窗口外主动矩0，无关节限位超量。检查实测截面总角/开口与管心绕管角，开放形态不能由承托替代。

原地性以不依赖沿管推进为重点，期望骨架平均位置沿管最大变化≤10mm；完整记录支撑点、最高带和骨架平均三维位移与横摆。上一轮5mm世界支撑位置不是本轮扩大调幅的前置条件，不因小摆动否定真实调长；也不把沿管小位移写成三维固定。

检查全部实际反馈/目标/掩码/qpos/qvel、完整过程、去程与返回后持续状态、最差形态、曲率、交接连续性、失能、支撑、限矩和自发漂移。每例冻结控制器/观察器/入口源码并保存实际轨迹、状态及视频/分镜。每轮区分事实、原因判断、未验证范围与下一项最小改进；未达到形态/长度标准不报总体通过。没有真实硬件验证时不报实机通过。
