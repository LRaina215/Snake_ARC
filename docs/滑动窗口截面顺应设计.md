# 滑动窗口与局部实际截面顺应

当前仅MuJoCo仿真。截面方法复用`FixedSectionCompliance`，没有把管道半径、管轴或接触送进截面重建。实机入口及串口逻辑本轮不修改。

## 控制相位与实机观测边界（补充澄清）

本文件的完整周期指内部滚动**指令相位**φ推进2π，排除停相位；不是从世界姿态或管道相对转角测出的机器人真实转动一圈。日志`phase_rad`与`post_exit_phase_cycles`均按此控制相位定义。窗口承重积分使用MuJoCo真实接触力F·|dφ|，不使用电机电流或原始负载代替它。

目前验证的是具有连杆接触力与主动关节矩观测的仿真窗口选择/交接。现有实机脚本可读取实测角、原始负载和电流，但没有标定为连杆向上接触力，也没有验证仅用这些信息可以可靠自动选窗。执行J8–13→J7–12的使能切换与自主判断何时/向哪边移动，是两项不同能力。将输入限制为实机可读反馈后，需要重新设计并验证定位和卸载判据；不能直接照搬2 N承重、80%覆盖或0.2 N·m卸载门槛。

截面拟合使用机器人头部坐标系的正运动学，当前没有世界姿态/重力方向输入，也没有截面相对地面垂直的控制目标。拟合平面与投影坐标基只服务于局部形状重建。仅关节角不能确定整个机器人的绝对朝向；水平管上的适合截面通常为竖直平面，但竖直不能唯一确定其法向或移窗方向，急弯两段管轴也不能共用一个严格垂直于两轴的平面。

## 三个职责

1. `section_geometry.py`与`fixed_section_compliance.py`：实测q→身体正运动学→局部平面→连续线圆弧→模块长度归一化→Yamada积分。保持同一参考校准、K=0.02、yielding=0.7、目标转角190°/开口0.4约束和45°/s过滤限速。
2. `sliding_section_compliance.py`：从实际开放形状与向上承重观测选择连续6关节窗口。初始选窗和支撑覆盖使用0.4 s滤波；自动迁移使用最近完整2π滚动相位内的承重积分F·dφ，中心相对窗口中点超过1.25关节并持续1.2 s才申请相邻移动；5 s冷却。相邻候选必须覆盖≥80%的观测承重。停相位不累加，完成交接清除旧分布，重新取得一个完整周期后才允许下一次自动定位。
3. `sliding_section_simulation.py`：把MuJoCo实际接触的世界竖直正分量按物理连杆分箱；提供实际退出主动关节力矩。控制器没有访问模型路线或管径的接口。驱动只对使能掩码施加限矩PD，失能条目输出精确0，机械阻尼保留。

机器人实际接触段不等于使能关节段。主动圆弧需要覆盖接触区并保留构形长度；只把有接触的关节使能会使圆弧碎裂。初始选窗扫描J2..J19内的6关节候选，要求实际截面150–218°、开口≥0.4、平面拟合≤15 mm、承重覆盖≥80%，再比较形态与承重中心。仿真先用前2 s形成可支撑姿态作为初始条件，选择器不能读取形成阶段窗口；此验证不是从悬空/任意姿态自主搭管。

## 最终采用：卸载相位交接

J8–13→J7–12时退出J13、进入J7，同为奇数轴；J8–13→J9–14时退出J8、进入J14，同为偶数轴。奇数目标是cosφ，偶数目标是sinφ。在对应族接近零时，旧/新窗口名义目标近乎相同，因此可以在不制造第二段圆弧的情况下交接。

选择器发起请求后保留旧窗口正常滚动，直到该族因子绝对值≤0.015。短暂停止相位递增，物理仿真和实际截面反馈继续；等待以下条件同时满足：

- 进入/退出实测角绝对值≤4°，变化速度≤8°/s；
- 退出主动关节力矩≤0.2 N·m，总承重≥2 N，新窗口覆盖≥80%；
- 新6关节实际截面150–218°、开口≥0.4、平面偏差≤15 mm；
- 进入关节预置实测角、重叠关节保留原过滤目标后，整个新窗口发送截面≤190°且开口≥0.4。

随后在同一控制周期退出关节失能、进入关节使能，重叠5关节目标不重置，相位保持连续，滚动恢复。20 s不能安全交接则保留旧窗口并记录拒绝；不自动扩大窗口掩盖交接问题。最终方案任一时刻使能6关节，不产生同时使能7关节的并集。短暂停相位带来推进等待，这是当前方法的代价，不能宣称无停顿迁移。

按有效控制相位而非时间平均承重，是针对S4出口后周期性往返切窗的修复。自动定位需要约一个滚动周期（当前ω=0.6，约10.47 s）观察，另有持续门槛和卸载等待，不能宣称快速应对任意突变。新110→210 mm场景只发生一次自动迁移，完整出口后3周期无往返；同一4 N载荷病例未产生完整周期的足够承重偏移，因此未触发迁移，该预设迁移测试项仍未通过。初始选择、手工请求与交接门槛不变，早期S1/S2/S3记录检验这些共用部分；不能将早期短时滤波的自动触发记录当作最终周期选择器的全矩阵验证。

参考曲率按机械弧长权重分别归一化每个奇偶族：θ奇=π·权重/族权重和·cosφ，θ偶=π·权重/族权重和·sinφ。均匀6关节时严格还原原60°公式；这防止增加关节时沿用60°造成额外包绕。历史平滑重叠/6→5→6策略见本地commit739e9f3和失败数据，当前默认不使用。

## 可观测性和验收边界

向上接触力及已标定N·m主动关节力矩属于当前仿真观测。不能将失能舵机原始负载寄存器当作已验证的管道接触传感器；实机定位/卸载观测留待用户验收后移植设计。

评价使用保存的实际qpos/qvel、实际发送目标、权重/掩码、支持力和交接事件。进度来自全身固定点集合，与窗口选取无关。实际身体截面和管轴包绕分别报告：急弯跨两个轴时管轴指标不可观测，不能以身体平面性替代“管轴包绕已验收”。完整出口持续3周期评价，视频/时序图/全部采样审核都可从保存状态生成，不增加动力学实验。

## 运行与常改位置

```powershell
py -3.12 -X utf8 codes/Rolling_Arc_Sliding_Section_Mujoco.py --scene elbow90_taper110_210 --start-x -.25 --duration 150
py -3.12 -X utf8 validation/sliding_section_experiment.py --scene elbow90_taper110_210 --label my_sliding --start -.25 --duration 150 --exit-cycles 3 --output validation/results/my_sliding
```

查看器：空格暂停/恢复相位，A/D请求头/尾相邻交接，U切换自动选窗，R反向；不使用F热键。手工交接时建议先U关闭自动选择，避免手工和自动请求相互覆盖。图中蓝色使能，紫色失能。GUI键盘未做人工实测，动力学入口与全程回放独立验证。

修改`WindowOptions`调整选择与卸载门槛；修改`SectionOptions`调整原截面反馈；修改`configs/step1.json`调整原步态与电机参数。控制命令仍为角度目标加显式使能掩码，而不是给失能关节下发零角度。正式结果及问题见`validation/reports/sliding_section/README.md`，本轮次数与条件见`docs/滑动窗口实验计划.md`。
