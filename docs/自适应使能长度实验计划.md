## 假设与固定条件

关节角重建的身体圆弧在粗管上被撑开时，实际转角/半径会偏离相位匹配的半圆参考，可据此请求增加构形长度；重新变细后若出现相反的可观测变形，则请求收缩。这是待验证假设，不假定身体拟合半径等于管径，也不假定8关节一定有优势。形状没有变化时，仅角度可能不足以识别管径变化；不能强制按场景位置/时刻移窗或改变长度取得通过。

输入仅20实测角、时间、已发相位、掩码和机械长度。200ms新采样，20ms目标控制，1ms物理；速度与持续判断只用新反馈。场景、接触、真实重力、力矩和路程仅供放置/评价。使用现有mujoco Conda，不安装软件，不改阻尼或延迟做扫描。

继承K=.02/yielding=.7/过滤.15s、PD127/1/限矩2.355Nm、被动阻尼1.5/armature .01。稳定长度6或8，过渡允许7；两端至少3被动关节。扩缩后尽量保持原中心。按每个奇偶族的物理长度分别归一化π预算，6为60°，8为45°，7的两族分别60°/45°。不沿用扩大后所有关节60°的旧失败策略。

每次只添加/释放一个边界，在该轴族零相位保持，检查新角小角/低速、旧与候选实际形态及发送目标。七关节仅过渡，不启动新的长度/位置决策；失败/超时保留实际状态与错误，不把停留在7称为完成。扩缩和滑动请求串行，稳定长度后重置确认并冷却。八关节冻结相位参考单独建立；七关节不依赖未验证的迁移基准。

## 数量与顺序：4次计划，最多1次针对性修复

1. **8关节恒径校准**：210mm直管，J7–J14，不执行长度/位置改变；第一完整周期建立24格参考，后一完整周期独立检查相位偏移和形态。约35s，不重复挑选周期。不能校准成功则先复盘，后续依赖八关节的病例不盲跑。
2. **固定6基线**：同一110→210→110mm渐变直管，初始J8–J13、x=-.5m，关闭扩缩/滑动。最长180s，全身离开变径段且出口2完整指令周期可提前结束。
3. **自动扩缩**：与2完全相同场景和初态，自动滑动关闭，只改变长度策略；要求由实测形态自动发生6→7→8→7→6，不能脚本请求。最长180s，最终完成和全身出口后2周期结束；无返回输入时报告收缩未覆盖，不自动改判。
4. **合并急弯**：前面主要结果通过后，用已有110→210mm连续90°急弯，x=-.25m，长度和位置请求共用调度器。最长150s，出口最后变更后2周期。真实急弯轴不可观测阶段单独报告，不能用身体开放代替严格管轴验收。
