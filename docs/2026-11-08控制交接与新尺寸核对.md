# 2026-11-08：L确认、ARC两端归零与新机械尺寸

## 已落实的行为

- `front_seat`／`front_hold`的Ctrl+L直接确认实物支撑，进入原送尾的`return_seat`；保持目标、使能和相位，下一次J/G才推进。此前已经提前确认也不再被忽略。`front_finish`尚未完成曲线衔接时，L仍记录确认，J/G继续衔接。
- Ctrl+7半圆形成后、自动归中前增加一次`arc_end_reset`：承载半圆保持，两端从实测角预置使能、逐步归零，再失能。调用与Ctrl+U相同的`PassiveEndReset`，不另造归零判据。
- 后续实测确认归中会释放新关节，仅上述一次不足覆盖最终状态；现补归中后的`arc_final_end_reset`并交回基础J/H/G。该后续修复及1倍通过、3倍过程形态失败的结果见[最新复盘](../validation/reports/helix_arc_basic_return_20261108/README.md)。
- 暂停、J预算用完或离开模式7时释放临时端部使能。接续时从新实测角继续，最长累计2秒执行时间后也会释放，不形成无限等待。归零后清除旧向下估计并重新采样；受接触约束的展直端不能据此认定已沿重力下垂。

## 用户确认的近似机械尺寸

| 距离 | 当前配置 |
| --- | --- |
| 头端至J1转轴 | 25 mm |
| J1→J2，以及中间所有相邻转轴 | 72 mm，共17段 |
| J18转轴至尾端 | 91 mm |
| 总骨架长度 | 1.340 m |

这些是手量近似，不是精确标定。J1仍代表头部第一个舵机；没有据“J1不控制其他关节”的口头描述擅自删ID、失能J1或改零位。

实机文件顶部设置`HEAD_AXIS_TO_TIP_M / JOINT_AXIS_SPACING_M / TAIL_AXIS_TO_TIP_M`。`FEED_DISTANCE_M`默认跟随一个身体轴距72 mm，速度仍由`FEED_RATE_JOINTS_S`控制。几何长度、一次调长请求量、目标ARC曲率是不同参数；本次更新尺寸没有求出“最优调长ARC半径”。

曲线积分按各轴累计材料坐标与相邻两段区间计算；Helix逆拟合、前部预算、送尾余量与归中交点也改用实际距离，不能把19段全改成同一个数。调长速度换算取身体轴距，避免25/91 mm首尾段拉偏平均值。

仿真手调在内存中读取已加载模型的真实骨架距离，包含头尾长度，并替换默认“一轴距”请求量；显式自定义的请求量保留。不改写实机源码尺寸。旧模型仍为64.5 mm，不能据其结果宣称新硬件动力学已通过。

## 必要核对及复盘

L修复使用已有实测姿态记录：先复现早已确认和未确认两种失败，再人为注入12°跟踪偏差，验证库与单文件L均可立即交接；目标、使能与相位无跳变，后续J/G仍逐节使能尾部。12°是回归输入，不是从用户此次片段测得的误差。

几何软件检查固定18舵机和25/72/91 mm配置：核对前向骨架各段长度、非等长Helix积分与解析式、反拟合半径/螺距/相位、实测曲线零移位复现、模式5/6/7工厂与仿真尺寸隔离。连同相关路由、原曲线调长和归零检查，共68项通过。全部使用内存串口，未连接机器人。

动力学只跑2次代表例：首次检查新归零阶段；数学改为非等长后，用相同原模型再做1次相关回归。固定18关节、110 mm直管、相同起态参数120°、0.2秒读角、速度倍率1，执行7→J→G暂停→J→G→归中保持→续滚6秒。控制器只读角、尺寸和时间；接触力与世界坐标仅用于评价。不是新尺寸模型，也没有新增延迟/阻尼组合试验。

验收检查全部保存的实际状态，覆盖解缠、成形、归零、移窗归中与续滚；半圆需开放，单纯不掉管不能代替形态验收。最终回归结果：

- 全程85.45秒；归零阶段约48.02–48.42秒，仅触发一次；承载J4–J9保持，其余12个关节临时归零后失能。结束时端部最大角约0.0314°。
- 归中完成保持后续滚6秒，包绕角176.95–181.83°，最大实际两侧长度差36.73 mm，截面最大平面RMS 10.35 mm。半圆过程与最终形态均通过原评价口径，最终两端失能。
- 全程最大关节角78.06°，最大跟踪误差1.73°；保存采样中无触地或非相邻自碰撞，失能执行器力矩为0。
- 仍有36个饱和采样和1个近零支撑采样，不能写成始终有接触或从未饱和。最终检查不因此否定已达到的开放形态与归中，也不据单例宣称任意起态稳定。
- 相同条件下首次归零检查也通过；两次存在小的轨迹差异，未发现新数学使原模型流程失效。完整视频与全采样指标共同检查，截图仅辅助定位。
