# 相位均衡的自主使能数量判断

## 当前版本与结果

当前研究控制器为`phase_normalized_count_v3`。位置观察器、局部截面顺应和每组π名义参考不变，仍无稳定6/8白名单、无指定返回数量。主要新增`snake_control/phase_balanced_count.py`，`posture_window.py`持续收集形状证据并联合选择边界。本轮入口`validation/phase_window_experiment.py`，只在已有Conda mujoco运行。

[完整实验报告](../validation/reports/phase_balanced_window/README.md)：七关节既有同一组角度的数量变化被压低，实际急弯回归稳定；110→210→110直管实际6→7→6及续行成立，但修复后真实绕管最大218.669°、53态超218°，严格验收未通过。实机和热键入口未同步。

## 输入和相位统计

输入仍是实际全关节角、读角时刻、已发相位/掩码与已知机械尺寸。没有接触、管径、真实力矩、root、真重力、qvel输入控制层。Body圆拟合半径不能解释为管径；长被动端提供条件性向下代理，不能保证任意绝对姿态或外载。

原连续数量代理保持：`width*(actual_body_radius/nominal_body_radius + nominal_turn/actual_turn)/2`。对同一使能区间，最近π已发相位内的新角记录按mod π分4组，组内取中位数、组间等权；每组至少2真实新反馈才做常规数量判断。采用π的理由是既有记录中几何数量代理近似半周期重复，外载/重力不对称下仍是假设。没有固定两周期等待，也没有hold，运动中持续补充证据。

换实际窗口重置；等待交接、冷却、短窗试探时继续收集，避免“仍在滚动却漏采样”。同一相位重复读角只更新一个样本，不能制造相位覆盖。新角中断>.5s或相位倒退则重置。不可靠截面/圆拟合不用于数量决定。

同相位实际转角先减名义转角，再按组统计偏差；直接用绝对180°会忽视名义三维滚动本身约178°的变化。扩大采用均衡数量≥当前+.5及转角偏差≤−5°，强紧凑收缩采用数量≤当前−.5及偏差≥+5°。

## 相邻短窗试探

身体本身满足开放条件但没有强紧凑信号时，若各组数量中位最大≤当前+.25、均衡转角偏差≥−2°，允许提出一次相邻缩窗试探。它是“没有持续形态不足”的证据，不是已经识别支持力或证明短窗承重。机械上不可更短时保持宽度并继续位置选择；不预设必须回到六关节。

常规决定需要同一长度方向持续1s，允许具体边界候选随相位改变，由候选资格和连续交接门槛决定哪侧可执行。平移仍要求具体相邻窗口的持续证据。进入实测角预置，共享目标不跳，实际候选150–218°/开口≥.4/RMS≤15mm、已发及下一目标≤190°/开口≥.4、下一目标步长≤.9°。

实际单边contract退出角上限12°，其他平移仍4°；没有旧静止8°/s限制。放宽退出角是为了在候选与目标均合格时提前运动交接，不证明卸载或矩连续。修复真实退出10.426°/−26.951°/s，下一目标步長.394°、共享预置0；实际支撑通过，整体绕管仍有小幅超限。

交接后5s实际形态审查、1s后连续2次不合格请求回退；这一短审查不是全周期/承重认证。回退能力没有本轮动力学触发覆盖。接管仍从已搭管名义圆弧开始，任意摆放、全部数量/速度/反向和硬件效果不在已验证范围。
