# 6↔8使能长度研究原型（2026-10-13）

已实现只用关节角的自动扩缩，以及与六/八关节位置滑窗共用交易调度。实测记录证明了6→7→8→7→6和急弯中的三次相邻移窗；尚未完成全部严格验收，不更新实机和现有手调默认入口。完整结果见[本轮复盘](../validation/reports/adaptive_arc_length/README.md)。

## 控制器与参考

`snake_control/adaptive_arc_length.py`不访问MuJoCo、世界位姿、管径、接触或力矩。输入仅实际20角、采样时间和已发相位；内部保存已发使能掩码和机械长度。仿真执行器`length_simulation.py`每200ms采集角，每20ms更新目标，每1ms执行原PD。场景几何只用于一次初始放置及评价。

`HalfArcParameters.targets`按物理模块弧长分别分配两个轴族的π参考预算：奇族乘cosφ，偶族乘sinφ。均匀6关节各60°，8关节各45°，7关节两族分别60°/45°。目标反馈仍由实际截面、连续线圆弧、Yamada积分和同相位参考校准完成；目标转角≤190°、开口≥.4，滤波/限速沿用现有值。参考预算不保证每一帧实际身体或管轴都是精确180°，两种实际形态必须分别复盘。

六关节冻结参考沿用`configs/motor_shape_reference.json`。八关节参考`motor_shape_reference8.json`取本轮210mm恒径第一周期的24格中位，第二周期独立检查；不在滑动/扩缩时在线重学。七关节只有过渡几何判据，没有已验证的迁移相位基准，其诊断建议不作为定位性能证据。

稳定长度仅6或8，过渡7；两端保留≥3被动关节。每次只改变一个边界，等待对应族零相位，保持相位而物理继续；两个新读角确认小角≤4°、速度≤8°/s、实际候选与预置目标开放后切换。加入关节以实测角预置，共享关节保留已有目标；退出关节主动矩归0。20s不满足则拒绝，不能强行使能。若交易停留在7则锁定故障保持，不写成稳定成功。

扩缩与位置迁移串行，过渡期不能开始第二个交易；稳定后冷却5s再判断。位置迁移仍要求冠部偏移与同旋向弯曲同时确认。角度小/低速不证明卸载，接触支持与实际退出矩只留在评价。

## 从被动半径判断改为可行性试探

第一版以相位匹配的实际/名义身体圆弧半径比和转角持续偏差选长度：六关节被撑开时请求8；八关节若进一步收紧则请求6。第一版能扩张但回到细管后不收缩，实际管轴跨度达到235.7°。主动参考会维持自己的身体半径，因此身体半径不能直接当成管径信号；保持身体开放也不等于保持管轴覆盖。

当前默认`feasibility_trial=True`：八关节稳定一完整指令周期、实际形态合格且当前方向可观测时，尝试原相位/小角低速门槛下的6关节收缩。完成后再一完整周期检验实际6关节形态；合格则在允许集合中优先保留较短构形，只有身体转角持续接近150°安全下界（过滤≤155°）才再扩张。原始半径信号仍可触发明显变形下的请求，但不会在已可行六关节区追逐180°而反复扩张。

这是“已观测形态可行性选择”，不是直接管径识别，也不是全局最优关节数；仅在6/8两种稳定长度中试探。它接受原有150–218°身体范围，可能保留粗管上约160°的六关节圆弧。若后续目标改为实际180°±更小误差，应重新确定优化目标，不能沿用本轮可行性结论。

`feasibility_trial=False`保留第一版以便复现失败。本轮未用更多次数做主动微扰辨识、力矩/电流标定、反馈延迟或阻尼扫描。

## 使用与修改位置

这是研究仿真原型，现有`Rolling_Arc_Debug_Mujoco.py`和实机仍用上一轮已验证的固定6关节三模式。当前不把扩缩原型默认接入用户实测。

在现有`mujoco` Conda环境中，可对归档执行只读复盘与控制器输入重放：

```powershell
python -X utf8 validation/replay_arc_length.py
python -X utf8 validation/audit_arc_length.py validation/reports/adaptive_arc_length/adaptive_repair_20261013_082802_005160
```

`length_experiment.py`保留calibration/baseline/adaptive/combined四个病例入口；当前已用完冻结的5次动力学预算，会拒绝再次启动，避免覆盖或无目的重跑。未来新一轮应明确新的数量和输出批次。默认adaptive选择可行性版本；`--radius-only`才选择原失败对照，不通过旧文件名猜测方法。

通常调步态看`HalfArcParameters.targets`和`FixedSectionCompliance`；调扩缩看`LengthOptions`、`_observe_length`、`_request_resize`、`_handover`；调可行性检验看`advance`中的eight/six周期状态。控制代码内部rad/m，读角边界degree，日志同时保存真实反馈时间及命令相位。当前参考只对应正向0.6rad/s、原机械尺寸，反向/其他频率需要新基准。

## 下一最小改进

先用现有记录明确急弯中单管轴截面的定义，保留最近点轴与实际接触轴冲突的不可测区。之后才用新一轮1个直管病例补足严格连续出口2周期，不能复用此次第一次越界后的计时值。

合并控制曾等待20s，因为待加入失能关节仍停在8.3°而没有自行回到4°以内。下一控制问题应分开“加入失能关节”和“退出承重关节”：研究加入关节的实测角预置、目标连续性和候选形态是否足以安全接入，或在长时间无变化时恢复滚动再找相位；不机械放宽退出关节的小角门槛。扩缩位置优先级、拒绝后持续确认重置也需要明确。不追加本轮第6次动力学，不将这些拟议改进写成已经通过。
