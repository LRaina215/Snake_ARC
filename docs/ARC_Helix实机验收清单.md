## 统一通过标准

**ARC→Helix部分：**调长时仍是开放承载弧；先形成前部螺旋并搭稳，确认后尾部逐节接入。送尾期间前部已发目标保持，实物前部持续承载、没有被拉开或与尾部明显干涉；最终完整Helix稳定保持约3秒。允许受力引起的整体位移。

**T管部分：**小U从尾朝头看搭在主管右侧；释放后尾段自然摆到轴线下方、前部随之滑转；回卷时尾部逐节上管、前部继续推进。整身越过支管后再滚动一小段，观察尾部仍贴管。

需要手扶、重新摆放或额外改参数才能完成时，单独记为“辅助完成”，并注明发生阶段。ARC切换与T管越障分别记录结果。

## 重力矩单步速查

1. `align`：J/H微调对准 → 空格暂停 → L确认 → J开始解旋。无需等待录像中的固定秒数。
2. `unwind`：逐次J；小U在主管右侧搭稳后，暂停 → L → J，关闭尾部扭矩、自然下落。
3. `drop_hold`：尾段摆到轴线下方 → L → 逐次J，接管直尾、回卷上管并恢复滚动。

5/6中，J每次默认最多推进1秒控制动作后保持；L只确认阶段。每次停住再按下一次J。G连续／暂停，K看阶段，空格暂停，X全部失能。
