# ARC→Helix与重力矩越障操作说明

更新：2026-11-07晚间。适用于 `codes/Rolling_Arc_Real.py` 和 `codes/Rolling_Arc_Debug_Mujoco.py`，两端共用控制器与Ctrl热键。首次送尾已改为原重力矩回卷；当前版本通过三种直管起态验证，实机等待用户验收，见[本轮报告](../validation/reports/source_entry_20261107/README.md)。历史10类入口结果保留，不自动视为修改后版本的回归结果。

现场按[实机验收清单](ARC_Helix实机验收清单.md)逐项记录，首轮6项各1次。

## Ctrl+4、5、6各自做什么

| 模式 | 完整任务 | 结束状态 |
| --- | --- | --- |
| Ctrl+4 | 手动发起一次两侧长度调整；J使头侧增长，H使头侧缩短。默认每次请求64.5 mm，到位保持，不自动往返 | 保持调整后的ARC，仍可继续J/H或切换5/6 |
| Ctrl+5 | 重新识别当前承载ARC，按当前形状规划是否调长；需要时自动重分配两侧材料，再先成前部螺旋、后逐节送尾 | 完整Helix，保持；不执行T管避障 |
| Ctrl+6 | 从ARC执行与5相同的自主准备和上管流程，再接入重力矩越障；从通过5形成的完整Helix接入则直接对准支管 | 解旋、失能下落、回卷后继续螺旋滚动，清障由现场观察 |

Ctrl+5自身包含调长，不要求用户先用Ctrl+4摆到固定位置。先用4调长再切5同样可用：切换时重读全身关节角、重新取承载弧，不直接把模式4的全部缓冲使能继承成ARC。

这里的“适合切换的位置”指承载圆弧在蛇身上的材料位置及两侧余长分配。当前方法按实测圆弧位置、设定的Helix半径／螺距和前部圈数预算选择可接入区间，并随反馈完成接管。它没有搜索或证明全局最佳位置，也不负责在主管上寻找T支管的世界坐标。

“直接从不同位置的ARC切换”限于程序已接管、当前能识别出开放承载圆弧、已稳定搭管的姿态；起始两侧不必等长。已验证近等长、头侧极短、尾侧极短及模式4正反调长后的起态。未证明任意散乱姿态、任意管径、弯管或其他障碍附近均能成功。不同两侧长度可以由5继续调整，不代表忽略机械行程、可用材料长度或真实接触条件。

## 启动

在已有 `mujoco` Conda环境中，选择一个入口运行：

```powershell
conda activate mujoco
python .\codes\Rolling_Arc_Real.py
# 或者运行手动仿真：
python .\codes\Rolling_Arc_Debug_Mujoco.py
```

当前实机默认18关节，ID为1–18、零位表18项、机械尺寸19段，均由顶部数量对应生成。实机无需命令行端口参数，串口与硬件校准在文件顶部修改。仿真沿用相同18关节数量，在顶部选择 `SCENE='straight'` 测试5，或 `SCENE='tee_up60'`、`START_X_M=.2` 测试6。真实机器人保持J1为前端；左右／右侧小U的观察方向统一为从尾朝头。

2026-11-07零位已按用户确认的标准直线姿态重新标定，更新后需退出旧进程再启动。新连接件精确转轴尺寸仍待核对，当前机械尺寸保留旧仿真64.5 mm；先核对直线读角及搭管预览，原仿真通过不等于新连接件实机通过。[零位与尺寸边界](../validation/reports/hardware18_zero_20261107/README.md)。

先按原流程接管并稳定搭管ARC：Ctrl+U按配置形成，或Ctrl+3按当前搭管形状选窗接管，形成完成后再选5/6。已经由本程序使能、稳定搭管的ARC可直接选5/6。实机和手调入口都用全局热键，操作时运行一个控制入口即可。

Ctrl+U在ARC形成、静置结束后，默认还会执行一次两端归零：承载段目标保持，非承载关节按当前实测角预置后临时使能，以60°/s发到0，短暂保持后恢复失能。一般约1 s，最多2 s；未到位也会释放并明确显示超时。空格可以立即终止并释放两端，Ctrl+X全部失能；切换模式也会撤掉临时使能。顶部 `END_ZERO_ON_U=False` 可关闭，速度／保持／最长时间为 `END_ZERO_RATE_DEG_S / END_ZERO_HOLD_S / END_ZERO_MAX_S`。它消除弯折，不证明触地端已经成为重力参考；Ctrl+3按姿态接管不执行此归零。

## 三条操作路线

### 直接ARC→Helix

1. 在稳定ARC上按Ctrl+5。选择模式后保持原状态。
2. Ctrl+J逐步推进，或Ctrl+G连续推进：程序自行识别承载弧、需要时调节两侧长度，形成前部螺旋并小幅滚动就位。
3. 前部实物搭稳后按Ctrl+L确认。`front_finish`、`front_seat`、`front_hold` 都接受确认，不必先暂停。提前确认时显示“已收到前部支撑确认”，保持当前目标；下一次J/G继续完成前部曲线衔接，再自动进入 `return_seat`。已到 `front_hold` 时，L直接选择 `return_seat`，仍由下一次J/G动作。重复L不会重置进度。到 `front_hold` 尚未确认时，J/G会提示先L。
4. 按一次Ctrl+G连续执行 `return_seat → return_wind → return_finish → recover → helix_normalize`，不用反复按J。先顺序接管过渡弧和直尾，再缩短直尾、推进前部螺旋相位，让尾段材料逐步进入螺旋；前部持续推进，不再冻结整段前部去单独掰尾。最后统一到一条Helix后报 `complete` 并保持。G再次按下或空格可暂停；J每次最多1秒，执行中重复按不追加。

L确认时保持目标；继续回卷后前部目标随曲线变化。现场对照支撑、前部前进与尾部逐段接入观察，不能以程序阶段或目标跟踪代替实物贴管。

### 恢复统一全身Helix

全身已经使能时，再按Ctrl+5选择 `helix_normalize`，当前目标先保持，再用G连续或J单步归形，空格可暂停。它结束后保持，不自动进入T管动作。原来重复5只会暂停，现增加此用途；前部接管后的过渡形态不会因为按过L就永远保留。已有T管控制状态且全身使能时，5也可以退出T管流程、转入统一Helix。尾段仍失能时，此操作不能替代逐段上管。

重启程序后，如果实物已经是可识别的全身螺旋，可直接5：读取全角、按当前角预置后使能，再J/G归形。识别复用现有全身Helix角度拟合，不使用MuJoCo接触或世界坐标；它不证明实物与主管同轴。

此次只验证目标曲线与角反馈交接，没有新增完整动力学实验，实机贴管效果仍待验收。[实测“完成但非统一Helix”的核对及修复](../validation/reports/helix_normalization_20261107/README.md)。

### 先手动调长，再按当前姿态切换

1. Ctrl+4后用J/H把两侧长度调到希望检查的位置，待本步停稳，或暂停后观察。
2. 只需要Helix时按Ctrl+5，再按上面的J/G、L、J/G流程。程序会根据最新形状判断是否还需要调长，既可以直接起卷，也可以继续调整。
3. 还需要接T管重力矩流程时按Ctrl+6。前半段同5，完整Helix形成后进入 `align`。

因此，`feed_h5_4x.mp4` 是4→H→5；`feed_h6_4x.mp4` 是4→H→6，后者还包含T管避障。按录像文件名和实际热键区分，不依赖“第一个／第二个视频”的顺序。

### 完整Helix→重力矩避障

通过5到 `complete` 后按Ctrl+6，进入 `align`。后续按下表确认和推进，无需重做两侧调长与首次送尾。

2026-11-08新增小U前半径手调：在 `align` 按 **Ctrl+O收紧、Ctrl+P放松**，每次1 mm，滚动相位暂停，自动平滑调到新半径后保持。可以累计按键；G／空格可暂停。观察抱管状态后L确认，再J/G形成小U。调节未完成就按L时，采用当前已执行到的半径，取消剩余调节，不会偷偷在解旋时补完。

手调值仅用于对准及小U／直尾形成；原解旋末段恢复放松半径，释放／回卷和恢复仍用原参数，保留越障所需滑移。K显示初始抱管当前／请求半径及后续原半径。该值是螺旋中心线半径，**不属于左右调长／主动送链时最佳ARC半径的自动选择**。仿真与实机同键位，详见[本轮说明与验证边界](2026-11-08重力矩抱管半径调试.md)。

## 重力矩流程：逐步按键

下表所有字母均需按住Ctrl。L接受确认时自动暂停并保持当前目标，只切换阶段，动作由下一次J/G执行。

| 当前阶段 | 观察与按键 | 下一步动作 |
| --- | --- | --- |
| `align` 对准支管 | J/H正反微调。观察前部已绕过支管且仍贴稳主管；Ctrl+空格暂停，L确认，然后J | 开始 `unwind` 解旋 |
| `grip_adjust` 小U前半径手调 | O/P继续收紧／放松，空格暂停，J/G继续；到位自动保持，也可L采用当前值后J/G | 按选定初始半径形成小U，之后恢复原放松流程 |
| `unwind` 解旋 | 每次J推进一段，停住后再按下一次；也可G连续。观察小U从尾朝头看搭在主管右侧 | 到 `right_u_hold` 自动暂停；已形成合适姿态时也可提前L确认，无3秒最低等待 |
| `right_u_hold` 右侧小U保持 | 确认U搭在主管右侧、前部仍承托，L确认，再J/G | 按当前曲线分界保留前部，关闭其余尾段扭矩；尾部自然下落。K显示保留范围 |
| `drop_hold` 尾部下垂 | 确认尾段摆到主管轴线下方，L确认，再J | 进入 `return_seat`，逐个接管切线弧与直尾 |
| `return_seat`／`return_wind`／`return_finish` | 继续逐次J，或G连续 | 缩短直线段、前部随曲线滚动推进，尾部逐节缠绕上管，再消去切线弧 |
| `recover`／`roll` | J单步或G连续，现场观察整身是否清障 | 恢复完整Helix与滚动 |

当前默认释放时保留J1–J8，其余失能，可在 `GRAVITY_RETAIN_JOINTS` 修改。失能发生在 `drop` 的第一个控制步，不以位置目标慢慢放低尾部。

## J、H、L的含义会随模式变化

| 按键 | 模式4 | 模式5／6 |
| --- | --- | --- |
| Ctrl+J | 发起一段头侧增长任务 | 当前阶段最多推进 `HELIX_STEP_S` 秒控制动作，默认1 s，然后保持 |
| Ctrl+H | 发起一段头侧缩短任务 | 仅在 `align` 阶段用于反向微调；其他阶段用J推进 |
| Ctrl+L | 沿当前调长任务方向强制推进一小步 | 确认实物支撑并保持；早按会记住，完成前部衔接后接尾，重复L不重置 |
| Ctrl+G | 当前调长任务暂停／继续 | 当前切换阶段连续推进／暂停；遇到姿态确认点会停下 |
| Ctrl+空格 | 暂停 | 暂停并保持当前目标 |
| Ctrl+K | 显示调长状态 | 显示当前阶段、计划窗口、进给、接管边界与下一步提示 |
| Ctrl+O/P | 不调整模式4的ARC半径 | 仅Ctrl+6对准阶段，初始Helix抱管半径收紧／放松，每次1 mm |
| Ctrl+X | 全部失能 | 全部失能 |

单步时每次等动作停下再按下一次J。一次J可包含多个20 ms控制更新，1 s是控制动作预算，并非“只让一个关节转一下”。在5/6中再次按模式热键会暂停已开始的流程，后续仍用J/G推进。

## 录像为什么很久才开始解旋

`feed_h6_4x.mp4` 的实测记录中，仿真t≈149.4 s已经形成Helix并进入 `align`；t≈332.6 s才确认并进入 `unwind`。约183 s花在0.14 rad/s的慢速滚动对准，未设置固定空等时间。

这是实验脚本模拟操作者时，同时要求滚动相位、前端方位、主管／支管接触及穿越位置满足条件造成的长对准。该判据较苛刻，当前对准效率仍有改进空间，不能把录像中的等待时长解释为步态必需时间。

这些MuJoCo世界坐标／接触判据只在实验脚本中使用。实机没有该自动确认：在 `align` 阶段观察实际姿态，暂停后L确认，再J即可开始解旋，不必等待某个秒数。控制器用舵机角、已发使能与时间生成运动，真实支撑、支管相对位置和释放时机由操作者确认。

2026-11-07确认入口修复：实机记录显示，旧版在 `front_hold` 等待期间，J累计执行16 s只旋转前部；后续记录显示已进入 `first_shift`，而旧代码在该阶段重复L会给出笼统拒绝提示。现已修复这两处行为，并支持在前部成形／就位阶段由操作者提前确认实物支撑。送尾不再要求已锁定前部追踪另一条名义螺旋；尾部仍沿实测拼接曲线逐节接入。日志新增最近16条命令的接收结果、拒绝原因及前后阶段。此次仅验证控制交接，未证明新连接件实机上管或自适应半径成功，见[核对记录](../validation/reports/front_confirmation_20261107/README.md)。

## 调参与证据

| 实机文件顶部参数 | 含义 |
| --- | --- |
| `HELIX_RADIUS_M / HELIX_PITCH_M` | 蛇身中心线螺旋半径／每圈轴向螺距 |
| `HELIX_MIN_FRONT_TURNS / HELIX_FRONT_SEAT_RAD` | 前部材料预算／前部单独小幅滚动就位量 |

| `FEED_RATE_JOINTS_S` | 与模式4共用的左右调长速度上限，默认`.10`个关节间距/s；模式5/6自动调长时再乘下行倍率。若曾在`FEED_OPTIONS_OVERRIDE`添加同名底层速度项，以覆盖项为准 |
| `HELIX_TRANSITION_SPEED_SCALE` | 首次ARC→Helix速度倍率，默认1.3；不加快后续重力释放回卷，1.0恢复原速 |

| `GRAVITY_SHIFT_RATE_M_S / GRAVITY_RETURN_ROLL_RAD_S` | 首次ARC接尾与重力矩回卷共用的直尾缩短速度／前部相位推进速度 |
| `GRAVITY_GRIP_RADIUS_STEP_MM / GRAVITY_GRIP_RADIUS_RATE_MM_S` | O/P每次调节的半径量／平滑速度；仅作用于小U前抱管阶段 |
