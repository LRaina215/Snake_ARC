# 姿态自主窗口：开发与实验计划

## 本轮假设与边界

仅根据实测全关节角、采样时间、已发相位、使能掩码和机械尺寸，可以把当前开放圆弧的位置与长度一起调整；不再只选择6/8两档。身体形状不能测量管径、接触或承重，本轮不声称自主识别全部受力关节。

使能仍是一个连续区间。起始搭管采用已有六关节参考，随后不设置期望关节数，也不要求回到六关节。机械限位、两端被动边界和截面可估计性保留。旧实机与手调入口保持，研究仿真使用新策略。

## 固定条件与改变变量

20关节、21段64.5mm；正向0.6rad/s；200ms新角、20ms目标、1ms动力学；原PD127/1、限矩2.355Nm、被动阻尼1.5和摩擦；截面顺应gain=.02/yielding=.7，目标限速45°/s和过滤.15s。不加外力、不改阻尼/反馈、不装环境。

改变：取消6/8白名单及优先回六关节；增加任意机械可行宽度的相位参考、基于实际形状的邻域边界选择、单边界扩缩和回退。新宽度参考由几何模型及已有正常滚动校准残差构造，未经该宽度实测校准的部分明确是迁移假设。不开启运动中在线学习，不将偏移学成正常。

长度依据同相位实际/名义身体半径与转角偏差，位置依据可信悬垂代理与曲率相互确认。几何合格优先，数量只是次要选择因素；观测不可信保留窗口，不用放宽门槛消除标志。

## 动力学预算：两个主例，最多一个修复

1. 直管：实体113mm，起始J6–J11、x=-.9m；不加侧拉。检查取消数量限制后正常滚动/自然迁移是否保持开放与支撑。最长82s，有至少两次实际位置交接后继续一完整指令周期可结束。
2. 急弯：连续90°，入口110/角部160/出口210mm，拐角前后各150mm变径；起始J8–J13、x=-.25m。最长100s；全身固定骨架越过特征后继续至少一完整指令周期，最近交接后也至少一周期，且没有未完成交易/试探。不强制出现9关节或返回六关节。
3. 仅当主例暴露具体缺陷时，保留失败并写原因与修改，再复验同病例一次。不得扫参数或借修复新增场景。若失败超过预算，报告未完成，不包装为通过。

每次动力学后先复盘再开展后续。落地、非有限、控制故障结束运行；保存结束前全部状态。启动前只读既有记录检查新参考/选择的明显缺陷，不计入动力学次数，也不能替代真实响应。

## 验收与全量审查

沿用已冻结形态带：实际段总转角150–218°、开口≥.4、平面RMS≤15mm；已发目标≤190°、开口≥.4。实际关节限位、连续掩码、失能主动矩0、支持≥2N、无落地、有限状态；正常交接不暂停相位，进入角实测预置，共享目标不跳变。

保存全部20ms实际qpos/qvel/目标/掩码/反馈/控制状态与事件，1ms检查失能、地面、限位、饱和。审核完整运动、最差帧、交接、曲率、出口续行和漂移；管轴展开包绕单独审核，急弯不可测区不当成通过。对照只引用同场景同初态历史记录，不据此宣称通过率或能效优势。

报告区分软件取消限制、真实选择行为、形态/支撑验收和未覆盖范围。奇数数量即使出现也不能单独证明自主选择合理；没有出现额外数量也不能凭测试少否定实现。只本地commit，不上传，不更新实机。
