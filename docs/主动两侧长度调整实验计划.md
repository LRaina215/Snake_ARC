# 主动两侧长度调整：两路线仿真比较

2026-10-14，用户批准两条路线并行比较，方向二沿用详细的主动圆弧搬移/重叠交接/必要时往复辅助方案。本轮只开发与验证仿真，保留实机可迁移的纯角度控制接口，不改现有实机与热键入口。沿用mujoco环境，只本地commit。

## 假设、固定条件与变量

方向一：较松圆弧在滚动时允许蛇身相对管道滑移，角度观察可以发现实际身体材料位置变化，之后恢复稳定模板并接续窗口。但仅放松不保证方向可控。

方向二：把固定圆弧曲率沿身体平滑搬移，可以在停止正常滚动时重新分配两侧真实悬垂长度；相邻窗口过渡暂时使用并集，使新关节逐渐接管，旧关节伸直后失能。失败时针对原因尝试小幅往复相位辅助，不改为持续前进。该机制未被动力学验证，不能以指令变化证明成立。

共用现有113 mm水平直管及20关节模型，初始J8–J13、60°、phase=0搭管；相同6 s建立段逐渐到phase=.7后静置，开始比较时应具有相同实际状态。64.5 mm连杆、原重力/摩擦/惯量、被动阻尼1.5、限矩2.355、PD127/1、1ms物理/20ms指令/200ms读角。不施加外力，不运行顺应性，不写根部位姿跟随目标。模板参数是预设，不按实测半径更新。

方向一改变幅值60→45°并以.6rad/s滚动，目标为头侧长度减少一步；先观察实际偏移，再跟随交接、恢复60°并停止滚动。冻结相位几何基准只用于补偿冠部周期性变化，不直接认为补偿结果是真实支撑。方向二保持phase=.7，J8–J13→J7–J12，再返回；5s平滑形变，动作结束观察3s。相邻奇偶轴不可忽略：phase=0时某一族为0°，单纯编号平移可能不改变形状，因此先选两族均参与的.7相位，而不把无动作换编号当成功。

## 预算与验收

首轮最多3次动力学：一例松弧滚动，一例固定相位搬移，第三例仅用于已发现问题的定向修复，运行前记录问题、修改与预期。各主例不超过55s，任务结束观察3s即可，不加长hold、不扫参数、不扩到弯管、反馈延迟或低阻尼。

真实评价由世界骨架在管道中心高度的两侧穿越点计算实际悬垂长度，由全身最高带计算管上冠部的身体材料坐标，并核对支撑连杆分布；均只进入存档和评价，不给控制器。角度控制器用条件性悬垂方向和实测骨架冠部估计，缺乏可信方向时明确输出不可观测，不能读取世界z替代。

单步目标以真实冠部向指定方向至少.65关节、两侧悬垂长度反向变化各至少.5连杆作为最低动作证据，须在结束3s内持续，不以掩码改变替代。返回需回到起始材料位置附近（.5关节范围），不是只回原编号。输出实际变化量和误差，不把这些容差称为精确1关节调整。

全过程检查开放形态，沿用150–218°真实绕管、端点开口/长度≥.4，并检查平面拟合、曲率、支撑、失能主动矩0、限位、饱和、公共目标跳变、自发漂移和推进距离。不更改门槛来报通过；暂时7关节并集单独标出。真实管轴/接触只作评价。无落地不代替形态验收。方向二还要求没有持续累计滚动相位；世界原地只能用真值/实机视频评价，纯关节角不证明绝对静止。

每例保留全程实际qpos/qvel、目标、掩码、角度输入/反馈时刻、控制阶段、事件、真实骨架、支撑与几何元数据。先复盘已完成例再决定第三例。完成后生成实际运动视频/时序图/最差状态图，报告事实、问题、原因置信程度和未验证范围。若未满足完整条件，交付阶段结果而不宣称实机或研究目标通过。
