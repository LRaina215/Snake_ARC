# 2026-11-07 晚间仿真计划

用户授权：本轮在仿真中完成五项问题的验证，优先2/5；通过后直接同步实机与手调入口。只用实机可读角度、使能和时间控制，不连接真实串口。保留已有未提交修改。

## 主任务：自动调长后直接接入源代码回卷

假设：形成同一曲线的前部螺旋和下垂尾段后，可以复用原重力矩 `return_seat → return_wind → return_finish → recover`，通过缩短直尾与前部相位推进完成上管，不需要固定全前部另写卷尾算法。

固定：18关节；首先用现有64.5 mm模型、110 mm主管、原驱动额定力矩2.355 N·m和摩擦参数；反馈200 ms、控制20 ms、实际状态50 ms。读取XML确认几何。新连接件的准确轴距未确定，旧模型通过不等于新实物通过。

第一轮只跑1个近等长ARC起态，记录自动选择的材料位置、前部曲线准备、源回卷接管与全身恢复。失败后针对证据修改，只复现该例，不盲目增加起态。基础例通过后检查头短、尾短、T管代表例，各1次；数量和必要修复逐轮记入报告。

验收：从ARC实际连续运动进入，不能瞬移／重置；调长阶段保持开放承载弧；前部确实形成贴主管的螺旋，接入时尾部自然下垂；回卷逐段改变曲线，前部随相位继续运动；最终实际全身形成同轴Helix，保持后再滚动一小段。检查实际支撑、地面接触、非相邻碰撞、失能力矩、目标/反馈、限位、饱和、整体滑移与最差状态。用管道接触与世界位姿评价，不把它们传给控制器。

## 末端零位使能后释放

单独验证用户指定的Ctrl+U初始化：承载ARC先形成并保持，两侧非承载关节按当前位置预置、短时使能并逐渐命令0，再恢复失能。先1例有弯折的悬垂端；通过后1例包含末端地面接触。检查是否展直、是否牵动承载区、释放是否确实关闭扭矩。地面上的直线端不等于重力参考，不能把它误记为已恢复竖直下垂。

## ARC半径与稳定/速度折中

主任务通过后进行有限对照。先固定同一110 mm管和同一保存起态，只变3个ARC幅值（初定50/60/70°），同方向同材料转移任务。比较实际材料迁移、开放形态、承载、完成时间、滑移和饱和，不以内部位移量替代实测送链。若三点不能区分，不声称全局最优；只有新证据需要时补一个针对点或第二个管径。必要时用73 mm等距代理模型检查几何敏感性，明确它不是已测定的新机械模型。
