# 角度反馈的连续滚动交接研究原型

2026-10-13：固定六关节直管三次无停顿交接通过；110→210mm连续90°急弯中，位置往返及6↔8交接通过本轮身体/支撑条件。强端部载荷下的固定六关节返回失败，短端全相位可靠定位未解决。完整证据和范围见[本轮复盘](../validation/reports/rolling_handover/README.md)。本方法尚未接入现有手调和实机入口。

## 修改位置与输入

- `rolling_shape_observer.py`：实际20角→头部坐标骨架→实际截面与连续曲线。冻结正常相位基准仍用已有6/8参考，正向60°/0.6rad/s与机械21×64.5mm。实际冠部偏移需要条件性的向下方向；同旋向弯曲质心只是交叉证据，不能冒充重力冠部。
- `rolling_handover.py`：继承既有长度策略；消费定位建议，用当前角度预置、目标预演和实际候选形态执行相邻交接。正常不写phase_hold。保留原暂停交接模块，避免改变已同步实机方法及历史输入。
- `rolling_simulation.py`：复用现有PD/模型，每200ms同步模拟读全角，20ms给目标/使能，1ms物理。内层模型速度供PD，外层速度只从新角差分。世界位姿、接触、管径、实际矩不进控制器；场景半径只在初始放置使用。

`HalfArcParameters`沿用奇偶各π预算；稳定6/8、扩缩过渡7。固定宽度位置交换恒6，不采用7关节重叠。至少保留1个被动边界关节，当前可迁移候选J2..J19；不是从任意姿态自主搭管。

## 定位的两类证据

先看实际开放形状。两侧长端足够直且方向一致时取均值；短端/两端不一致时尝试选择至少3段、直线度≥.98、方向位于开口方向60°内的长端。选中单端时记录来源和“不能证明重力”的假设，不读取真实重力。原冠部残差0.5关节，加弯曲0.2关节或边界差8°同方向佐证，持续0.5s才建议相邻迁移。

没有可信悬垂方向时，保留强同旋向弯曲0.5关节+边界8°的几何输出。它可能识别弯曲区移动，却不能证明最高点/支撑在哪里。本轮首例纯弯曲没识别353个真正冠部偏移样本；返回失败的落地状态还产生了错误几何建议。`valid/position_valid`是该输出的几何/条件有效标志，不等于已取得真实重力或接触。全相位采样覆盖与独立位置正确性分开报告。

参考不在线重学。窗口或反馈连续性变化清除滤波/确认，稳定后冷却5s。7关节只输出过渡几何，没有已校准迁移定位，不能把稳定6/8的相位验证扩大到7关节或任意速度。

## 动态交接

进入关节以新读的实测角预置，五个共享关节延续已发目标；退出实际角沿用≤4°，取消原≤8°/s的静止要求。位置交换在最新角采集时完成，一进一出；扩大只加入一个，收缩只释放一个。纯加入等待该族参考因子≤.1，给200ms采样留运动机会，不暂停相位。

检查实际候选150–218°、开口≥.4、平面RMS≤15mm；预置与下一帧下发目标≤190°、开口≥.4。下一帧在复制的截面核心预演，真实核心只积分一次，45°/s限速。候选不合格保留原窗继续滚动，20s仍不能交接则拒绝。当前形态/目标故障或不完整7关节交易会冻结；这是异常处理，不是正常移窗hold。

位置连续不保证力矩连续；退出接近伸直也不证明卸载。本轮动态退出实际矩约0.39–0.99Nm，明显不能沿用旧0.2Nm卸载结论。支撑与力矩都只在事后审核。

## 六关节试探计数修复

原新策略沿用旧规则“pending为空才收集六关节试探”，但等待移窗仍在正常推进相位，导致57.2s完整周期只有28次统计，被误报形态失败，实际上good=true。现仅本策略修复：等待位置交接仍收集真实新角；实际移窗后从新窗口重新覆盖一周期。至少40新反馈才判，数量不足继续收集，不称形态失败。8关节时序和半径/形状长度信号保持。

急弯复验停止时，新窗口已有53次合格读角，实际保存态覆盖一指令周期；最后新读角尚差下一采样机会，`six_trial`仍在等待，`prefer_feasible_six=false`。不能说控制器已发出新的六关节可行确认。驱动已补充等待该确认再结束；该停止规则没有另增动力学复验，不为了约0.1s再跑整轮。


仿真实验入口`rolling_handover_experiment.py`为natural/short_return/combined，当前5次预算用完会拒绝新动力学。新一轮需明确病例、数量和输出批次。视频/参数/失败在本轮报告目录；无硬件、无新安装、无实机或手调行为修改。

下一最小工作是先用保存的无可信端状态，判断为什么真实重力方向代理不可用；不要仅放宽直线度/开口夹角让标志变绿。固定六关节返回需要先设计保持在管道上的实际迁移激励，当前60N端部载荷差已证实能使该短端病例掉落，不能继续按同刺激做无目的重复。若要求所有状态都取得真实重力最高点，角度本身不含整体绝对朝向，需要明确附加可观测条件。
