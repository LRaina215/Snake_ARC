# 连续滚动交接及定位拓展（2026-10-13）

用户批准无停顿交接方案，并新增授权双向返回、短被动端和全相位定位。先仿真，只本地commit；新方法验收后才同步实机。当前实机及手调的暂停交接默认保持。现有用户未提交改动不纳入本轮。

## 假设和输入边界

相邻六关节窗口的进入/退出属于同一奇偶族；当前运动阶段可能存在开放、指令连续的接管机会，不必等关节静止。新角采集时预置进入关节实际角，共享目标保持，退出接近伸直的关节失能；正常相位持续推进。角度几何条件不等于已测卸载，进入预置位置也不保证力矩连续。

旧观察器因两端向下方向不一致或少于三个被动关节而拒绝。新增定位通路使用实际截面内同旋向曲率的身体中心及两侧边界差，与冻结相位基准比较。它估计身体上的弯曲区位置，不假装测量绝对重力方向、管径或接触。先对旧正常/侧拉/自然/返回/急弯记录离线评价误判、实际迁移方向和逐相位覆盖；不以有效标志100%代替正确性。真实冠部、接触和根姿态仅评价。

继续全20角200ms新反馈、20ms目标控制、1ms物理；已发相位和掩码、21×64.5mm机械尺寸为已知状态。频率0.6rad/s、原增益/摩擦/限矩/被动阻尼不变，不测延迟或扫阻尼。固定宽度位置交接恒6；长度扩缩稳定6/8、中间7，维持奇偶族π预算。窗口至少保留一侧/两侧实际存在的边界构形；候选不跨机器人关节范围，短端病例先覆盖一至二个被动关节，不声称零被动端也能定位。

## 开发顺序

1. 对已知旧定位拒绝状态和旧正常段离线复现，冻结新弯曲判据及适用性；旧输入不读qvel/世界信息。
2. 新交接策略独立保留：正常不设置phase_hold；退出实际角门槛先沿用4°，取消绝对低速要求；进入不要求4°，从实测角预置。检查旧/候选身体形态、预置及下一帧目标、共享目标连续。只用新角完成交接。候选不合格保留旧窗继续滚动；当前形态故障或过期反馈采用明确异常处理。
3. 六关节病例通过后同原则用于6↔8扩缩，维持原长度策略；不因移窗失败偷偷扩大使能。

## 三个主病例，最多一个明确修复：总上限4

1. **natural**：已有113mm水平直管，J6–J11、x=-0.9m、先静置2s，最长82s，无外力、无脚本移窗。至少两次由观察自动触发的连续相邻交接，最后交接后至少一个完整指令周期；所有正常交接相位继续推进，六关节使能。已有暂停版本作同初态参考，不另跑旧基线。
2. **short_return**：同一实体直管延长出口以免掉出末端，初始J3–J8、x=-0.9m，最长120s。覆盖两关节短端，并尝试一关节短端。为产生实际反向迁移，由实验执行器在24–36s给头端向下、尾端向上各30N，60–72s反向；两端各2s余弦渐入/出、净外力0、峰值力大小总和60N。此前20N净向下载荷仅回摆而未发生真正反向迁移；此处改为明确的端部载荷差，不扫描强度。原参数/实际支持不变，刺激只在执行器，不传给观察器、不能脚本指定窗口。要求实际位置变化同时有头/尾向相邻交接及返回既往窗口。没有真实反向迁移记激励未覆盖；有真实迁移但没跟上才是跟踪失败。刺激可使重力方向代理失效，故要核对几何定位而非依赖末端向下。
3. **combined**：已有110→210mm连续90°急弯，J8–J13、x=-0.25m，最长150s；启用原6↔8策略及新动态交接。检查实际发生的长度/位置改变，出口持续运动及最后交接后完整周期。不得用不可定义单管轴投影否定/证明身体开放，使用保存态接触轴一致性报告评价范围。

逐例审核后才执行依赖病例。最多1次修复，必须先写具体原因、改动和病例；所有失败/中断保留。本轮不扫阈值/刺激强度。全相位定位主要由上述全部实际新采样及旧记录覆盖24相位格验证，不新增无目的动力学矩阵。

## 统一验收与主动复盘

实际身体150–218°、开口≥0.4、平面RMS≤15mm；下发目标≤190°、开口≥0.4。直管实际管轴150–218°另列。支撑≥2N、无落地/越限/非有限，失能主动力矩0；饱和与接管前后实际矩记录。候选/旧窗口、交接边界曲率、完整三维运动、最差状态及持续收紧均审查。指令周期是φ推进2π，不是实测绕管一圈。

位置判断的有效率、每相位误建议/拒绝、与真实冠部/同旋向形状和候选支持方向一致性分别报告。曲率中心不是重力冠部；两者不同不隐藏。只在实际可评价且定位正确的全24相位格讨论全相位覆盖，不以插值或保持旧读数冒充新观察。短端/返回没有覆盖则逐项说明，不抹去已验证交接成果；初始已搭管，不宣称任意姿态自搭管。

不以目标代替实际、不以支持代替开放形态、不以基线也通过的病例宣称效率优势。不为凑第二完整周期追加一次仿真；真实异常仍可以停机，正常交接不能用暂停来取得成功。交付代码、全部实际状态/条件、完整视频、复盘及本地commit。

## 急弯实际记录后的必要计数修复：新增1次，总上限5

原4次均完成。combined在57.2s记录`actual_geometry.turn=161.102°`、`trial.good=true`，但`trial.samples=28<40`，因此误报six-joint geometry trial failed。完整实际身体159.894–189.150°、最低支持25.508N、无落地，不能把计数不足说成身体形态失败。旧程序只在pending为空时收集六关节试探，暂停交接中相位不推进问题不明显；动态交接的等待仍在推进相位，漏计了有效新反馈。

修复只针对本新策略：等待位置交接期间仍以新读角检查当前六关节；实际移窗后从新窗口重启完整周期检验。未满40次继续收集而非报形态失败。八关节时序和长度信号不改变。先用既有combined输入复现原错误并检查修复前缀，再增加唯一combined_repair同初态/场景复验，最长150s。总5次，不追加返回刺激/阈值搜索。
