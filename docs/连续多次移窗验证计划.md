# 连续多次移窗验证与条件移植（2026-10-13）

## 假设和实现条件

先在当前可观测范围内检查连续相邻交接，不直接降低两端至少3段被动连杆的门槛。连续能力指同一段真实动力学中至少两次由角度观察触发的交接，不是手工指定窗口，也不是延长时长替代迁移覆盖。第二例另检查实际反向迁移时窗口是否返回。

拆开新角反馈与20 ms目标控制：主验证按实机默认200 ms采集全20角，观察器/角速度/持续就绪只在新反馈上更新；两个采集间正常推进指令相位、过滤目标。已知相位取采集时刻之前的已发相位。没有重复读数冒充新速度；200 ms是移植的正常接口条件，不做额外延迟/阻尼扫描。窗口始终6关节，当前J4..J17内部，其他主动矩精确为0。

保留60度/.6正向冻结基准、固定截面增益.02/让顺.7/目标过滤.15、原驱动127/1/2.355 N·m、阻尼1.5与armature .01。世界姿态、真实重力、接触、力矩只用于评价。外部拉动只在实验执行器，不送入观察器，也不脚本调用移窗。

## 数量、场景和刺激

1. **连续自然迁移**：113 mm水平直管，20关节，初始J6–J11使能（两侧5/9失能），名义已搭管圆弧，静置2 s，起点x=-0.9 m。自然重力演化，自动期望至少两次连续交接。最多82 s；第二次交接后满两个正常指令周期即可结束。
2. **往返**：相同初始条件，在36–39 s向头端施加短时向外/向下总20 N拉力，随后完整松开；控制器全程自动且不知道刺激阶段。要求头向与尾向均有自动交接，至少一次返回以前的窗口，最后一次交接后至少两个正常指令周期。最多82 s。拉动中不可靠则应拒绝；实际未发生反向迁移则明确是未覆盖，不能只靠目标方向算通过。

先完成第一例复盘，再执行第二例；若第一例因具体实现或交接问题失败，允许一例针对性修复复验，总计最多3个新动力学尝试，不改变刺激强度做搜索。任何中断保存实际前缀和错误。已知旧偏置失败/短端拒绝由已有记录离线复现；正常共同前缀回归使用原数据，不另增动力学。

## 通过与同步条件

- 两次（或修复后相应）动力学验证实际覆盖连续交接及返回；每次建议/交接与真重力冠部迁移、同旋向曲率变化相符，候选支持覆盖≥0.8，不能把支持覆盖本身称为必要性。
- 滚动和每次交接后的实际身体转角150–218度、开口≥.4、平面RMS≤15 mm；直管实际管轴角跨度≤218度。没有落地/越限/非有限状态；失能主动力矩0，使能计数6。全程检查力矩饱和、曲率、拒绝、相位保持、无刺激阶段的往返误切。
- 用所有实际保存态检查全过程，保留失败和成功。手工窗口请求、预设掩码切换、无实际反向迁移不能算返回通过。
- 主验证通过，直接将同一数学核心和三模式Ctrl热键同步到现有仿真入口及独立实机Python文件；不需要用户再批准代码同步。实机仍直接运行一文件，预置新关节实际位置、退出逐ID失能并读回。没有执行真实机器人实验，不能写成实机通过。
- 不通过则保留仿真修复与完整证据，不更新实机滑窗模式。只做本地commit，不上传GitHub。

## 两例完成后的激励复盘与最后一次复验

自然例已覆盖两次交接，50.58 s结束。第二例的头端斜向拉动没有产生真实尾向迁移：松手后真重力冠部偏移中位-1.21关节，支持中心继续向头侧移动，不能将没有返回归咎于窗口执行器。核对施力关于真实管轴的力矩，方向并没有相反，但水平与竖直分量抵消后中位仅0.52 N·m；同姿态的纯竖直载荷差可提供约3.66 N·m。这是已算出的施力分解，后一数字是未执行前的机械估算，不能当成运行结果。

最后一次预算修正的是实验激励，不改观察或交接阈值：仍36–39 s，头端向下17.071 N、固定J10模块向上2.929 N。力大小之和仍20 N，净向下仍14.142 N，与原斜拉相同，去掉水平分量的抵消；不扫描幅值/时长，不传刺激标签给控制器。原失败完整保留，返回未覆盖与真实跟踪失败分别报告。若此例仍不满足验收，不继续加试验。

## 实际覆盖与同步范围决定

三次动力学预算已用完，不追加。用户本轮要求验证“连续多次移窗”，第一例在18.0和29.6 s连续自动交接并在最后交接后完整滚动两个周期，该主目标已通过。额外两种刺激均未产生冠部及同旋向弯曲共同确认的尾向迁移（逐新反馈统计为0），不能把没有返回判成反向跟踪通过，也不能据此否定主目标。
