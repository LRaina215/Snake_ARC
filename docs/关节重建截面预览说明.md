# 关节重建截面预览（当前版本）

用户要看的截面是关节重建后控制器拟合的那张平面。当前预览沿该平面法向正视它；不再用重力方向或世界Z另外选平面。

直接运行原来的仿真/实机Python入口即可。左侧显示局部使能段及两端边界连杆，右侧保留全身角度、使能与最大角差。u/v是实测截面的二维坐标，没有世界坐标含义。已取消Gravity / Head按钮和PREVIEW_GRAVITY_ALIGN选项；窗口开关仍为实机SHOW_PREVIEW、仿真SHOW_SHAPE_PREVIEW。

- 蓝/紫折线：实测连杆在该截面内的投影，紫色表示失能边界。
- 橙色虚线：已发目标连杆，投影到同一张实测平面。
- 青绿色曲线：控制缓存的实测平滑曲线，其显示坐标与控制器原始二维曲线一致。
- 洋红色虚线：滤波前顺应候选的平滑曲线，先按自身几何还原到头部坐标，再投影到实测平面。不会分别旋转/平移去凑重合；它与已发目标可能因滤波和限速而不同。

实测截面原点和基底直接取自控制的geometry缓存。基础模式没有顺应缓存，使用同一local_section方法并注明“未参与顺应控制”；近乎直线、无法确定截面时等待圆弧形成。控制缓存缺失或窗口不匹配时等待控制器更新，不切到其他平面伪装结果。

实际三维连杆可能并非严格共面，这里展示的是控制器使用的平面截面；面外差异应结合右侧关节角检查。该显示不提供世界位置或姿态，也不使用重力估计。历史重力观察器源码/记录保留供追溯，不由当前预览调用。

仅用原25 s记录核对，未改控制或新增动力学；[检查记录](../validation/reports/reconstructed_section_preview/README.md)。
