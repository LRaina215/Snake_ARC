# 双侧重力对齐预览：本轮计划

假设：两侧合格悬垂段融合并维护历史方向，可减少单侧摆动导致的画面转动；仅改变显示，不改变任何控制输出。仅角度不能观测全身共同刚体转动，因此跨帧转换仍以可信悬垂端近似稳定为条件，不声称绝对世界姿态。

固定条件：当前v3控制、20关节尺寸、0.2 s读角、原机械模型。改变变量仅为预览方向估计。输入为全角、窗口、时间和尺寸；MuJoCo根旋转和真实重力只在离线评价中使用。

预算：先只读已有直管修复记录；新增一次25 s直管短仿真，10–12 s对头端施加4 N侧向/向下拉力，之后连续恢复13 s。必要时最多一次有明确失败原因的修复，不作参数扫描。原始状态/目标/掩码/反馈保存，完整运动与开放形态、支持、失能、限位、饱和照常复盘。

验收：估计仅新角更新；双侧冲突/均不可用明确降级而非假装可靠；无180°翻转和数值异常；正常双侧可靠区对真实向下误差p95≤12°；扰动后的可靠区恢复。比较双侧瞬时平均及融合历史估计的实际方向误差变化，不只比较头坐标向量变化。显示变换必须为正交旋转，骨架长度保持，实测和目标共用同一旋转。头部视图与重力视图可切换，显示不写控制状态。

真实重力与接触仅用于评价；不据此给控制器供参，不把图像稳定当作重力准确。已有直管残留包绕超限仍保留，非本轮控制修复目标。
