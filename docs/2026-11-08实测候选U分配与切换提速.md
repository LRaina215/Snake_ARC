# 实测候选：缩短U/直尾并适度加快ARC→Helix

用户正在实机测试，授权直接提供一套候选分配和适当提速，由用户现场验证。本轮不把候选参数称为最优，不连接实机串口。

## 本轮假设与必要检查

假设：缩短解旋圆弧和直尾的总长度可保留更多前部螺旋；释放边界也必须跟随当前曲线，否则缩短后继续只保留前8关节会抵消收益。首次切换进给提高，同时按同倍率提高相应目标斜率，可缩短等待而保持顺序接管。先试1.5倍，发现跟踪误差增大后，默认收回1.3倍。

固定18关节和现有64.5 mm等轴距代码模型；U半径90 mm、Helix半径／螺距、原放松半径及重力矩释放后回卷速度不变。变量是U角度150°、直尾129 mm、自动曲线释放边界，以及首次ARC→Helix速度倍率。

检查包含：候选曲线预算与实际发出的使能边界、提前L与回卷边界交接、首次提速不影响重力释放后回卷；此前成功的4(H)→5场景先跑1.5倍、再针对跟踪问题补1次1.3倍，共2次，之后停止。新U配置的实物可释放姿态、打滑与负载由用户验收，不用软件检查冒充实机通过。

## 默认值和操作

实机文件顶部可直接修改：

```python
GRAVITY_U_ANGLE_DEG = 150.0
GRAVITY_U_RADIUS_M = .090
GRAVITY_RELEASE_LINE_M = .129
GRAVITY_RETAIN_JOINTS = None
HELIX_TRANSITION_SPEED_SCALE = 1.3
```

按当前代码模型，U曲线长约235.6 mm，直尾129 mm，剩余前部螺旋约860.9 mm，即1.42圈，完整螺旋关节前缀为J1–J12。原180°／322 mm对应约1.03圈、J1–J8。以上是目标曲线预算，不是新连接件的实测尺寸。

`None`表示按当前U／直尾曲线分界保留完整螺旋关节；也可改成整数手动固定。提前L会按当前已经执行到的曲线计算，可能保留多于12个；不再强制等3秒或等满目标角度。L先确认并保持，下一次J/G才关闭尾部扭矩。K和L提示都会显示前缀；这不是读取了接触力的自动支撑判断。

模式5/6的首次切换加快自动调长、前部成形和首次回卷接尾。仍逐段预置实测角后接管；保持反馈采样、跟踪判据和姿态确认。原重力矩解旋时序、后续释放／放松及回卷速度不随此倍率加快。设成1.0可恢复原切换速度；模式4手动送链速度不改。

运行新代码前需退出旧进程；已经运行的Python不会自动加载修改。Ctrl+5→G自动准备前部，搭稳后L→G接尾；Ctrl+6仍按实物观察确认。O/P只调U前抱管半径，后续仍恢复原放松参数。

## 同日补充：显式送链速度与两种入口共用

此前模式4虽支持`FEED_OPTIONS_OVERRIDE`覆盖速度，但未在顶部显式列出；模式5/6的自动调长又硬编码`.1 × 切换倍率`，不会继承模式4的速度修改。现增加顶部`FEED_RATE_JOINTS_S=.10`，模式4直接使用，模式5/6自动调长使用它乘`HELIX_TRANSITION_SPEED_SCALE`。例如改为`.15`时，两者上限分别为`.15`和`.195`关节间距/s（倍率1.3）。上限不是实测毫米速度，实际仍受反馈及跟踪影响。此参数只改变调长阶段，后续成螺旋／接尾仍由各自速度参数控制。

兼容之前建议的字典配置：若`FEED_OPTIONS_OVERRIDE`已有`maximum_position_rate_joints_s`，它优先于新独立参数，模式4/5/6都读取该值；通常只需修改新参数，不必再手动添加字典字段。K输出显示当前实际采用的调长速度上限，模式5/6显示值已经包含倍率。仿真手调直接导入实机控制器，共用同一设置。修改后重启程序。

本次只调整参数传递，默认上限仍为模式4的`.10`和模式5/6的`.13`，未改变默认几何、目标限速或时序。不新增动力学实验；40项相关软件检查通过。新增检查用内存舵机分别核对默认值、改为`.20`及旧字典覆盖`.15`时，真实模式入口和自动调长的实际曲线坐标推进，覆盖独立实机核心与库版本；未打开COM。该检查验证速度配置生效，不证明更高速度的实机稳定性。
