# 姿态驱动的圆弧位置与使能数量

2026-10-13 最新数量判据为实测覆盖角接近180°，不引用初始幅值；取消名义π预算否决五关节候选。实测曲线离散逆算补偿、反向统计和推荐执行修复已同步实机与手调。两主例具备扩缩/收紧证据，全过程严格形态仍未通过。[当前设计与交接](../validation/reports/half_circle_window/README.md)。下文为旧版历史。

本文保存上一轮v1方法与验证；当前数量判据已更新为[相位均衡及同相位归一化](相位均衡数量判断设计.md)，下文的.5s数量过滤、绝对转角门槛和全部退出角4°不再代表最新研究控制器。现有实机/手调入口仍未同步。

## 当前接口与适用范围

核心在`snake_control/posture_window.py`，仿真适配在`posture_simulation.py`，研究入口为`validation/posture_window_experiment.py`。现有实机/手调入口没有更新。初始化仍从已经搭在管上的名义圆弧开始，不是任意放置自搭管。

`PostureWindow`只接收全关节实测角（度）、采样/控制时间、采样对应已发相位；机械长度、滚动参考与当前掩码在内部保存。没有MuJoCo导入、root/真重力、接触、管径、qvel或真实力矩。内层仿真PD仍使用qvel。失能主动矩0，阻尼/armature仍存在，未标定成实机等效。

## 不再选择两档数量

稳定使能区域是连续区间`[first,last]`，不设稳定数量白名单，也没有`prefer_feasible_six`、六/八关节专用试探或指定返回数。7、9等可稳定运行；上限来自20关节的两端被动边界，低限来自截面拟合和全周期关节限位。当前每组总预算π、限位留.01rad余量时，五关节的一组仅有两轴，需要90°，会被拒绝；这不是重新写入六关节白名单。

`HalfArcParameters`和`nominal_angles`对两种交替轴分别按模块长度分配π。增加关节后每轴转角随之减小，不沿用每轴固定60°。初始化检查实际参数参考与此分配一致，防止把旧固定幅值参数用于任意宽度。

## 相位参考

有已冻结校准的宽度直接复用其记录；没有校准的宽度，计算该宽度自身的名义三维形状，再加已有校准相对于各自名义形状的残差。残差按宽度插值，超出校准范围使用最近残差。已校准宽度目前为历史6与8，这是数据来源而不是允许集合。模型不在线学习，不把迁移后的形状学成正常。

参考字段仍为冠部相对中心、同向曲率质心相对中心、尾边界减头边界曲率。模型开口方向用于生成名义参考；实际观测仍需可信悬垂端。新宽度的残差可迁移性是假设，本轮仅实际验证七关节，没有验证所有宽度或任意被动端/外载。

## 统一选择两端边界

对当前实测段和同相位名义段求身体圆拟合半径与总转角。候选所需数量的连续代理为：

`count_proxy = current_count * (actual_radius / nominal_radius + nominal_turn / actual_turn) / 2`

它是几何启发式，不是测得的管径、接触长度或承重最优解。半径/转角项交叉约束，实际圆拟合RMS≤12mm才用于数量选择；.5s滤波、.65关节滞回、1s相同候选持续确认。转角≤175°且代理显著大于当前值时增一边；转角≥185°且代理显著小于当前值时减一边。没有满足条件就保持数量，不主动试探最少数。

位置依据既有条件性冠部与曲率交叉确认。当前误差≥.5关节并有同方向曲率证据时，平移相邻一关节；长度要调整时比较两侧增/减候选，让新增/退出边界同时靠近圆弧位置。候选先满足实际开放、平面拟合、机械可行和至少一个可信长悬垂参考，再按中心偏差和接近180°评分。数量优先级没有覆盖形态资格；没有可信参考时保留，不声称知道真实最高点。

## 连续滚动交接与试探

平移一进一出；扩缩一次只改变一个边界，不将7关节当成必须立即结束的交易。进入关节从本次读角预置，共享目标不跳；退出角≤4°，添加时相应轴接近零相位。复制核心预演下一帧目标，当前预置和下一目标需≤190°、开口≥.4、步长≤.9°。没有旧8°/s静止条件，也不暂停相位。20s无法交接就拒绝，保留原窗口。

每次交接后5s观察实际形态、至少1s后连续两次不合格申请回退；回退也经过候选和目标门槛。该短审查不称为完整周期或承重认证；全过程验收独立检查最后交接后完整指令周期。回退没有本轮动力学触发覆盖，不能宣称恢复能力验证通过。

## 运行与证据

在已有Conda `mujoco`环境、仓库根目录执行研究入口：

```powershell
python -X utf8 validation/posture_window_experiment.py straight
python -X utf8 validation/posture_window_experiment.py acute
```

这是有预算保护的研究入口：本轮两个主例已运行，不能用同一命令覆盖重跑；具体修复须先写报告中的`repair_plan.md`，再加`--repair`，总动力学上限三次。日常热键调试仍运行README中的`codes/Rolling_Arc_Debug_Mujoco.py`。

只读归档审核/视频和软件检查不增加动力学：

```powershell
python -X utf8 -m unittest validation.test_posture_window
python -X utf8 validation/replay_posture_window.py
```

完整结果见[本轮复盘](../validation/reports/posture_window/README.md)。直管保持六关节并连续移窗；急弯实际选择七关节并续行，末段仍出现扩大候选。不声称最终数量最优或所有扩缩、宽度、双向返回已验证。只本地提交，实机效果尚未验证。
