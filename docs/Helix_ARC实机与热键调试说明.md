# Ctrl+7：Helix → 开放半圆ARC → 自动归中

完整的上电→Ctrl+U→Ctrl+5→Ctrl+7连续操作及各阶段调速见[往返切换简明说明](上电到ARC_Helix往返切换操作说明.md)。

2026-11-08，按用户验收的三周向仿真版本同步。实机与`Rolling_Arc_Debug_Mujoco.py`共用同一个控制器；实机仍只需运行一份`Rolling_Arc_Real.py`。实机效果由用户验收，本轮没有打开COM串口。

## 启动与操作

沿用`mujoco` Conda环境，运行原入口：

```powershell
conda activate mujoco
python .\codes\Rolling_Arc_Real.py
# 仿真手调：python .\codes\Rolling_Arc_Debug_Mujoco.py
```

1. 将机器人稳定搭在主管上，起态为Helix；可以先完成Ctrl+5，也可从实物已形成的Helix接管。
2. **Ctrl+7**：读取全身实测角，选择逆向解缠流程并保持；此时不改变已发目标或使能。
3. **Ctrl+J**：执行最多1秒后保持。执行中重复J不追加任务。首次推进重新读取实测姿态，不使用选择模式时的过期姿态。
4. **Ctrl+G**：连续执行；再按G暂停。暂停后再次J/G从原进度继续，不重置曲线或追赶暂停时间。
5. 连续流程依次完成出管过渡、逆向逐段解缠／失能、顶部承载弧选择、头端导出／半圆成形、端部失能、两端归零再失能、自动送链归中，以及**按最终使能范围再次归零两端再失能**。随后交回基础圆弧并自动保持，不直接继续走。
6. 完成后**Ctrl+J/H正反单步、Ctrl+G连续／暂停**，沿用刚形成半圆的材料区间、半径、窗口和相位。使用基础控制器的`PHASE_STEP_RAD`步长、`OMEGA_RAD_S`速度；不再受模式7的一秒预算和速度倍率调度。参数热键也走原基础入口。

基础圆弧J/H每次行程可直接改顶部`PHASE_STEP_RAD`，如0.10改0.30就是每次三倍相位行程；Ctrl+=／Ctrl+-在线加倍／减半（热键当前范围0.01–0.6 rad）。步长不等于速度，动作速度由`OMEGA_RAD_S`控制，目标变化还受`MAX_TARGET_RATE_DEG_S`限速。运动中再按J/H继续累计或反向抵消，不再进入额外建形／2秒静置，也不等目标误差小于1e-8才结束单步；相位走完后目标继续平滑到位，下一键随时可接入。G／空格／N的人工暂停仍立即冻结最近目标。

Ctrl+空格／N暂停保持，Ctrl+K显示阶段、使能、拟合半径／螺距、执行时间与角反馈估计的两侧长度差，Ctrl+X全部失能，Ctrl+Q退出。Ctrl+7切换过程中不需要Ctrl+L确认，也不使用H倒放流程；**完成后的H是基础圆弧反向单步**。切换过程中再次Ctrl+7暂停并保留进度；完成后再次7代表新建一轮Helix→ARC流程，应在Helix上使用。

Ctrl+4/5/6保持原功能。可以离开7选择其他模式；选择其他模式失败时保留7的进度并保持。切回Ctrl+4仍按原送链配置工作，Ctrl+5/6仍按原成形／越障流程工作。

## 直接修改的参数

整体速度直接改实机文件顶部`HELIX_ARC_SPEED_SCALE`，使用方式与Ctrl+5的倍率一致；仿真手调读取同一份配置。默认1.0保留验收速度，1.5表示1.5倍动作速度，2.0表示两倍。改完需重启Python。

如果希望Ctrl+7始终共用Ctrl+5的倍率，可直接写`HELIX_ARC_SPEED_SCALE = HELIX_TRANSITION_SPEED_SCALE`；默认仍是独立的1.0，避免此前Ctrl+5设为2.0就自动把7加倍。

| 参数 | 默认值与作用 |
| --- | --- |
| `HELIX_ARC_SPEED_SCALE` | 1.0，统一动作倍率。下列OPTIONS是基础值，实际动作按倍率缩放 |
| `HELIX_ARC_STEP_S` | 1.0 s，J单步运行时间 |
| `reverse_feed_m_s` | 0.016 m/s，直尾送出速度 |
| `reverse_roll_rad_s` | 0.112 rad/s，配合的反向相位速度；整体调快解缠时与上一项按同比例调整 |
| `retained_turns` | 1.0，转换半圆前保留的螺旋预算；此前0.7圈方案在仿真掉管，不作为默认 |
| `exit_extra_rad` | 30°的弧度值，退出过渡额外弯角 |
| `head_clearance_rad` | 40°的弧度值，头端临时正交绕行弯角，成形后消除 |
| `lead_s / flatten_s` | 1.5／6.0 s，建立过渡／半圆成形时间 |
| `target_rate_deg_s` | 35°/s，目标角最大变化率 |
| `FEED_RATE_JOINTS_S` | 与Ctrl+4/5共用的调长速度；归中时乘Ctrl+7倍率，同名底层覆盖项优先 |
| `FEED_OPTIONS_OVERRIDE` | 公共调长参数；length_tolerance_m为长度代理容差，target_rate_deg_s为调长目标限速 |
| `roll_rate_rad_s` | 0.35 rad/s，仅用于离线直接调用核心续滚；实机／手调完成后由基础`OMEGA_RAD_S`控制 |

整体倍率覆盖解缠送链／相位、调相、过渡成形、头端导出、逐节释放和自动归中；各自目标角最大变化率也同比缩放。比如1.5倍时，基础16 mm/s与0.112 rad/s成为24 mm/s与0.168 rad/s，半圆成形6 s成为4 s。J单步秒数、200 ms反馈周期、2／3 s静置和公共FEED配置中的稳定等待仍按实际执行时间计算，所以全流程时间不一定严格反比于倍率。完成后滚动由基础`OMEGA_RAD_S`控制，不乘此倍率。暂停不推进任何阶段。

模式7不叠乘`HELIX_TRANSITION_SPEED_SCALE`。归中与Ctrl+4/5使用同一个`create_feeding_controller`和`ContinuousFeeding.advance`，读取相同FEED速度、观察器和交接参数，只把目标设为两侧等长；沿用已形成的连续圆弧半径和相位。旧的center_rate_m_s / center_tolerance_m独立选项已删除。机械尺寸由`LINK_LENGTHS_M`提供，当前实机按用户手量近似为头端25 mm、17段相邻轴距72 mm、尾端91 mm。曲线积分与实测Helix拟合均使用各段实际配置距离。仿真手调按加载模型的骨架距离配置，不把新实机尺寸强加给旧模型。

`END_ZERO_ON_HELIX_ARC=True`在归中前`arc_end_reset`和归中后`arc_final_end_reset`各执行一次两端归零。第二次使用最终的承载掩码，包含归中中新释放的关节。保持承载弧目标，预置两端实测角后使能，再按`END_ZERO_RATE_DEG_S`逐步到零；保持`END_ZERO_HOLD_S`且实测角≤5°后失能，最长`END_ZERO_MAX_S`即2秒执行时间后也会失能并继续。实际归零速率乘模式7速度倍率。暂停或J预算用完会立即撤去临时端部使能，再J/G从最新角反馈接续。可设False关闭，不影响Ctrl+U的独立开关。

`zero_then_disabled`代表释放前读角已接近零；`timeout_then_disabled`代表到时释放，不能解读为已归零。日志保留归中前/后两次记录及关节列表；完成后K同时显示释放前最大角和当前失能关节最大角。失能后不维持零角，接触、摩擦或摆动仍可使关节再次弯曲。

控制只用关节角、机械尺寸与时间；实机不需要MuJoCo接触、外部位姿或管道半径输入。起态没有下垂参考时，先执行逆向出管；自由尾段出现后再估计向下。拟合或下垂方向不是承重测量。当前仿真范围为18关节、110 mm直管、三种周向和相同Helix形态，不保证任意装配／Helix都能成功。
