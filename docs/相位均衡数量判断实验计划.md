# 相位均衡数量判断与扩缩验证

## 假设、已知缺口和本轮改变

上一轮七关节的数量代理6.68–7.91，随相位反复建议扩大；旧八关节110→210→110记录末段代理仍约7.7，原.65关节缩窗阈值不会触发。角度重建出的身体形状不是管径或承重。本轮先用既有角记录核对原因，再修改数量决策，不改变窗口位置观察器或截面顺应公式。

数量统计按几何滚动相位mod π分4组，保留最近π相位内的真实新角，组内取中位、组间等权，至少每组2新样本才作常规数量决定。已有七关节记录支持近似π重复；不是所有外载的保证。收集在等待交接/试探/冷却时仍进行，换窗重置，hold同相位数据不能制造覆盖。正常滚动继续，无固定两周期等待。

旧.65门槛用于瞬时/短过滤信号防止峰值触发；改为多相位证据后，扩大使用.5关节的整数舍入边界及1s持续，避免旧直管真实偏差约6.56被忽略。相邻短窗试探需各相位组数量中位最大≤当前数+.25且均衡转角≥180°，另外仍有强紧凑的收缩条件。它判断没有持续不足，只允许一次受约束的缩窗试探，不证明短一关节一定承重。

扩大依据均衡后的持续形态不足；缩小保留强紧凑信号，同时增加“没有持续长度不足、当前接近半圆时”的相邻短窗试探。试探由形态和多相位证据提出，不指定最终6/8/其他数；交接仍需实测预置、实际候选、机械、目标开放和限速条件。实际形态审查/回退不能冒充承重检测。
